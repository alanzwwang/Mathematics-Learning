No peeking until you've tried! If you got one wrong, figure out which tool slipped — the sign rule, the LCD, the reciprocal, the undo, or the flip.

Easy

  • 1.
    3 ÷ 8 = 3/8 — the fraction bar IS the division sign.
  • 2.
    −9 = −9/1 — any integer over 1.
  • 3.
    7/0 is undefined: it would have to be a number q with q × 0 = 7, but
    anything times 0 is 0. (0/7 = 0 — zero on TOP is fine.)
  • 4.
    −(5/8) = (−5)/8 = 5/(−8). One minus sign, three homes.
  • 5.
    −3/2 < −1/4 < 1/4 < 5/4. (Negatives come first, and −3/2 = −1 1/2 is
    farthest left on the number line.)
  • 6.
    True. Every integer n can be written as n/1 — and that's exactly what
    "rational number" means.
  • 7.
    GCF(12, 16) = 4 → (12 ÷ 4)/(16 ÷ 4) = 3/4.
  • 8.
    GCF(16, 24) = 8 → (16 ÷ 8)/(24 ÷ 8) = 2/3.
  • 9.
    GCF is 4 and the sign stays: −12/16 = −3/4.
  • 10.
    Two negatives cancel first: (−10)/(−16) = 10/16 = 5/8.
  • 11.
    GCF(18, 24) = 6 → (18 ÷ 6)x/(24 ÷ 6) = 3x/4. The x rides along.
  • 12.
    12x/(16x) = (12/16)(x/x) = (3/4)(1) = 3/4 (as long as x ≠ 0).
  • 13.
    Factor the top: 4x + 8 = 4(x + 2), so (4x + 8)/4 = x + 2.
  • 14.
    16 = 4 × 4, so multiply the top by 4 too: 3/4 = 12/16.
  • 15.
    Cross-multiply: 3·6 = 18 and 5·4 = 20. Since 18 < 20, we get
    3/4 < 5/6 — so 5/6 is bigger. (LCD check: 9/12 < 10/12.)
  • 16.
    Write as (−2)/3 and (−3)/4. Cross: (−2)·4 = −8 and (−3)·3 = −9.
    Since −8 > −9, we get −2/3 > −3/4 — so −2/3 is bigger (it's closer
    to 0).
  • 17.
    Cross: 5·12 = 60 and 7·8 = 56. Since 60 > 56, we get 5/8 > 7/12 —
    so 5/8 is bigger. (LCD check: 15/24 > 14/24.)
  • 18.
    Multiply both sides by 2 (positive — no flip): x < 10.
  • 19.
    Divide both sides by 3 (positive — no flip): x ≥ −4.
  • 20.
    Divide both sides by −4 — NEGATIVE, so flip: x < −2.
    Check x = −3: −4(−3) = 12 > 8 ✅
  • 21.
    Same bottom: 2/7 + 3/7 = 5/7.
  • 22.
    LCD 12: 10/12 − 3/12 = 7/12.
  • 23.
    LCD 6: −3/6 + 2/6 = −1/6.
  • 24.
    Same bottom: 3/4 − 5/4 = −2/4 = −1/2.
  • 25.
    LCD 6: 2x/6 + x/6 = 3x/6 = x/2.
  • 26.
    Same bottom: 5x/8 − x/8 = 4x/8 = x/2.
  • 27.
    LCD 4x: 1/x = 4/(4x) and 1/4 = x/(4x) → (x + 4)/(4x).
  • 28.
    Same bottom: 2/(3x) + 1/(3x) = 3/(3x) = 1/x (cancel the factor 3).
  • 29.
    (3·2)/(5·3) = 6/15 = 2/5. (Or cancel the 3s before multiplying.)
  • 30.
    Negative × positive = negative: (−2·3)/(3·8) = −6/24 = −1/4.
  • 31.
    Negative × negative = positive: (1·4)/(2·5) = 4/10 = 2/5.
  • 32.
    (x·x)/(3·2) = x²/6.
  • 33.
    (2/3)(2/3) = 4/9 — square the top AND the bottom.
  • 34.
    (1/2)(1/2)(1/2) = 1/8.
  • 35.
    Distribute to BOTH terms: (3/4)x + (3/4)(8) = (3/4)x + 6.
  • 36.
    (2x·3)/(3·4) = 6x/12 = x/2. (Or cancel: the 3s cancel, 2/4 = 1/2.)
  • 37.
    Keep, change, flip: 3/4 × 3/2 = 9/8 (= 1 1/8).
  • 38.
    Keep, change, flip: −2/5 × 5/1 = −10/5 = −2. (How many fifths fit
    in −2/5? Two of them — with a negative sign.)
  • 39.
    Keep, change, flip: (x/2)(6/x) = 6x/(2x) = 3 (x ≠ 0).
  • 40.
    Complex fraction: 1/2 ÷ 4 = 1/2 × 1/4 = 1/8.
  • 41.
    6 ÷ 2/3 = 6 × 3/2 = 18/2 = 9.
  • 42.
    Complex fraction: 3/5 ÷ 9/10 = 3/5 × 10/9 = 30/45 = 2/3.
  • 43.
    11 ÷ 4 = 2 remainder 3 → 2 3/4.
  • 44.
    9 ÷ 2 = 4 remainder 1, and the sign stays: −4 1/2.
  • 45.
    Multiply-add: (2·5 + 3)/5 = 13/5.
  • 46.
    The whole thing is negative: −(1·3 + 2)/3 = −5/3.
  • 47.
    17 ÷ 5 = 3 remainder 2 → 3 2/5.
  • 48.
    Twist: they're EQUAL — 2 1/3 = (2·3 + 1)/3 = 7/3. Two outfits,
    one amount.
  • 49.
    Multiply both sides by 5: x = 15.
  • 50.
    Multiply both sides by the reciprocal 4/3: x = 12 · 4/3 = 48/3 = 16.
  • 51.
    Multiply both sides by 3/2: x = −6 · 3/2 = −18/2 = −9.
  • 52.
    Subtract 1: x/2 = 5. Multiply by 2: x = 10.
  • 53.
    Add 3: (1/2)x = 4. Multiply by 2: x = 8.
  • 54.
    Subtract 2: (2/5)x = 4. Multiply by 5/2: x = 4 · 5/2 = 20/2 = 10.
  • 55.
    f(8) = (1/2)(8) + 3 = 4 + 3 = 7.
  • 56.
    f(−6) = (2/3)(−6) − 1 = −4 − 1 = −5.

Intermediate

  • 57.
    Factor the top: 6x + 9 = 3(2x + 3) → (6x + 9)/3 = 2x + 3.
  • 58.
    Factor the top: x² + 2x = x(x + 2) → x(x + 2)/x = x + 2 (x ≠ 0).
  • 59.
    Difference of squares: x² − 16 = (x + 4)(x − 4), so
    (x² − 16)/(x + 4) = x − 4 (x ≠ −4).
  • 60.
    Factor the top: 2x + 10 = 2(x + 5) → 2(x + 5)/(x + 5) = 2 (x ≠ −5).
  • 61.
    LCD 2x: 2/(2x) + 1/(2x) = 3/(2x).
  • 62.
    LCD 2x: 4/(2x) + 3/(2x) = 7/(2x).
  • 63.
    LCD 3x: 3/(3x) − x/(3x) = (3 − x)/(3x).
  • 64.
    LCD 4: (2(x + 1))/4 + (x − 1)/4 = (2x + 2 + x − 1)/4 = (3x + 1)/4.
    (The 2 must distribute to BOTH the x and the 1!)
  • 65.
    3x/(6x) = 3/6 = 1/2 (x ≠ 0).
  • 66.
    2x/(8x) = 2/8 = 1/4 (x ≠ 0).
  • 67.
    Keep, change, flip: (x/4)(12/x) = 12x/(4x) = 3 (x ≠ 0).
  • 68.
    Keep, change, flip: (x²/5)(10/x) = 10x²/(5x) = 2x (x ≠ 0).
  • 69.
    Clear with LCD 8: 8·(3/4)x − 8·(1/2) = 8·(5/8) → 6x − 4 = 5 →
    add 4: 6x = 9 → divide by 6: x = 9/6 = 3/2.
    Check: (3/4)(3/2) − 1/2 = 9/8 − 4/8 = 5/8 ✅
  • 70.
    Clear with LCD 6: 3x + 2x = 30 → 5x = 30 → x = 6.
    Check: 6/2 + 6/3 = 3 + 2 = 5 ✅
  • 71.
    Clear with LCD 12: 4x = 3x + 12 → subtract 3x: x = 12.
    Check: 12/3 = 4 and 12/4 + 1 = 4 ✅
  • 72.
    Subtract (3/4)x from both sides: 2 = x − (3/4)x = (1/4)x.
    Multiply by 4: x = 8.
    Check: (3/4)(8) + 2 = 6 + 2 = 8 ✅
  • 73.
    Multiply both sides by 2: x + 1 = 6 → subtract 1: x = 5.
  • 74.
    Multiply both sides by 5: 2x − 3 = 5 → add 3: 2x = 8 → x = 4.
  • 75.
    Add 1: x/3 < 3. Multiply by 3 (positive — no flip): x < 9.
  • 76.
    Subtract 4: −2x > 6. Divide by −2 — FLIP: x < −3.
    Check x = −4: −2(−4) + 4 = 8 + 4 = 12 > 10 ✅
  • 77.
    Subtract 3: (1/2)x ≤ 2. Multiply by 2 (positive — no flip): x ≤ 4.
  • 78.
    Multiply both sides by −4/3 — FLIP: x ≤ 6 · (−4/3) = −8.
    Check x = −8: −(3/4)(−8) = 6 ≥ 6 ✅ (equality counts: it's ≥)
  • 79.
    f(12) = (3/4)(12) + 1 = 9 + 1 = 10.
    f(−8) = (3/4)(−8) + 1 = −6 + 1 = −5.
  • 80.
    (2/5)x − 3 = 1 → add 3: (2/5)x = 4 → multiply by 5/2: x = 10.
  • 81.
    x/3 + 2 = 6 → subtract 2: x/3 = 4 → multiply by 3: x = 12.
  • 82.
    (5/2)x − 4 = 6 → add 4: (5/2)x = 10 → multiply by 2/5: x = 4.
  • 83.
    (2/3)(2/3)(2/3) = 8/27.
  • 84.
    (−3/4)(−3/4) = 9/16 — two negatives multiply to a positive.
  • 85.
    Top: x³ · x² = x⁵ (add the exponents: 3 + 2). Then x⁵/x⁴ = x
    (cancel four x's; one survives — as long as x ≠ 0).

Challenge

  • 86.
    Sample: (2/3)x + 2 = 6. Check: plug in x = 6 → (2/3)(6) + 2 =
    4 + 2 = 6 ✅ Another that works: (1/2)x + 1 = 4 (since 3 + 1 = 4).
    Yours is right if plugging in 6 makes both sides equal!
  • 87.
    (a) Clear: multiply every term by 6: 5x − 6 = 4 → add 6: 5x = 10 →
    x = 2.
    (b) Add 1 first: (5/6)x = 2/3 + 1 = 5/3. Multiply by the reciprocal
    6/5: x = (5/3)(6/5) = 30/15 = 2.
    Same answer both ways — most people find (a) shorter.
    Check: (5/6)(2) − 1 = 5/3 − 3/3 = 2/3 ✅
  • 88.
    Substitute x = (3/4)y into x + y = 7:
    (3/4)y + y = 7 → (3/4)y + (4/4)y = (7/4)y = 7 →
    multiply by 4/7: y = 4. Then x = (3/4)(4) = 3.
    Check: 3 + 4 = 7 ✅ and 3 = (3/4)(4) ✅
  • 89.
    Add the equations: (a + b) + (a − b) = 9 + 1 → 2a = 10 → a = 5.
    Back-substitute: 5 + b = 9 → b = 4.
    Check: 5 − 4 = 1 ✅
    Bonus: (5/4)(4) = 20/4 = 5 — yes, the larger IS 5/4 of the smaller!
  • 90.
    x = 3/5 or x = −3/5, written x = ±3/5. Two answers because squaring
    erases the sign: (3/5)² = 9/25 AND (−3/5)² = 9/25.
  • 91.
    (a) Side s satisfies s² = 16/9, so s = ±4/3 — but a length is
    positive: s = 4/3 m. (Check: (4/3)(4/3) = 16/9 ✅)
    (b) Perimeter = 4 sides: 4 · 4/3 = 16/3 m (= 5 1/3 m).
  • 92.
    One answer: −5/12, because −1/2 = −6/12 and −1/3 = −4/12, and
    −6/12 < −5/12 < −4/12. Another: −11/24, because −1/2 = −12/24 and
    −1/3 = −8/24, and −12/24 < −11/24 < −8/24. (Infinitely many work —
    between any two rational numbers there's always another!)
  • 93.
    Equivalents of 3/4: 3/4, 6/8, 9/12... have sums 7, 14, 21. Go
    negative: (−3)/(−4), (−6)/(−8)... have sums −7, −14. There it is:
    (−6)/(−8), because (−6) + (−8) = −14 and (−6)/(−8) = 3/4. ✅
  • 94.
    (a) The room is done when (2/5)·t = 1, so t = 1 ÷ 2/5 = 1 × 5/2 =
    5/2 = 2 1/2 hours.
    (b) In 3/4 hour: (2/5)(3/4) = 6/20 = 3/10 of the room.
  • 95.
    Average = sum ÷ 2, so the sum is 2 · 3/4 = 3/2. The other number:
    3/2 − 1/2 = 1. Check: (1 + 1/2) ÷ 2 = (3/2) ÷ 2 = 3/4 ✅
  • 96.
    Inside out: f(9) = (2/3)(9) = 6. Then f(6) = (2/3)(6) = 4.
    So f(f(9)) = 4.
  • 97.
    Sample (a): "A 2-meter ribbon is cut into pieces that are each 2/5 m
    long. How many pieces do you get?" → 2 ÷ 2/5 = 2 × 5/2 = 5 pieces.
    Sample (b): "Three-quarters of the class went on the field trip, and
    12 students went. How many students are in the class?" →
    (3/4)x = 12 → x = 12 · 4/3 = 16 students. Your problems may look
    totally different — if the division counts how many pieces fit and
    the equation says "3/4 of something is 12," you're right!
  • 98.
    Test value x = 2: (2 + 4)/2 = 6/2 = 3, but x + 2 = 4. Not equal —
    busted. Correct: (x + 4)/2 = x/2 + 4/2 = x/2 + 2. The classmate
    canceled as if 2 were a factor of the whole top — but you can only
    cancel FACTORS, never TERMS; the bottom 2 must divide every term.
  • 99.
    (a) 1/3 + 1/4 = 4/12 + 3/12 = 7/12 ✅
    (b) 1/8 + 1/4 = 1/8 + 2/8 = 3/8 ✅ (The trick: split 3/8 into
    1/8 + 2/8, then simplify the second piece.) The Egyptians would be
    proud.
  • 100.
    Sample equation: (2/5)x + 3 = 7. Solve: subtract 3 → (2/5)x = 4 →
    multiply by 5/2 → x = 20/2 = 10. Check: (2/5)(10) + 3 = 4 + 3 = 7 ✅
    Sample word problem: "Maya hiked 2/5 of a trail, then walked 3 more
    km back to the parking lot, covering 7 km in all. How long is the
    trail?" → (2/5)x + 3 = 7 → x = 10 km. Yours will be different — if
    solving gives a whole number and your story matches the equation,
    you nailed it.
