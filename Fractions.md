Lesson 1: Fractions Are Division — Meet the Rational Numbers
─────────────────────────────────────────────

📌 Key idea of this section:

        A fraction is division wearing a bar:  a/b  means  a ÷ b.
        Any number that can be written as a/b (with b ≠ 0) is a RATIONAL number.

The fraction bar is a division sign

What is 3 ÷ 4? Split 3 pizzas among 4 people: each person gets 3/4 of a pizza. The division problem 3 ÷ 4 and the fraction 3/4 are the same answer wearing two outfits:

        3 ÷ 4 = 3/4        7 ÷ 2 = 7/2        1 ÷ 3 = 1/3

The top number has a name — the numerator — and the bottom has a name — the denominator. (Memory trick: the denominator is down under, and it names the denomination — the size of the pieces.) Once you see the bar as division, a lot of mystery evaporates.

Every integer is secretly a fraction. 5 = 5/1, because 5 ÷ 1 = 5. Same with negatives: −7 = −7/1. Any number that can be written as a/b — a whole number on top, a nonzero whole number on the bottom — is called a rational number. ("Rational" comes from "ratio"!) Integers, fractions, and negative fractions are all rational numbers.

The minus sign has three homes

Where does a negative sign live in a fraction? In any of three places — and all three mean the same number:

        −(3/4)  =  (−3)/4  =  3/(−4)

Why? Because each one is a division with exactly one negative: (−3) ÷ 4 and 3 ÷ (−4) are both negative, since a negative divided by a positive (or a positive divided by a negative) is negative. One minus sign anywhere → the whole fraction is negative. Two minus signs → they cancel: (−3)/(−4) = 3/4, because negative ÷ negative = positive.

The one rule that can never break: b ≠ 0

The bottom of a fraction can be any number except zero. Why? The fraction 5/0 would have to mean 5 ÷ 0 — and 5 ÷ 0 would be a number q with q × 0 = 5. But anything times 0 is 0, never 5. No such q exists, so 5/0 is undefined — not a number at all. Flip it around and there's no problem: 0/5 = 0, because 0 = 0 × 5. Zero on top is fine; zero on the bottom is forbidden. This rule will follow you through all of algebra — whenever a variable shows up on the bottom, we'll whisper "as long as that bottom isn't zero."

Fractions on the number line — now with negatives

You may already know that 3/4 sits between 0 and 1: split the space from 0 to 1 into 4 equal hops and take 3. Negative fractions work the same way, mirrored to the left of 0. Where is −5/4? Since 5/4 = 1 + 1/4, the point −5/4 sits one quarter-hop to the LEFT of −1 — between −2 and −1, closer to −1.

There's always another fraction between two fractions

Here's a genuinely amazing fact about rational numbers: between any two of them, no matter how close, there is always another one. The trick: average them. The average of two numbers is their sum divided by 2 — and the average always sits exactly halfway between them.

        Between 1/3 and 1/2:
        Step 1: add them:        1/3 + 1/2 = 2/6 + 3/6 = 5/6
        Step 2: divide by 2:     5/6 ÷ 2 = 5/12
        Check: 1/3 = 4/12  <  5/12  <  6/12 = 1/2   ✅

No gaps, ever. Mathematicians call this property density — the rational numbers are dense.

✏️ Your Turn

(a) Write −7 as a fraction.
(b) Which is undefined, 0/6 or 6/0? Say why in one sentence.
(c) Use the averaging trick to find a fraction between 1/4 and 1/3.

Answers: (a) −7/1. (b) 6/0 is undefined — no number times 0 equals 6. (0/6 = 0, perfectly fine.) (c) 1/4 + 1/3 = 3/12 + 4/12 = 7/12; half of that is 7/24. Check: 1/4 = 6/24 < 7/24 < 8/24 = 1/3. ✅

Lesson 2: Equivalent Fractions — Simplify Anything (Even with x!)
─────────────────────────────────────────────

📌 Key idea of this section:

        Multiply or divide the top and bottom by the same NONZERO number —
        the value never changes. This works for numbers AND variables.

        3/4 = 6/8 = 12/16 = (3x)/(4x)

Why multiplying top and bottom keeps the value frozen

Take 1/2 of a pizza. Cut your half into 2 smaller pieces: same amount of pizza, now called 2/4. You doubled the pieces (the bottom) AND doubled what you have (the top). Multiplying top and bottom by the same number just renames the same amount. Dividing runs it backwards: 12/16 = (12 ÷ 4)/(16 ÷ 4) = 3/4. (Adding the same number to top and bottom does NOT work: 1/2 would become 2/3, a different number entirely. Only × and ÷ keep the value frozen.)

Simplifying in one move: the GCF

A fraction is in lowest terms when no number except 1 divides both the top and the bottom. The one-move shortcut: divide by the GCF — the Greatest Common Factor, the biggest number that divides both.

        12/16:   GCF(12, 16) = 4,  so  12/16 = (12 ÷ 4)/(16 ÷ 4) = 3/4

If you divide by a smaller shared factor, you just need more steps: 12/16 = 6/8 = 3/4. Same answer, slower road. The GCF is the express train.

Negative signs just come along

Simplifying never touches the sign:

        −12/16 = −3/4                (one minus sign stays one minus sign)
        (−12)/(−16) = 12/16 = 3/4    (two minus signs cancel first)

Now with variables!

A variable is a letter that stands for a number — one we don't know yet, or one that can change. Variables obey the same rules as numbers, so everything above still works:

        18x/24:   GCF(18, 24) = 6,  so  18x/24 = (18 ÷ 6)x/(24 ÷ 6) = 3x/4

The x simply rides along on top. And if x is on the bottom too, it can cancel — here's why, written out in full:

        12x/(16x) = (12/16) × (x/x) = (3/4) × 1 = 3/4

        (One condition: x ≠ 0, because then the bottom 16x would be 0 — forbidden!)

Factoring: the move that simplifies the big ones

Before the main example, one tool. The distributive property says that multiplying a sum works term by term:

        a(b + c) = ab + ac
        Check with numbers: 2(3 + 4) = 2·3 + 2·4 = 6 + 8 = 14, and 2·7 = 14 ✅

Running that rule BACKWARDS — pulling out what every term shares — is called factoring:

        4x + 8 = 4(x + 2)     because 4(x + 2) = 4x + 8 ✅

Now watch factoring simplify a fraction that looks unsimplifiable:

        (4x + 8)/4 = 4(x + 2)/4 = x + 2

We factored the top, then canceled the shared factor of 4. Key vocabulary: terms are things being added (4x and 8 are terms); factors are things being multiplied (4 and (x + 2) are factors). You can only cancel FACTORS — never terms. (That's Mistake 2 in Lesson 8!)

A peek at quadratics: the difference of squares

What's x²? Just x · x (read "x squared" — Lesson 5 has much more). Now multiply out (x + 3)(x − 3) — every term times every term, distributing twice:

        (x + 3)(x − 3) = x(x − 3) + 3(x − 3)     distribute (x + 3) across
                       = x² − 3x + 3x − 9         distribute x, then 3
                       = x² − 9                    −3x + 3x cancels!

The pattern a² − b² = (a + b)(a − b) is called the difference of squares, and it simplifies fractions like magic:

        (x² − 9)/(x + 3) = (x + 3)(x − 3)/(x + 3) = x − 3   (as long as x ≠ −3)

That's real Algebra II, and you just did it.

✏️ Your Turn

(b) Simplify (6x + 9)/3.  (Factor the top first: what do 6x and 9 share?)
(c) Simplify (x² − 25)/(x + 5).  (25 = 5² — difference of squares!)
(d) Which of these are the same value: −(5/8), (−5)/8, 5/(−8), (−5)/(−8)?

Answers: (a) GCF(18, 24) = 6 → 3x/4. (b) 6x + 9 = 3(2x + 3), so (6x + 9)/3 = 2x + 3. (c) x² − 25 = (x + 5)(x − 5), so the fraction equals x − 5 (as long as x ≠ −5). (d) The first three are all −5/8; the last one is +5/8 — two minus signs cancel.

Lesson 3: Comparing Fractions — Cross-Multiplication and the Inequality Flip
─────────────────────────────────────────────

📌 Key idea of this section:

        To compare a/b and c/d (with positive bottoms), cross-multiply:
        compare a·d against c·b. And in an inequality, multiplying or
        dividing by a NEGATIVE number flips the sign.

The old way: common denominators

Which is bigger, 2/3 or 3/5? The classic move: rewrite both with a common bottom — the LCD (least common denominator), which is the least common multiple of the bottoms. LCM(3, 5) = 15:

        2/3 = 10/15         3/5 = 9/15
        10/15 > 9/15,  so  2/3 > 3/5   ✅

The one-step shortcut: cross-multiplication

Look at what the common-bottom move actually compares. Using bottom 15 = 3·5:

        2/3 = (2·5)/(3·5) = (2·5)/15        3/5 = (3·3)/(3·5) = (3·3)/15

The bottoms match automatically — so the whole contest is between the two cross-products 2·5 = 10 and 3·3 = 9. That's the shortcut:

        To compare a/b and c/d (bottoms positive):  compute a·d and c·b.
        If a·d > c·b, then a/b > c/d.

One multiplication on each side, no LCD needed: 10 > 9, so 2/3 > 3/5. Done in one line.

Comparing with negatives

Move minus signs up into the tops first (Lesson 1!), then cross-multiply carefully:

        Which is bigger, −2/3 or −3/5?  Write them as (−2)/3 and (−3)/5.
        Cross-products:  (−2)·5 = −10   and   (−3)·3 = −9.
        −10 < −9  (with negatives, the bigger-looking number is smaller!)
        So −2/3 < −3/5.  Number-line check: −2/3 sits left of −3/5. ✅

Into algebra: solving inequalities

The symbols: < (less than), > (greater than), ≤ (less than or equal to), ≥ (greater than or equal to), ≠ (not equal to). An inequality with a variable asks: which numbers make this true?

        x/3 < 2
        Multiply both sides by 3 (positive, so the sign stays):   x < 6
        Check x = 6: 6/3 = 2 — not less than 2, correctly excluded.
        Check x = 3: 3/3 = 1 < 2 ✅

The famous flip

Here's the rule that trips up half the world. Start with a true fact and multiply both sides by −1:

        2 < 4   is true.  Multiply both sides by −1:  −2 ... −4.
        On the number line, −2 is to the RIGHT of −4, so  −2 > −4.

Multiplying by a negative reflects the number line — the order flips. So:

        THE RULE: multiplying or dividing both sides of an inequality
        by a negative number flips the sign (< becomes >, ≤ becomes ≥).

        −3x ≥ 12
        Divide both sides by −3 — negative! Flip:   x ≤ −4
        Check x = −5: −3(−5) = 15 ≥ 12 ✅
        Check x = 0: −3(0) = 0, and 0 ≥ 12 is false — correctly excluded. ✅

✏️ Your Turn

(a) Which is bigger, −5/6 or −7/8? (Cross-multiply!)
(b) Solve: x/4 ≤ −2.  (Multiplying by positive 4 — no flip.)
(c) Solve: −2x > 10.  (Careful...)

Answers: (a) Write as (−5)/6 and (−7)/8. Cross-products: (−5)·8 = −40 and (−7)·6 = −42. Since −40 > −42, we get −5/6 > −7/8. (b) Multiply both sides by 4: x ≤ −8. (c) Divide both sides by −2 and FLIP: x < −5. Check x = −6: −2(−6) = 12 > 10 ✅.

Lesson 4: Adding and Subtracting — LCD, Negatives, and Variables
─────────────────────────────────────────────

📌 Key idea of this section:

        You can only add pieces of the SAME size. Match the bottoms first —
        then add or subtract the TOPS only. The rule never changes,
        even with negative signs and variables on top.

Same bottoms: just count the pieces

        2/7 + 3/7 = 5/7

Two sevenths plus three sevenths is five sevenths — like 2 apples + 3 apples. The bottom never gets added: sevenths don't turn into fourteenths when you count them, any more than apples turn into oranges.

Negatives: the number line does the counting

        3/4 − 5/4 = −2/4 = −1/2

Three quarters minus five quarters goes two quarters below zero. And with an LCD (least common denominator — the least common multiple of the bottoms; LCM(2, 3) = 6):

        −1/2 + 1/3 = −3/6 + 2/6 = −1/6

Start at −3/6, hop 2/6 to the right, land at −1/6. Signs don't change the rule: match the bottoms, combine the tops — the tops are signed numbers now, so "combine" means add with signs.

Variables on top: like terms

        x/7 + 3x/7 = 4x/7

One x-seventh plus three x-sevenths is four x-sevenths. Pieces with the same letter part are called like terms, and you combine them by adding their coefficients — the numbers in front (here, 1 and 3).

Different bottoms with variables: the LCD still runs the show

        x/2 + x/3 = ?
        Step 1: LCD of 2 and 3:   6
        Step 2: rewrite each fraction:
                x/2 = 3x/6   (top and bottom × 3)
                x/3 = 2x/6   (top and bottom × 2)
        Step 3: combine the tops, keep the bottom:
                3x/6 + 2x/6 = 5x/6   ✅

When x lives on the bottom

What's the LCD of x and 2? Their least common multiple is 2x. Same three steps:

        1/x + 1/2 = ?
        Step 1: LCD:   2x
        Step 2: rewrite:
                1/x = 2/(2x)    (top and bottom × 2)
                1/2 = x/(2x)    (top and bottom × x)
        Step 3: combine:
                2/(2x) + x/(2x) = (x + 2)/(2x)   ✅

And one where the bottoms match already — watch it collapse:

        2/(3x) + 1/(3x) = 3/(3x) = 1/x   (cancel the shared factor 3)

Subtraction works identically — just subtract the tops, signs and all:

        5x/6 − x/4 = ?
        LCD of 6 and 4:   12
        5x/6 = 10x/12   (top and bottom × 2)
        x/4 = 3x/12     (top and bottom × 3)
        10x/12 − 3x/12 = 7x/12   ✅

✏️ Your Turn

(a) −2/3 + 1/2
(b) x/4 + x/8
(c) 1/x + 1/3   (LCD: 3x)

Answers: (a) LCD 6: −4/6 + 3/6 = −1/6. (b) LCD 8: 2x/8 + x/8 = 3x/8. (c) 1/x = 3/(3x) and 1/3 = x/(3x), so the sum is (x + 3)/(3x).

Lesson 5: Multiplying — Straight Across, with Exponents Peeking In
─────────────────────────────────────────────

📌 Key idea of this section:

        Top × top, bottom × bottom. No matching bottoms needed.
        Signs multiply, variables multiply, and repeated
        multiplication gives us exponents.

The friendliest operation, with signs

        2/3 × 3/4 = (2·3)/(3·4) = 6/12 = 1/2

Same as ever. Now the sign rules — multiplication makes them simple:

        negative × positive = negative:   (−2/3)(3/4) = −6/12 = −1/2
        negative × negative = positive:   (−2/3)(−3/4) = 6/12 = 1/2

Why is negative × negative positive? One-line intuition: a negative flips direction; two flips bring you back. (The opposite of the opposite of a number is the number itself.)

Canceling early still works — with variables too

        (2/3)(x/4) = 2x/12 = x/6

Or cancel first: the 2 on top and the 4 on the bottom share a factor of 2, leaving x/(3·2) = x/6. Same answer, smaller numbers. Canceling shared factors before multiplying is legal for exactly the same reason simplifying is: you're dividing the top and the bottom by the same number.

x times x: exponents arrive

        (x/2)(x/3) = (x·x)/(2·3) = x²/6

x² means x · x — read "x squared." x³ means x · x · x ("x cubed"). The little raised number is an exponent: it counts how many copies of the base get multiplied. This births the first exponent law:

        x² · x³ = (x·x)(x·x·x) = x⁵
        LAW: same base, ADD the exponents:  xᵃ · xᵇ = xᵃ⁺ᵇ

Powers of fractions square the top AND the bottom:

        (2/3)² = (2/3)(2/3) = 4/9
        (1/2)³ = (1/2)(1/2)(1/2) = 1/8
        (−3/4)² = (−3/4)(−3/4) = 9/16   (two negatives → positive!)

Feeding fractions through the distributive property

Remember from Lesson 2: a(b + c) = ab + ac. A fraction can be the "a":

        (2/3)(x + 6) = (2/3)·x + (2/3)·6 = (2/3)x + 4

Every term inside the parentheses gets multiplied — both the x AND the 6. (Forgetting the 6 is Mistake 6 in Lesson 8!)

Lesson 6: Dividing — Keep, Change, Flip (and This Time We Prove It)
─────────────────────────────────────────────

📌 Key idea of this section:

        Dividing by a fraction = multiplying by its reciprocal.
        KEEP the first, CHANGE ÷ to ×, FLIP the second.

        2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6

The reciprocal

The reciprocal of a fraction is the fraction flipped: the reciprocal of 4/5 is 5/4, and the reciprocal of −2/3 is −3/2 (the sign stays put!). The key fact:

        A fraction times its reciprocal is always 1:   (4/5)(5/4) = 20/20 = 1.

The move — and why it works

You know the move: 2/3 ÷ 4/5 = 2/3 × 5/4 = 5/6. But WHY does flipping work? Here is a full proof, with every step explained. Call the answer A:

        Let A = (a/b) ÷ (c/d).
        Step 1: Division undoes multiplication, so A is THE number with
                A · (c/d) = a/b.          (that sentence is what "÷" means)
        Step 2: Multiply both sides by d/c:
                A · (c/d) · (d/c) = (a/b) · (d/c)
        Step 3: (c/d)(d/c) = 1, so the left side collapses:
                A · 1 = (a/b)(d/c)
        Step 4: A · 1 = A, so:
                A = (a/b)(d/c)   ∎

Dividing by c/d gives exactly the same thing as multiplying by d/c — no exceptions, for any fractions with b, c, d ≠ 0. The little square ∎ means "proof complete." You just read a real mathematical proof!

Signs and variables come along

        −3/4 ÷ 2/3 = −3/4 × 3/2 = −9/8        (negative × positive = negative)

        (x/2) ÷ (x/3) = (x/2)(3/x) = 3x/(2x) = 3/2    (as long as x ≠ 0)

Complex fractions: fractions over fractions

A complex fraction is a fraction whose top or bottom is itself a fraction. The long bar is just division in disguise, so rewrite it as ÷ and keep-change-flip:

        (2/3)/(4/5) = 2/3 ÷ 4/5 = 2/3 × 5/4 = 5/6
        (3/4)/6     = 3/4 ÷ 6 = 3/4 × 1/6 = 3/24 = 1/8
        (2/3)/(x/6) = 2/3 ÷ x/6 = (2/3)(6/x) = 12/(3x) = 4/x   (x ≠ 0)

✏️ Your Turn

(a) −3/4 ÷ 1/2
(b) (x/5) ÷ (x/10)
(c) (2/5)/4   (complex fraction!)

Answers: (a) Keep, change, flip: −3/4 × 2/1 = −6/4 = −3/2. (b) (x/5)(10/x) = 10x/(5x) = 2. (c) 2/5 ÷ 4 = 2/5 × 1/4 = 2/20 = 1/10.

Lesson 7: Fractions in Action — Mixed Numbers, Equations, and f(x)
─────────────────────────────────────────────

📌 Key idea of this section:

        An equation is a balance: whatever you do to one side, do to the other.
        Fractions inside equations follow the same rule — and the reciprocal
        is the key that unlocks them.

First, a 60-second mixed-number refresher

A fraction with a bigger top than bottom (like 11/4) is called improper; the same amount written as a whole plus a leftover (2 3/4) is a mixed number. The bar is division, so divide:

        11/4:  11 ÷ 4 = 2 remainder 3   →   2 3/4
        Backwards (multiply-add):  2 3/4 = (2·4 + 3)/4 = 11/4

With negatives, the whole mixed number is negative: −9/2 = −4 1/2, which means −(4 + 1/2) — both parts sit below zero. And converting the other way: −1 2/3 = −(1·3 + 2)/3 = −5/3.

Equations: the balance rule

An equation is a sentence claiming two things are equal, like x/3 = 4. A solution is the value of x that makes it true. The one rule above all rules: whatever you do to one side, you must do to the other — otherwise the balance tips. We solve by undoing operations (× is undone by ÷, + by −), one legal move at a time.

One step: undo the division

        x/3 = 4
        x was divided by 3, so multiply BOTH sides by 3:
        x = 12
        Check: 12/3 = 4 ✅

One step: undo a fraction multiply (the reciprocal key!)

        (2/3)x = 10
        x was multiplied by 2/3, so multiply both sides by its reciprocal 3/2:
        x = 10 · (3/2) = 30/2 = 15
        (Why the reciprocal? Because (3/2)(2/3) = 1, and 1 · x = x.)
        Check: (2/3)(15) = 30/3 = 10 ✅

Two steps: undo in reverse order

        (2/3)x + 1 = 7
        Step 1: undo the +1 — subtract 1 from both sides:   (2/3)x = 6
        Step 2: undo the ×(2/3) — multiply both sides by 3/2:   x = 9
        Check: (2/3)(9) + 1 = 6 + 1 = 7 ✅

Reverse order means: peel off the LAST operation first. The +1 happened last, so it goes first.

Variables on both sides: clear the fractions!

        x/2 = x/3 + 1
        Big idea: multiply BOTH sides by the LCD (6) to clear every fraction:
        6·(x/2) = 6·(x/3) + 6·1        (every term gets multiplied — all three!)
        3x = 2x + 6
        Subtract 2x from both sides:    x = 6
        Check: 6/2 = 3  and  6/3 + 1 = 3 ✅

Clearing fractions turns a fraction equation into a whole-number equation. It's the single most useful trick in this lesson — but it only works if EVERY term gets multiplied.

Functions: meet f(x)

A function is a machine: feed it an input, it follows a fixed rule and hands back exactly one output. We name machines with letters like f or g, and we write f(x) — read "f of x" — for "the output when the input is x."

        f(x) = (3/4)x − 2

        Find f(8):   plug in 8:   f(8) = (3/4)(8) − 2 = 6 − 2 = 4
        Find f(−4):  plug in −4:  f(−4) = (3/4)(−4) − 2 = −3 − 2 = −5

        Solve f(x) = 1:  that means (3/4)x − 2 = 1
                         add 2 to both sides:   (3/4)x = 3
                         multiply by 4/3:       x = 4
        Check: f(4) = 3 − 2 = 1 ✅

Evaluating f at a number is plugging in. Solving f(x) = something is exactly the equation-solving you just learned. Two views, one machine.

✏️ Your Turn

(a) Solve: (2/5)x = 8
(b) Solve: x/3 − 2 = 1
(c) Let g(x) = (2/3)x + 1. Find g(6), then solve g(x) = 3.

Answers: (a) Multiply both sides by 5/2: x = 8 · 5/2 = 20. Check: (2/5)(20) = 8 ✅ (b) Add 2: x/3 = 3; multiply by 3: x = 9. (c) g(6) = (2/3)(6) + 1 = 4 + 1 = 5. And g(x) = 3 means (2/3)x + 1 = 3 → (2/3)x = 2 → x = 3.

Lesson 8: Watch Out! Common Mistakes (Honors Edition)
─────────────────────────────────────────────

📌 Keep the big ideas in sight:

        Match the bottoms to add. Go straight across to multiply.
        Flip the second to divide. Flip the INEQUALITY when you × or ÷ by a negative.

These six mistakes cost students points every single year — now in algebra flavors. Learn them now, and they can't catch you!

Mistake 1: Adding the bottoms

        1/2 + 1/3 = 2/5?   ❌
        The algebra twin:  x/2 + x/3 = x/5?   ❌

Catch it with a test value! Plug in x = 6: the left side is 3 + 2 = 5; the right side is 6/5 — nowhere close. Match the bottoms first: x/2 + x/3 = 3x/6 + 2x/6 = 5x/6. ✅

Mistake 2: Canceling TERMS instead of FACTORS

        (x + 2)/2 = x + 1?   ❌

You can't cancel the bottom 2 with the 2 inside a sum — the bottom divides the WHOLE top. Test x = 4: (4 + 2)/2 = 3, but 4 + 1 = 5. Busted. The honest split:

        (x + 2)/2 = x/2 + 2/2 = x/2 + 1   ✅

Canceling is fine only when the thing you cancel is a FACTOR of the entire top: (2x)/2 = x works, because the top is 2·x.

Mistake 3: Flipping the wrong fraction

        2/3 ÷ 4/5 = 3/2 × 4/5?   ❌

Keep, change, flip — flip the SECOND fraction, the one you're dividing by. The first stays exactly as it is: 2/3 ÷ 4/5 = 2/3 × 5/4 = 5/6. ✅ (Flipping BOTH is wrong too — one flip only!)

Mistake 4: Forgetting the inequality flip

        −2x < 6   →   x < −3?   ❌

Dividing both sides by −2 is dividing by a NEGATIVE — the sign must flip: x > −3. ✅ Check x = 0: −2(0) = 0 < 6 is true, and 0 > −3 is true — consistent. The wrong answer x < −3 would exclude 0!

Mistake 5: Losing the parentheses on a squared negative

        (−1/2)² = −1/4?   ❌

The exponent applies to EVERYTHING inside the parentheses: (−1/2)² = (−1/2)(−1/2) = 1/4. ✅ What IS negative is −(1/2)² = −(1/4) = −1/4 — without parentheses, the square lands on the 1/2 only. Parentheses decide who gets squared.

Mistake 6: Distributing to only one term

        (2/3)(x + 6) = (2/3)x + 6?   ❌

The multiplier must visit EVERY term: (2/3)(x + 6) = (2/3)x + (2/3)(6) = (2/3)x + 4. ✅ Test x = 3: (2/3)(3 + 6) = (2/3)(9) = 6, and the correct split gives 2 + 4 = 6 — but the wrong version gives 2 + 6 = 8.

Lesson 9: Review — The Big Picture (Plus Capstones)
─────────────────────────────────────────────

📌 Everything, one last time:

        Add/Subtract: match the bottoms, then combine the TOPS only
        Multiply: straight across — top × top, bottom × bottom
        Divide: keep, change, flip (that's multiplying by the reciprocal)
        Simplify: divide top and bottom by their GCF (or cancel shared factors)
        Solve: undo operations one legal move at a time — or clear fractions with the LCD
        Inequalities: × or ÷ by a negative flips the sign

The recap list

  · A fraction is division: a/b = a ÷ b. A rational number is anything writable as a/b with b ≠ 0.
  · A minus sign has three homes; two minus signs cancel: (−3)/(−4) = 3/4.
  · Zero on the bottom is forbidden — always.
  · Equivalent fractions: multiply or divide top and bottom by the same nonzero number — even by x.
  · Simplify with the GCF: 12/16 = 3/4. Or with factoring: (4x + 8)/4 = x + 2.
  · Compare by cross-multiplying: 2/3 vs 3/5 → 10 > 9 → 2/3 > 3/5.
  · Add/Subtract: LCD first, then the tops only — signs and variables included: x/2 + x/3 = 5x/6.
  · Multiply: straight across, cancel early if you can: (−2/3)(−3/4) = 1/2.
  · Exponents: xᵃ · xᵇ = xᵃ⁺ᵇ, and (2/3)² = 4/9.
  · Divide: keep, change, flip — and you saw the proof: 2/3 ÷ 4/5 = 2/3 × 5/4 = 5/6.
  · Equations: undo in reverse order, or clear fractions by multiplying every term by the LCD.
  · Functions: f(x) = (3/4)x − 2 is a machine; f(8) = 4.

The magic sentence (honors remix)

        Match the bottoms to add —
        go straight across to multiply —
        flip the second to divide —
        and clear the fractions to solve.

Say it out loud three times. That's the whole lesson in four lines.

Capstone 1: Two methods, one answer

Solve: (2/3)x + 2 = x − 2.  There's more than one legal road!

        Method 1 — clear the fraction first:
        Multiply both sides by 3:   2x + 6 = 3x − 6
        Subtract 2x from both sides:   6 = x − 6
        Add 6 to both sides:   x = 12

        Method 2 — collect the x's first:
        Subtract (2/3)x from both sides:   2 = x − (2/3)x − 2
        Combine like terms (x − (2/3)x = (1/3)x):   2 = (1/3)x − 2
        Add 2 to both sides:   4 = (1/3)x
        Multiply both sides by 3:   x = 12

        Check: (2/3)(12) + 2 = 8 + 2 = 10  and  12 − 2 = 10 ✅

Two different roads, same destination. In algebra that's normal — what matters is that every step is legal on both sides.

Capstone 2: Systems — two equations at once

A system of equations is two equations with two unknowns; a solution is a pair (x, y) that makes BOTH true at the same time.

        Method: substitution (replace x with what it equals)
        x + y = 5     and     x = (2/3)y
        Substitute into the first equation:   (2/3)y + y = 5
        Combine like terms ((2/3)y + (3/3)y):   (5/3)y = 5
        Multiply both sides by 3/5:   y = 3
        Then x = (2/3)(3) = 2
        Check: 2 + 3 = 5 ✅  and  2 = (2/3)(3) ✅

        Method: elimination (add the equations to make a variable vanish)
        a + b = 7     and     a − b = 3
        Add the left sides, add the right sides (equals + equals are equal):
        (a + b) + (a − b) = 7 + 3
        2a = 10   →   a = 5
        Back-substitute: 5 + b = 7, so b = 2
        Check: 5 − 2 = 3 ✅

Capstone 3: A peek at quadratics

        Solve: x² = 25/16
        (5/4)² = (5/4)(5/4) = 25/16 ✅
        But also (−5/4)² = (−5/4)(−5/4) = 25/16 ✅
        Two answers! We write x = ±5/4 (the symbol ± means "plus or minus").
        Squaring erases the sign — so an x² equation usually has TWO solutions.

        Geometry version: a square has area 9/4. Its side s satisfies s² = 9/4,
        so s = ±3/2 — but a LENGTH can't be negative, so s = 3/2.

        And one more peek: multiplying out (x + 2)(x + 3) by distributing:
        (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6.
        Undoing THAT — turning x² + 5x + 6 back into (x + 2)(x + 3) — is
        called factoring a quadratic, and it's waiting for you in Algebra II.

Why this matters

Fractions aren't a topic you finish — they're the water algebra swims in. Slope is rise ÷ run: a fraction. Probability is favorable ÷ total: a fraction. Every rate, every ratio, every equation with a coefficient — fractions. And you now own the machinery: signs, LCDs, reciprocals, clearing, undoing. That's real algebra, and you're doing it.

  87. (a) Clear: multiply every term by 6: 5x − 6 = 4 → add 6: 5x = 10 →
      x = 2.
      (b) Add 1 first: (5/6)x = 2/3 + 1 = 5/3. Multiply by the reciprocal
      6/5: x = (5/3)(6/5) = 30/15 = 2.
      Same answer both ways — most people find (a) shorter.
      Check: (5/6)(2) − 1 = 5/3 − 3/3 = 2/3 ✅
  88. Substitute x = (3/4)y into x + y = 7:
      (3/4)y + y = 7 → (3/4)y + (4/4)y = (7/4)y = 7 →
      multiply by 4/7: y = 4. Then x = (3/4)(4) = 3.
      Check: 3 + 4 = 7 ✅ and 3 = (3/4)(4) ✅
  89. Add the equations: (a + b) + (a − b) = 9 + 1 → 2a = 10 → a = 5.
      Back-substitute: 5 + b = 9 → b = 4.
      Check: 5 − 4 = 1 ✅
      Bonus: (5/4)(4) = 20/4 = 5 — yes, the larger IS 5/4 of the smaller!
  90. x = 3/5 or x = −3/5, written x = ±3/5. Two answers because squaring
      erases the sign: (3/5)² = 9/25 AND (−3/5)² = 9/25.
  91. (a) Side s satisfies s² = 16/9, so s = ±4/3 — but a length is
      positive: s = 4/3 m. (Check: (4/3)(4/3) = 16/9 ✅)
      (b) Perimeter = 4 sides: 4 · 4/3 = 16/3 m (= 5 1/3 m).
  92. One answer: −5/12, because −1/2 = −6/12 and −1/3 = −4/12, and
      −6/12 < −5/12 < −4/12. Another: −11/24, because −1/2 = −12/24 and
      −1/3 = −8/24, and −12/24 < −11/24 < −8/24. (Infinitely many work —
      between any two rational numbers there's always another!)
  93. Equivalents of 3/4: 3/4, 6/8, 9/12... have sums 7, 14, 21. Go
      negative: (−3)/(−4), (−6)/(−8)... have sums −7, −14. There it is:
      (−6)/(−8), because (−6) + (−8) = −14 and (−6)/(−8) = 3/4. ✅
  94. (a) The room is done when (2/5)·t = 1, so t = 1 ÷ 2/5 = 1 × 5/2 =
      5/2 = 2 1/2 hours.
      (b) In 3/4 hour: (2/5)(3/4) = 6/20 = 3/10 of the room.
  95. Average = sum ÷ 2, so the sum is 2 · 3/4 = 3/2. The other number:
      3/2 − 1/2 = 1. Check: (1 + 1/2) ÷ 2 = (3/2) ÷ 2 = 3/4 ✅
  96. Inside out: f(9) = (2/3)(9) = 6. Then f(6) = (2/3)(6) = 4.
      So f(f(9)) = 4.
  97. Sample (a): "A 2-meter ribbon is cut into pieces that are each 2/5 m
      long. How many pieces do you get?" → 2 ÷ 2/5 = 2 × 5/2 = 5 pieces.
      Sample (b): "Three-quarters of the class went on the field trip, and
      12 students went. How many students are in the class?" →
      (3/4)x = 12 → x = 12 · 4/3 = 16 students. Your problems may look
      totally different — if the division counts how many pieces fit and
      the equation says "3/4 of something is 12," you're right!
  98. Test value x = 2: (2 + 4)/2 = 6/2 = 3, but x + 2 = 4. Not equal —
      busted. Correct: (x + 4)/2 = x/2 + 4/2 = x/2 + 2. The classmate
      canceled as if 2 were a factor of the whole top — but you can only
      cancel FACTORS, never TERMS; the bottom 2 must divide every term.
  99. (a) 1/3 + 1/4 = 4/12 + 3/12 = 7/12 ✅
      (b) 1/8 + 1/4 = 1/8 + 2/8 = 3/8 ✅ (The trick: split 3/8 into
      1/8 + 2/8, then simplify the second piece.) The Egyptians would be
      proud.
  100. Sample equation: (2/5)x + 3 = 7. Solve: subtract 3 → (2/5)x = 4 →
      multiply by 5/2 → x = 20/2 = 10. Check: (2/5)(10) + 3 = 4 + 3 = 7 ✅
      Sample word problem: "Maya hiked 2/5 of a trail, then walked 3 more
      km back to the parking lot, covering 7 km in all. How long is the
      trail?" → (2/5)x + 3 = 7 → x = 10 km. Yours will be different — if
      solving gives a whole number and your story matches the equation,
      you nailed it.
