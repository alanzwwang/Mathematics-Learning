    Input x = 6. Output 26 means 5x − 4 = 26. Add 4 (undo the −4 layer): 5x = 30. Divide by 5 (undo the ×5 layer): x = 6. Check: f(6) = 30 − 4 = 26 ✅
  • 90.
    Sample answer: 2x + 3 = 17. How to build it: start with the answer 7, dress it in two layers — multiply by 2 to get 14, then add 3 to get 17 — and write the dressed-up form on the left: 2x + 3 = 17. Unwrapping it (subtract 3, divide by 2) must give 7 back, and it does. Any two layers work, so your equation may look different — verify yours by solving it!
  • 91.
    Sample answer: 3x + 2 = 2x − 2. Verify: left side: 3 × (−4) + 2 = −10; right side: 2 × (−4) − 2 = −10. Equal! ✅ To build one yourself, put some x's and a number on the left, different x's and a number on the right, chosen so that −4 balances them — then always verify by plugging in.
  • 92.
    Sample answer: x + 3 = x + 5. Why no x works: subtracting x from both sides leaves 3 = 5, which is false — the variable is gone, so nothing can ever fix it. Any equation where the x's cancel and the leftover sentence is false has no solution.
  • 93.
    Sample answer: 2(x + 1) = 2x + 2. Why every x works: distributing gives 2x + 2 = 2x + 2, and subtracting 2x leaves 2 = 2, which is true no matter what x is — both sides are the same expression in two costumes (an identity).
  • 94.
    x = 6 both ways. Method A: divide both sides by 6 → x − 2 = 4 → x = 6. Method B: distribute → 6x − 12 = 24 → add 12 → 6x = 36 → divide by 6 → x = 6. Both are legal because each step is the Golden Rule: dividing first undoes the outer layer, while distributing unwraps the parentheses first — two reverse orders that both end at x.
  • 95.
    x = 0 or x = 5. Subtract 5x: x² − 5x = 0. Factor: x(x − 5) = 0. A product is zero only when a factor is zero: x = 0 or x − 5 = 0. Check: 0² = 5 × 0 ✅ and 5² = 25 = 5 × 5 ✅ (Dividing by x would have stolen the x = 0 solution!)
  • 96.

  • 97.

  • 98.
    Equation: s² = 64, so s = ±8. The real answer is s = 8 meters. We reject s = −8 because a side length is a physical distance — it cannot be negative. The algebra offers two answers; the real world keeps one.
  • 99.
    Multiplying by −1 mirrors every number across zero on the number line, and the mirror swaps which side is bigger. Demonstration: 3 < 5 is true. Multiply both by −1: you get −3 and −5. On the number line −3 sits to the RIGHT of −5, so −3 is greater: −3 > −5. The only way to keep the statement true was to flip the sign. No flip, and you would be claiming −3 < −5, which is false.
  • 100.
    (a) Equation: 2w + 2(w + 4) = 36 (two widths plus two lengths make the perimeter, and the length is w + 4). (b) Distribute: 2w + 2w + 8 = 36. Combine like terms: 4w + 8 = 36. Subtract 8: 4w = 28. Divide by 4: w = 7. (c) Width = 7 cm, length = 7 + 4 = 11 cm. Check: 2 × 7 + 2 × 11 = 14 + 22 = 36 ✅
