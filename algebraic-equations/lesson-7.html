🛠️ Exponent Laws — and Your First Quadratics

📖 Lesson 7 of 12

📌 KEY IDEA

An exponent counts repeated multiplication: x³ = x · x · x. Exponents follow a small set of laws — and equations with x² finally get two answers.

The Language of Exponents

In x³, the x is the base and the little 3 is the exponent. The exponent tells you how many copies of the base get multiplied:

x³ = x · x · x
2⁴ = 2 · 2 · 2 · 2 = 16

Exponent Law 1: Multiplying Same Bases — Add the Exponents

x² · x³ = (x · x) · (x · x · x) = x⁵

Count the x's: two, then three more — five total. So the law is:

xᵃ · xᵇ = xᵃ⁺ᵇ

Worked mini-example: 2x² · 3x³ = (2 · 3) · (x² · x³) = 6x⁵. Multiply the coefficients, add the exponents.

Exponent Law 2: A Power of a Power — Multiply the Exponents

(x²)³ = x² · x² · x² = x⁶

Three groups of two x's is six x's. So:

(xᵃ)ᵇ = xᵃ·ᵇ

Careful — this is where students mix up Laws 1 and 2! x² · x³ = x⁵ (add), but (x²)³ = x⁶ (multiply). When in doubt, expand it out and count the x's.

Exponent Law 3: Dividing Same Bases — Subtract the Exponents

x⁵ ÷ x² = (x · x · x · x · x)/(x · x) = x³

Two x's on the bottom cancel two x's on top, leaving three. So:

xᵃ ÷ xᵇ = xᵃ⁻ᵇ   (as long as x ≠ 0 — dividing by zero is never allowed)

Exponent Law 4: The Zero Exponent

Watch the pattern as the exponent drops by 1 — each value divides by 2:

2³ = 8
2² = 4      (8 ÷ 2)
2¹ = 2      (4 ÷ 2)
2⁰ = 1      (2 ÷ 2)  ← the pattern demands it!

So any (nonzero) number to the zero power is 1: x⁰ = 1. Keep the pattern going one more step and you meet negative exponents:

2⁻¹ = 1/2,  2⁻² = 1/4,  and in general  x⁻ⁿ = 1/xⁿ

A negative exponent means "flip it into the denominator." It is not a negative number — 2⁻² is a positive 1/4!

Your First Quadratic: x² = 49

An equation with x² in it is called a quadratic equation. Here comes the big surprise:

x² = 49

What numbers, squared, give 49? Well, 7 × 7 = 49... but ALSO (−7) × (−7) = 49, because a negative times a negative is positive! So this equation has TWO solutions:

x = 7  or  x = −7,  which we write as  x = ±7

Check both: 7² = 49 ✅ and (−7)² = 49 ✅. Every x² = (positive number) equation comes with two answers. Never forget the negative one!

Worked Example 1: 3x² = 48

3x² ÷ 3 = 48 ÷ 3          divide both sides by 3 (Golden Rule)
x² = 16                   48 ÷ 3 = 16
x = ±4                    both 4² and (−4)² equal 16

Check: 3 × 4² = 3 × 16 = 48 ✅ and 3 × (−4)² = 48 ✅

Worked Example 2: x³ = −8

Cubes are different from squares: a cube keeps the sign of its base. (−2)³ = (−2)(−2)(−2) = −8, so:

x = −2                    the only solution

Check: (−2)³ = −8 ✅. One solution only — because no positive number cubes to a negative.

Worked Example 3: 3ᵏ = 81

The variable is UP in the exponent this time! Ask: how many 3's multiply to make 81?

3¹ = 3,  3² = 9,  3³ = 27,  3⁴ = 81   ← there it is
k = 4

Check: 3⁴ = 3 × 3 × 3 × 3 = 81 ✅
