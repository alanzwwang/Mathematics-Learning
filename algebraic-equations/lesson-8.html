🎨 Function Notation f(x) — Machines You Can Run Backwards

📖 Lesson 8 of 12

👋 Start123456789101112🏋️ Practice🏆 Quiz

📌 KEY IDEA

f(x) names a machine: put a number in, get a number out. f(4) means "the output when the input is 4." Solving f(x) = 16 means asking "which input gives output 16?"

Meet the Machine

A function is a rule that takes an input and produces exactly one output. We name functions with letters like f, g, and h, and we write the rule like this:

f(x) = 3x − 2

Read it out loud: "f of x equals 3x minus 2." It means: to get the output, multiply the input by 3 and subtract 2. HUGE warning: f(x) does NOT mean f times x! The parentheses here are not multiplication — they hold the input.

Running the Machine Forward: f(4)

To find f(4), replace every x in the rule with 4:

f(x) = 3x − 2             the rule
f(4) = 3 × 4 − 2          replace x with 4
f(4) = 12 − 2 = 10        multiply first, then subtract

Input 4, output 10. Done!

Running the Machine Backwards: f(x) = 16

Now the famous backwards problem. The output is 16 — what was the input? Translating f(x) = 16 with our rule gives an equation you already know how to solve:

3x − 2 = 16               the rule's output equals 16
3x = 18                   add 2 to both sides
x = 6                     divide both sides by 3

Check: f(6) = 3 × 6 − 2 = 16 ✅. The input was 6. Every "solve for x" you have ever done is secretly running a machine backwards!

A Squaring Machine: g(x) = x² − 5

g(3) = 3² − 5 = 9 − 5 = 4
g(−3) = (−3)² − 5 = 9 − 5 = 4

Two different inputs, same output! That is legal for a function (each input still gets exactly ONE output) — and it happens because squaring erases the minus sign. It is also why g(x) = 4 has two answers: x² − 5 = 4 gives x² = 9, so x = ±3.

When Two Machines Agree

Here is a preview of Lesson 10. Two functions:

f(x) = 2x + 1
g(x) = x + 7

For which input do both machines give the SAME output? Set the rules equal:

2x + 1 = x + 7            the outputs must match
x + 1 = 7                 subtract x from both sides
x = 6                     subtract 1 from both sides

Check: f(6) = 13 and g(6) = 13 ✅. At input 6, both machines say 13. You just solved your first system without knowing it!

✏️ Your Turn!

Let h(x) = 5x + 1. (a) Find h(3). (b) Find the input x that makes h(x) = 21.

👀 Show the answers

Answers: (a) h(3) = 5 × 3 + 1 = 16. (b) 5x + 1 = 21 → 5x = 20 → x = 4. Check: h(4) = 21 ✅
