# 📐 Mathematics Learning

**Version:** V.2.7

A personal library of math notes, from arithmetic all the way to complex analysis.

## What's inside

20 topics in four groups:

- **Foundations:** arithmetic, fractions and more
- **Algebra:** equations, linear functions, logarithms, exponential growth and more
- **Geometry:** geometry, trigonometry, fractal and non-Euclidean geometry and more
- **Advanced:** calculus, complex analysis, number theory, probability, logic and more

Start at `index.md`. It links to every topic.

## Read it online

This is a GitHub Pages site (Cayman theme), so each `.md` note turns into a web page.
