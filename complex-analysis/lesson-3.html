🎯 Adding and Subtracting — Pile by Pile

📖 Lesson 3 of 9

👋 Start123456789🏋️ Practice🏆 Quiz

📌 Key idea of this section

Add the real parts. Add the imaginary parts.
(a + bi) + (c + di) = (a + c) + (b + d)i

Apples and oranges

Think of 3 + 2i as two piles: 3 in the real pile, 2 in the imaginary pile. You can never merge the piles into one — 3 + 2i is already as simple as it gets, the same way "3 apples and 2 oranges" isn't 5 of anything.

But two complex numbers CAN be combined — pile by pile:

(2 + 3i) + (1 + 4i) = 3 + 7i

Real pile: 2 + 1 = 3. Imaginary pile: 3 + 4 = 7. That's the whole rule!

Fractions work too — pile by pile, exactly like the Fractions lesson:

(1/2 + i) + (3/2 + 2i) = 2 + 3i     (because 1/2 + 3/2 = 2)

Sliding arrows

Watch the same addition on the map, with arrows. Start at 0, walk the first arrow (right 2, up 3), then walk the second arrow from there (right 1, up 4). Where do you end up? Right 3, up 7 — the answer! Adding complex numbers is joining arrows tip to tail: a SLIDE across the map. Nothing spins, nothing stretches — you just end up somewhere new.

Subtracting is the same game, with signs to watch:

(5 + 2i) − (3 + 7i) = 2 − 5i

Real: 5 − 3 = 2. Imaginary: 2 − 7 = −5. Yes, imaginary parts can go negative — the pile can owe!

And every number has an opposite that cancels it back to zero: the opposite of 2 − 3i is −2 + 3i, because (2 − 3i) + (−2 + 3i) = 0. The opposite arrow is the same length, turned all the way around.
