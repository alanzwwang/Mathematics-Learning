The Probabilistic Method

Lesson 13 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

If Pr(a random object has property P) > 0, an object with property P exists.
Some value of a random variable is at least its expectation.

Erdős's lower bound for Ramsey numbers

Theorem 13.1 (Erdős, 1947). If C(n, k) 21 − C(k, 2) < 1, then R(k, k) > n. In particular R(k, k) > ⌊2k/2⌋ for every k ≥ 3.

Proof. Colour each edge of Kₙ red or blue independently with probability 1/2. A fixed set of k vertices is monochromatic with probability 2 · 2−C(k,2). By the union bound, the probability that some k-set is monochromatic is at most C(n, k) 21 − C(k,2) < 1, so some colouring has no monochromatic Kₖ. For n = ⌊2k/2⌋, use C(n, k) < nᵏ/k! ≤ 2k²/2/k!, so the bound is less than 2k²/2 · 21 − k²/2 + k/2/k! = 21 + k/2/k!, which is less than 1 for k ≥ 3 (it equals 22.5/6 ≈ 0.94 at k = 3, and each increase of k multiplies it by √2/(k + 1) < 1). ∎

The remarkable feature is that no explicit construction is known achieving R(k, k) > (1 + ε)ᵏ for any ε > 0. Finding one is a central open problem (Erdős offered $100), and explicit "Ramsey graphs" are closely related to randomness extractors in theoretical computer science.

Linearity of expectation

Expectation is linear even for dependent random variables, which makes it the method's most powerful tool.

Theorem 13.2. Every graph with m edges has a bipartite subgraph with at least m/2 edges.

Proof. Put each vertex independently on side A or B with probability 1/2. Each edge crosses with probability 1/2, so the expected number of crossing edges is m/2, and some partition achieves at least that. ∎

Theorem 13.3 (Szele, 1943). There is a tournament on n vertices with at least n!/2ⁿ⁻¹ Hamiltonian paths.

Proof. Orient each edge of Kₙ randomly. Each of the n! orderings of the vertices is a directed path with probability 2−(n−1), so the expected number of Hamiltonian paths is n!/2ⁿ⁻¹. ∎

Theorem 13.4 (Caro 1979, Wei 1981). Every graph G has an independent set of size at least ∑ᵥ 1/(deg(v) + 1).

Proof. Order the vertices uniformly at random, and let I be the set of vertices that precede all of their neighbours. I is independent, and v ∈ I with probability 1/(deg(v) + 1), since each of the deg(v) + 1 vertices of the closed neighbourhood is equally likely to come first. Take expectations. ∎ Applied to the complement, this implies Turán's theorem: a graph on n vertices with no Kᵣ₊₁ has at most (1 − 1/r)n²/2 edges.

The alteration method

Sometimes a random object is nearly good and can be repaired. For any n, colour Kₙ randomly as above and delete one vertex from each monochromatic k-set. The expected number deleted is C(n, k) 21 − C(k,2), so R(k, k) > n − C(n, k) 21 − C(k,2) for every n. Optimizing n improves Erdős's bound by a factor of about √2.

Property B

A hypergraph is 2-colourable (has property B) if its vertices can be coloured red and blue with no monochromatic edge. Erdős (1963) showed that every k-uniform hypergraph with fewer than 2k−1 edges is 2-colourable: in a random colouring each edge is monochromatic with probability 21−k, so the expected number of monochromatic edges is less than 1. The least number m(k) of edges in a non-2-colourable k-uniform hypergraph satisfies m(2) = 3 (a triangle) and m(3) = 7 (the Fano plane).

The Lovász local lemma

Union bounds waste information when bad events are rare and mostly independent. The local lemma exploits this.

Theorem 13.5 (Erdős–Lovász, 1975, symmetric form). Let A₁, …, Aₙ be events, each with Pr(Aᵢ) ≤ p, such that each Aᵢ is mutually independent of all but at most d of the others. If e p (d + 1) ≤ 1, then Pr(no Aᵢ occurs) > 0.

Applied to the monochromatic k-sets of a random colouring, the local lemma gives Spencer's bound R(k, k) > (√2/e)(1 + o(1)) k 2k/2, still the best known lower bound up to the constant factor. Applied to k-SAT, it shows that a formula in which every clause has exactly k literals and shares variables with at most 2ᵏ/e − 1 other clauses is satisfiable. Moser and Tardos (2010) made the lemma algorithmic: resampling the variables of violated events terminates quickly in expectation, so the objects it promises can actually be found.

Exercise

  • (a)
    In a uniformly random 2-colouring of the edges of K₁₀, what is the expected number of monochromatic K₄'s?
  • (b)
    Use the Caro–Wei bound to find a lower bound for the independence number of the 5-cycle C₅.
  • (c)
    Show that some tournament on 6 vertices has at least 23 Hamiltonian paths.
Show solution

Answers: (a) C(10, 4) · 21−6 = 210/32 = 105/16 = 6.5625. (b) ∑ 1/3 over five vertices gives 5/3, so α(C₅) ≥ 2, which is the true value. (c) The expectation is 6!/2⁵ = 720/32 = 22.5, so some tournament has at least 22.5 and hence, being an integer count, at least 23.
