Problem Set

60 problems

Overview12345678910111213ProblemsAssessment

The problems are grouped by difficulty. The core problems check fluency with the definitions and standard techniques; the advanced problems require a short proof or a multi-step computation; the challenge problems are of the kind found on graduate qualifying examinations. Numerical answers should be verified independently, and every proof should be written out in full.

Core (Problems 1–20)

  • 1.
    Prove directly from the definition ln x = ∫₁ˣ dt/t that ln(x/y) = ln x − ln y for x, y > 0.
  • 2.
    Evaluate ∫₁e³ dt/t and ∫1/eᵉ dt/t.
  • 3.
    Prove that ln x ≤ x/e for all x > 0, with equality only at x = e.
  • 4.
    Solve 3²ˣ⁻¹ = 5ˣ⁺¹ exactly, and give x to four decimal places.
  • 5.
    Compute log₈ 32 and log₂₇ 9 exactly.
  • 6.
    Evaluate limn→∞ (1 + 2/n)³ⁿ.
  • 7.
    Find the derivative of x1/x for x > 0 and its maximum value.
  • 8.
    Express log₄ 7 and log1/2 7 in terms of log₂ 7.
  • 9.
    Find the Maclaurin series of ln(1 − x²) up to the term in x⁶, and its radius of convergence.
  • 10.
    Use the series for ln(1 + x) to compute ln 1.1 to five decimal places, with an error bound.
  • 11.
    Compute the principal values Log(−2), Log(2i) and Log(−1 + i).
  • 12.
    Find all values of log(−4).
  • 13.
    Compute the principal value of 2ⁱ in the form a + bi, to four decimal places.
  • 14.
    Find ∫ x ln x dx.
  • 15.
    Evaluate ∫₁e (ln x)² dx.
  • 16.
    Compute the entropy, in bits, of a fair six-sided die.
  • 17.
    Under Benford's law, find the probability that the leading digit is 1 or 2.
  • 18.
    Find the discrete logarithm x ∈ {0, …, 9} with 2ˣ ≡ 9 (mod 11).
  • 19.
    An amplifier multiplies power by 250. Express its gain in decibels.
  • 20.
    Estimate H₁₀₀₀ using Hₙ ≈ ln n + γ + 1/(2n), and state the size of the next correction.

Advanced (Problems 21–45)

  • 21.
    Prove that ln is not a rational function on (0, ∞).
  • 22.
    Prove that the sequence (1 + 1/n)ⁿ⁺¹ is strictly decreasing.
  • 23.
    Prove that eˣ ≥ 1 + x for all real x, and deduce that (1 + x/n)ⁿ ≤ eˣ whenever n > −x.
  • 24.
    Prove that limx→0 (aˣ − 1)/x = ln a for every a > 0.
  • 25.
    Evaluate limx→∞ x (ln(x + 1) − ln x).
  • 26.
    Prove that (n!)1/n/n → 1/e.
  • 27.
    Evaluate ∑k≥1 1/(k·2ᵏ).
  • 28.
    Evaluate ∑n≥1 1/(n(2n + 1)).
  • 29.
    Use the artanh series to compute ln(5/4) to six decimal places.
  • 30.
    Let f(x) = ∏ₖ₌₁ⁿ (x − k). Compute f′(0)/f(0).
  • 31.
    Find the critical points of p(z) = (z − 1)(z − 2)(z − 4) and verify the Gauss–Lucas theorem.
  • 32.
    Let L be the branch of log on ℂ minus the closed positive imaginary axis {iy : y ≥ 0} with L(1) = 0. Find L(−1) and L(−i).
  • 33.
    Find all values of (1 + i)ⁱ, and the modulus and argument of the principal value.
  • 34.
    Evaluate ∮|z|=2 p′(z)/p(z) dz for p(z) = z⁵ + 3z + 1.
  • 35.
    Prove that ∫₀¹ ln(1 − x)/x dx = −π²/6, using ∑ 1/n² = π²/6.
  • 36.
    Prove that ∫₀∞ ln x/(1 + x²) dx = 0.
  • 37.
    Evaluate ∫₀¹ (x − 1)/ln x dx.
  • 38.
    Prove that H₂ₙ − Hₙ → ln 2, and deduce the value of the alternating harmonic series from it.
  • 39.
    Prove that ∑ₖ₌₂ⁿ 1/(k ln k) = ln ln n + O(1).
  • 40.
    Use Mertens' third theorem to estimate ∏p≤1000 (1 − 1/p), and compare with the true value 0.080965.
  • 41.
    Use Legendre's formula to find the exact power of 2 dividing C(20, 10).
  • 42.
    Use the prime number theorem to estimate the number of primes in the interval (10⁹, 10⁹ + 10⁶].
  • 43.
    Compute the entropy of the geometric distribution pₖ = 2⁻⁽ᵏ⁺¹⁾, k = 0, 1, 2, … .
  • 44.
    For p = (0.4, 0.3, 0.2, 0.1), compute H(p), the Shannon code lengths ⌈−log₂ pᵢ⌉, and the expected length of that code.
  • 45.
    Use the table in Lesson 13 to find log₅ 3 and log₅ 7 modulo 22, and use them to find log₅ 21.

Challenge (Problems 46–60)

  • 46.
    Prove that n(e − (1 + 1/n)ⁿ) → e/2.
  • 47.
    Let f: (0, ∞) → ℝ be continuous, and suppose that for every y > 0 the integral ∫ₓˣʸ f(t) dt is independent of x > 0. Prove that f(t) = c/t.
  • 48.
    Prove that ln is uniformly continuous on [1, ∞) but not on (0, 1].
  • 49.
    Prove that ∑n≥1 (−1)ⁿ (ln n)/n = γ ln 2 − (ln 2)²/2. You may use the result of Problem 52.
  • 50.
    Prove that ∑k≥1 cos(kθ)/k = −ln(2 sin(θ/2)) for 0 < θ < 2π.
  • 51.
    Prove that there is no continuous function s on the unit circle with s(z)² = z.
  • 52.
    Prove that ∑ₖ₌₁ⁿ (ln k)/k = (ln n)²/2 + C + o(1) for some constant C.
  • 53.
    Prove that ∏p≤n p < 4ⁿ for every n ≥ 1.
  • 54.
    Deduce from the prime number theorem that for every ε > 0 and all sufficiently large x there is a prime in (x, (1 + ε)x].
  • 55.
    How many decimal digits does 100! have? Find the answer with logarithms, and show that the number of digits of n! is asymptotic to n log₁₀ n.
  • 56.
    Find the smallest n ≥ 1 such that 2ⁿ has leading digit 7, and state the asymptotic proportion of such n.
  • 57.
    Prove that the joint entropy satisfies H(X, Y) ≤ H(X) + H(Y), with equality if and only if X and Y are independent.
  • 58.
    Solve 5ˣ ≡ 8 (mod 23) by Pohlig–Hellman, and explain why a group of order 2²⁵⁶ would be a poor choice for Diffie–Hellman.
  • 59.
    Carry out Diffie–Hellman with p = 23, g = 5, a = 6, b = 15, and verify that both parties obtain the same key.
  • 60.
    Prove that |Log(1 + z)| ≤ −ln(1 − |z|) for |z| < 1.
