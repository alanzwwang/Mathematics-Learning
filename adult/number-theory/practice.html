Problem Set

60 problems

Overview12345678910111213ProblemsAssessment

The problems are in three groups. The Core problems are computations that every reader should be able to carry out quickly with the tools of Lessons 1–13. The Advanced problems ask for short proofs and less routine calculations. The Challenge problems contain several classical theorems whose proofs are standard material in graduate courses; each is solvable with the methods of this course, but some require a genuinely new idea.

Core (Problems 1–20)

  • 1.
    Use the Euclidean algorithm to compute gcd(3587, 1819), and find integers x, y with 3587x + 1819y = gcd(3587, 1819).
  • 2.
    Find all integer solutions of 3587x + 1819y = 51.
  • 3.
    Compute φ(2026) and φ(5040). (1013 is prime.)
  • 4.
    Find the last two digits of 7²⁰²⁶.
  • 5.
    Compute 3²⁰²⁶ mod 13.
  • 6.
    Find the inverse of 97 modulo 1000.
  • 7.
    Compute τ(360), σ(360) and φ(360).
  • 8.
    Show that 3 is a primitive root modulo 31.
  • 9.
    Solve the system x ≡ 2 (mod 7), x ≡ 4 (mod 11), x ≡ 5 (mod 13).
  • 10.
    List the quadratic residues modulo 17.
  • 11.
    Evaluate the Legendre symbol (3/101).
  • 12.
    Show that −2 is a quadratic residue modulo an odd prime p if and only if p ≡ 1 or 3 (mod 8).
  • 13.
    Compute 97! mod 101.
  • 14.
    Show that 341 is a Fermat pseudoprime to base 2 but not to base 3.
  • 15.
    Show that 2821 is a Carmichael number.
  • 16.
    Compute r₂(325) by Jacobi's formula and list the representations 325 = x² + y² with x > y ≥ 0.
  • 17.
    Evaluate ∑d|360 μ(d) σ(360/d) without computing any σ values.
  • 18.
    Find the three smallest positive solutions of x² − 2y² = 1 and of x² − 2y² = −1.
  • 19.
    In RSA with p = 7, q = 17 and e = 5, find d, encrypt m = 10, and check the decryption.
  • 20.
    Run the Miller–Rabin test on n = 1105 with base 2, and use the result to find a factor of 1105.

Advanced (Problems 21–45)

  • 21.
    Prove that if gcd(a, b) = 1 then gcd(a + b, a − b) is 1 or 2.
  • 22.
    Prove that 30 divides n⁵ − n for every integer n.
  • 23.
    Prove that there are infinitely many primes p ≡ 3 (mod 4).
  • 24.
    Prove that there are infinitely many primes p ≡ 1 (mod 4).
  • 25.
    Prove that for n ≥ 2 the sum of the integers k with 1 ≤ k ≤ n and gcd(k, n) = 1 is nφ(n)/2.
  • 26.
    Find all solutions of x² ≡ 1 (mod 105).
  • 27.
    Let p be prime and m ≥ 1. Prove that ∑ₖ₌₁p−1 kᵐ ≡ −1 (mod p) if p − 1 | m, and ≡ 0 (mod p) otherwise.
  • 28.
    Evaluate (−42/61).
  • 29.
    Prove that if p ≡ 3 (mod 4) and q = 2p + 1 are both prime, then q | 2ᵖ − 1. Deduce that 2²⁵¹ − 1 is composite.
  • 30.
    Prove that σ(n) is odd if and only if n is a square or twice a square.
  • 31.
    Prove Liouville's identity ∑d|n τ(d)³ = (∑d|n τ(d))².
  • 32.
    Let λ(n) = (−1)Ω(n) be Liouville's function (not to be confused with the Carmichael function), where Ω(n) counts prime factors with multiplicity. Prove that ∑d|n λ(d) is 1 if n is a square and 0 otherwise.
  • 33.
    Find all n with φ(n) = 12, and prove that your list is complete.
  • 34.
    Show that 3 is a primitive root modulo 50.
  • 35.
    Find the smallest primitive root modulo 41.
  • 36.
    Prove that for a prime p ≥ 5, the product of the primitive roots modulo p (taken in {1, …, p − 1}) is ≡ 1 (mod p).
  • 37.
    Find the fundamental solution of x² − 14y² = 1 from the continued fraction of √14.
  • 38.
    Prove that if d has a prime factor q ≡ 3 (mod 4), then x² − dy² = −1 has no integer solutions.
  • 39.
    Prove that x² + y² = 3z² has no solution in integers other than x = y = z = 0.
  • 40.
    Find r₂(5525) and all representations 5525 = x² + y² with x > y > 0. (5525 = 5² · 13 · 17.)
  • 41.
    Show that 2047 is a strong pseudoprime to base 2 but that base 3 proves it composite.
  • 42.
    Prove that if 2ⁿ − 1 is prime then n is prime, and if 2ⁿ + 1 is prime (n ≥ 1) then n is a power of 2.
  • 43.
    Let p be an odd prime. Prove that every prime divisor q of 2ᵖ − 1 satisfies q ≡ 1 (mod 2p) and q ≡ ±1 (mod 8). Use this to factor 2¹¹ − 1.
  • 44.
    Solve x² ≡ −1 (mod 125) using Hensel's lemma.
  • 45.
    Compute λ(561), and prove that a composite n is a Carmichael number if and only if λ(n) | n − 1.

Challenge (Problems 46–60)

  • 46.
    Prove that (n − 1)! ≡ 0 (mod n) for every composite n > 4, and compute 3! mod 4.
  • 47.
    Prove that ∑ 1/p over all primes diverges. (Hint, after Erdős: suppose not, and count the integers n ≤ N all of whose prime factors are small.)
  • 48.
    Let n ≥ 3. Prove that every prime p with n < p ≤ 2n divides C(2n, n) exactly once, and that no prime p with 2n/3 < p ≤ n divides C(2n, n).
  • 49.
    Prove that for a prime p the sum of the primitive roots modulo p (taken in {1, …, p − 1}) is ≡ μ(p − 1) (mod p).
  • 50.
    Let Φₙ be the n-th cyclotomic polynomial. Prove that if a prime p ∤ n divides Φₙ(a) for an integer a, then ordₚ(a) = n. Deduce that there are infinitely many primes p ≡ 1 (mod n), for every n ≥ 2.
  • 51.
    Prove that the number Q(x) of squarefree integers n ≤ x satisfies Q(x) = (6/π²)x + O(√x).
  • 52.
    Determine the odd primes p ≠ 7 for which 7 is a quadratic residue, as congruence classes modulo 28.
  • 53.
    Prove Euler's discovery that 641 divides F₅ = 2³² + 1, and show that every prime divisor of Fₙ is ≡ 1 (mod 2ⁿ⁺¹).
  • 54.
    Find the fundamental solutions of x² − 29y² = −1 and x² − 29y² = 1. (√29 = [5; 2, 1, 1, 2, 10, …].)
  • 55.
    Prove that no integer of the form 4ᵃ(8b + 7), with a, b ≥ 0, is a sum of three squares.
  • 56.
    Prove Euler's theorem: every even perfect number has the form 2ᵖ⁻¹(2ᵖ − 1) with 2ᵖ − 1 prime.
  • 57.
    Complete the proof of Korselt's criterion: if n is a Carmichael number, then n is squarefree and p − 1 | n − 1 for every prime p | n.
  • 58.
    Factor n = 1022117 by Fermat's method (write n = a² − b²), and explain why RSA primes must not be too close together.
  • 59.
    For the RSA modulus n = 3233 = 61 · 53 with e = 17, compute λ(n) and the smallest positive d with ed ≡ 1 (mod λ(n)). Prove that this d decrypts correctly.
  • 60.
    Prove that every prime p ≡ 1 or 3 (mod 8) can be written as p = x² + 2y².
