Absolute values

An absolute value on a field K is a function |·|: K → [0, ∞) with |x| = 0 only for x = 0, |xy| = |x||y| and |x + y| ≤ |x| + |y|. It is non-archimedean if it satisfies the stronger ultrametric inequality |x + y| ≤ max(|x|, |y|), and archimedean otherwise. Two absolute values are equivalent if they define the same topology; equivalently, one is a positive power of the other. The trivial absolute value has |x| = 1 for all x ≠ 0.

For a prime p, the p-adic absolute value on ℚ is |x|p = p−vp(x), with |0|p = 0. Multiplicativity is vp(xy) = vp(x) + vp(y), and the ultrametric inequality is vp(x + y) ≥ min(vp(x), vp(y)) from Proposition 3.1. In this metric a number is small when it is divisible by a high power of p: |pk|p = p−k → 0, while |1/pk|p = pk. We write |·|∞ for the usual absolute value.

Ultrametric geometry

Ultrametric spaces look strange to archimedean eyes. If |x|p ≠ |y|p then |x + y|p = max(|x|p, |y|p) exactly, the equality case of Proposition 3.1; consequently every triangle is isosceles, with its two longest sides equal. Every point of an open ball is a centre of that ball, two balls are either disjoint or one contains the other, and every ball is both open and closed, so ℚ with |·|p is totally disconnected. A series ∑ ck converges in a complete ultrametric field if and only if ck → 0, a dramatic simplification compared with real analysis.

The product formula

Theorem 12.1. For every x ∈ ℚ×, |x|∞ · ∏p |x|p = 1, where the product is over all primes and has only finitely many factors different from 1.

Proof. Both sides are multiplicative in x, so it suffices to check x = −1 and x = q prime. For −1 every factor is 1. For x = q we have |q|∞ = q, |q|q = 1/q and |q|p = 1 for p ≠ q. ∎

The product formula expresses the unique factorisation of integers analytically. It is the prototype of the adelic point of view, in which all the completions of ℚ are treated simultaneously, and of the theory of heights in Diophantine geometry.

Ostrowski's theorem

Theorem 12.2 (Ostrowski, 1916). Every nontrivial absolute value on ℚ is equivalent either to |·|∞ or to |·|p for exactly one prime p.

Proof of the non-archimedean case. Suppose |·| is non-archimedean and nontrivial. Then |n| = |1 + ⋯ + 1| ≤ 1 for every integer n. If |n| = 1 for all nonzero integers, multiplicativity would make |·| trivial on ℚ; so the set I = {n ∈ ℤ : |n| < 1} is a nonzero ideal of ℤ (closed under addition by the ultrametric inequality, and under multiplication by integers because |m| ≤ 1). It is proper since |1| = 1, and prime since |ab| = |a||b| < 1 forces |a| < 1 or |b| < 1. Hence I = pℤ for a prime p. Writing n = pv m with p ∤ m, we have |m| = 1 and |n| = |p|v. Setting |p| = p−α with α > 0, |n| = (p−v)α = |n|pα for every integer n, and by multiplicativity for every rational. ∎

Sketch of the archimedean case. Let m, n ≥ 2 be integers. Writing mk in base n with at most 1 + k log m/log n digits, each of absolute value at most n, gives |m|k ≤ (1 + k log m/log n)·n·max(1, |n|)k log m/log n. Taking k-th roots and letting k → ∞,

|m| ≤ max(1, |n|)log m / log n.

If |·| is archimedean, some integer has |n| > 1 (otherwise the ultrametric inequality would hold), and the inequality then forces |n| > 1 for all n ≥ 2; applying it in both directions gives |m|1/log m = |n|1/log n. Hence |n| = nα for a constant 0 < α ≤ 1, so |·| = |·|∞α.

The completions ℚp

Completing ℚ with respect to |·|∞ gives ℝ. Completing with respect to |·|p gives the field ℚp of p-adic numbers, introduced by Hensel in 1897. By Ostrowski's theorem these are all the completions of ℚ. The closed unit ball ℤp = {x ∈ ℚp : |x|p ≤ 1} is a ring, the p-adic integers, isomorphic to the inverse limit of the rings ℤ/pkℤ. Every x ∈ ℚp has a unique expansion

x = ∑k ≥ −N dk pk,    dk ∈ {0, 1, …, p − 1},

convergent because its terms tend to 0. Familiar identities hold in a new form:

1/(1 − p) = 1 + p + p² + p³ + ⋯,        −1 = (p − 1) + (p − 1)p + (p − 1)p² + ⋯.

In ℚ₂ the geometric series gives −1/3 = 1/(1 − 4) = 1 + 4 + 16 + ⋯, that is, the 2-adic digits of −1/3 are …010101, and 1/3 = 1 + (−2/3) = 1 + 2 + 2³ + 2⁵ + ⋯ has digits …101011. As promised in Lesson 4, a p-adic number is rational if and only if its digit sequence is eventually periodic.

Hensel's lemma and local–global principles

Theorem 12.3 (Hensel's lemma). Let f ∈ ℤp[x] and a ∈ ℤp with f(a) ≡ 0 (mod p) and f′(a) ≢ 0 (mod p). Then there is a unique α ∈ ℤp with f(α) = 0 and α ≡ a (mod p).

The proof is Newton's method: αk+1 = αk − f(αk)/f′(αk) converges p-adically, the error being squared at every step. For example, −1 is a square modulo 5 (2² = 4 ≡ −1) and f′(2) = 4 ≢ 0, so √−1 exists in ℤ₅; the successive approximations are 2, 7, 57, … modulo 5, 25, 125, …, because 7² + 1 = 50 and 57² + 1 = 3250 = 26·125. By contrast √2 ∉ ℚ₅, since 2 is not a square modulo 5, while √2 ∈ ℚ₇ because 3² ≡ 2 (mod 7).

The p-adic fields are the setting for local–global principles. The Hasse–Minkowski theorem states that a quadratic form over ℚ represents 0 nontrivially over ℚ if and only if it does so over ℝ and over every ℚp. For cubic equations the principle fails: Selmer (1951) showed that 3x³ + 4y³ + 5z³ = 0 has nontrivial solutions in ℝ and in every ℚp but none in ℚ. The study of this failure leads to Tate–Shafarevich groups and to the deepest open problems about rational points, such as the conjecture of Birch and Swinnerton-Dyer.

Exercise

  • (a)
    Compute |x|v for x = 63/550 at v = ∞, 2, 3, 5, 7, 11, and verify the product formula.
  • (b)
    Find the 2-adic expansion of −1/3 and check it by adding 1/3.
Show solution

Answers: (a) 63 = 3²·7 and 550 = 2·5²·11, so |x|∞ = 63/550, |x|2 = 2, |x|3 = 1/9, |x|5 = 25, |x|7 = 1/7, |x|11 = 11, and all other factors are 1. The product is (63/550)·2·(1/9)·25·(1/7)·11 = (63/550)·(550/63) = 1. (b) −1/3 = 1/(1 − 4) = 1 + 4 + 4² + ⋯, with digits …010101. Adding 1/3, with digits …101011, digit by digit with carries: 1 + 1 = 10 gives 0 carry 1; then 0 + 1 + 1 = 10 gives 0 carry 1; and so on, every digit becoming 0 with a carry that runs off to infinity. The sum is 0, as it should be.
