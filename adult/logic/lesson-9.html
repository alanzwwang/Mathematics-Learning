Compactness and the Löwenheim–Skolem Theorems

Lesson 9 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

Compactness: a set of first-order sentences with arbitrarily large finite models has an infinite model.
Downward LS: a countable theory with an infinite model has a countable model.
Upward LS: a theory with an infinite model has models of every infinite cardinality κ ≥ |L|.

Compactness and its first consequences

Theorem 9.1 (Compactness). A set Σ of first-order sentences has a model iff every finite subset of Σ has a model.

The first application shows that finiteness is not first-order. Let λₙ be the sentence ∃x₁ … ∃xₙ ⋀ xᵢ ≠ xⱼ (the conjunction over all i < j) saying that there are at least n elements.

Corollary 9.2. If Σ has arbitrarily large finite models, it has an infinite model. Consequently the class of finite structures, and the class of finite groups, are not axiomatisable by any set of first-order sentences.

Proof. Every finite subset of Σ ∪ {λₙ : n ≥ 1} mentions only finitely many λₙ and is satisfied by a sufficiently large finite model of Σ. A model of the whole set is infinite. If a set Φ axiomatised the finite structures, Φ would have arbitrarily large finite models and hence an infinite one. ∎

Similarly, connectedness of graphs, being a torsion group, and being a well-order are not first-order axiomatisable. For well-orders: if Φ axiomatised them, add constants c₀, c₁, … and the sentences cₙ₊₁ < cₙ; every finite subset is satisfied in ℕ by interpreting finitely many cₙ as a decreasing finite sequence, and a model of everything is a linear order with an infinite descending sequence.

Nonstandard models of arithmetic

Let Th(𝔑) be the set of sentences true in the standard model 𝔑 = (ℕ, 0, S, +, ·, <). Add a constant c and consider Th(𝔑) ∪ {c > S(S(…S(0)…)) : n ∈ ℕ}, where the n-th sentence has n copies of S. Every finite subset is satisfied in 𝔑 by interpreting c as a large number. So there is a model 𝔐 of Th(𝔑) containing an element greater than every numeral: a nonstandard model of true arithmetic. Skolem constructed one explicitly in 1934.

Such a model looks like this: an initial copy of ℕ, followed by densely ordered copies of ℤ with neither a first nor a last copy. Indeed, if a is nonstandard then so is ⌊a/2⌋ (smaller copy) and 2a (larger copy), and between a and b in different copies lies ⌊(a + b)/2⌋, in a third copy. Since the order type of the copies is a dense linear order without endpoints, a countable nonstandard model has order type ω + ζ·η, where ω is ℕ, ζ is ℤ and η is ℚ. Tennenbaum's theorem (1959) adds that in no countable nonstandard model of Peano arithmetic is either + or · computable.

Nonstandard analysis

The same method applied to Th(ℝ, +, ·, <, every function and relation on ℝ) produces an elementary extension *ℝ containing a positive element ε smaller than every 1/n. Abraham Robinson (1961) showed that the infinitesimal calculus of Leibniz can be developed rigorously inside *ℝ: f is continuous at a iff f(x) − f(a) is infinitesimal whenever x − a is.

The Löwenheim–Skolem theorems

Let 𝔄 ⊆ 𝔅 be L-structures with 𝔄 a substructure of 𝔅. 𝔄 is an elementary substructure, 𝔄 ≼ 𝔅, if for every formula φ(x⃗) and tuple a⃗ from A, 𝔄 ⊨ φ[a⃗] iff 𝔅 ⊨ φ[a⃗].

Lemma 9.3 (Tarski–Vaught test). A substructure 𝔄 ⊆ 𝔅 is elementary iff for every formula φ(x⃗, y) and every a⃗ from A: if 𝔅 ⊨ ∃y φ[a⃗, y], then 𝔅 ⊨ φ[a⃗, b] for some b ∈ A.

Proof. Necessity is clear. For sufficiency, prove 𝔄 ⊨ φ[a⃗] iff 𝔅 ⊨ φ[a⃗] by induction on φ; only the ∃ step needs the hypothesis, which supplies a witness inside A. ∎

Theorem 9.4 (Downward Löwenheim–Skolem; Löwenheim 1915, Skolem 1920). Let 𝔅 be an L-structure and X ⊆ B. Then there is 𝔄 ≼ 𝔅 with X ⊆ A and |A| ≤ |X| + |L| + ℵ₀.

Proof. Choose Skolem functions: for each formula φ(x⃗, y), a function fφ on B that picks a witness b with 𝔅 ⊨ φ[a⃗, b] whenever one exists. Let A be the closure of X under all fφ (and the interpretations of the function symbols). A is a union of countably many stages, each of size at most |X| + |L| + ℵ₀, it is a substructure, and it passes the Tarski–Vaught test by construction. ∎

Theorem 9.5 (Upward Löwenheim–Skolem, Tarski–Vaught). If Σ has an infinite model, then for every cardinal κ ≥ |L| + ℵ₀, Σ has a model of cardinality exactly κ.

Proof. Add κ new constants cα and the sentences cα ≠ cβ for α ≠ β. Every finite subset is satisfied in the given infinite model, so by compactness (in the form for languages of size κ) there is a model of size at least κ. Apply Theorem 9.4 with X the set of interpretations of the cα to obtain a model of size exactly κ. ∎

Skolem's paradox

ZFC proves that there are uncountable sets. If ZFC is consistent, then by Theorem 9.4 it has a countable model M. Inside M there is an element r that M believes is the set of real numbers, and M ⊨ "r is uncountable"; yet externally r has only countably many members in M. There is no contradiction: "uncountable" means that no bijection with ω exists, and the bijections that exist externally are simply not elements of M. Uncountability is relative to the model.

Categoricity

A theory T is κ-categorical if it has, up to isomorphism, exactly one model of cardinality κ. By the Löwenheim–Skolem theorems no first-order theory with an infinite model is categorical outright. Examples: the theory DLO of dense linear orders without endpoints is ℵ₀-categorical by Cantor's back-and-forth argument but not 2ℵ₀-categorical; the theory of algebraically closed fields of a fixed characteristic is κ-categorical for every uncountable κ, since such a field is determined by its transcendence degree, but not ℵ₀-categorical.

Theorem 9.6 (Łoś–Vaught test). If T has no finite models and is κ-categorical for some κ ≥ |L| + ℵ₀, then T is complete.

Proof. If T ⊬ σ and T ⊬ ¬σ, then T ∪ {¬σ} and T ∪ {σ} both have models, necessarily infinite, and by Löwenheim–Skolem both have models of size κ. These are isomorphic by categoricity, yet one satisfies σ and the other ¬σ. ∎

So DLO is complete, which gives (ℚ, <) ≡ (ℝ, <); and ACF₀ is complete, which yields the Lefschetz principle: a first-order sentence in the language of rings is true in ℂ iff it is true in all algebraically closed fields of characteristic 0, iff it is true in algebraically closed fields of characteristic p for all sufficiently large primes p. A celebrated application is Ax's theorem (1968) that every injective polynomial map ℂⁿ → ℂⁿ is surjective, proved by checking it over the algebraic closures of the finite fields 𝔽ₚ, which are unions of finite fields, where injective maps of finite sets are surjective. Morley's categoricity theorem (1965) states that a countable theory categorical in one uncountable cardinal is categorical in all of them; it founded modern model theory.

Lindström's theorem (1969) characterises first-order logic as the strongest logic satisfying both compactness and the downward Löwenheim–Skolem property for countable sentences, which explains the central position of first-order logic.

Exercise

  • (a)
    Show that there is no first-order sentence in the language of graphs true exactly in the connected graphs.
  • (b)
    In a nonstandard model of Th(𝔑), let a be nonstandard. Show that a − 1 exists and is nonstandard.
  • (c)
    Why does the Łoś–Vaught test require "no finite models"?
Show solution

Answers: (a) Suppose Φ axiomatises connectedness. Add constants c, d and the sentences δₙ saying that there is no path of length ≤ n from c to d. Each finite subset of Φ ∪ {δₙ} is satisfied by a long path graph with c and d at its ends; a model of all of them is a connected graph in which c and d are joined by no finite path, a contradiction. (b) Th(𝔑) contains ∀x (x ≠ 0 → ∃y S(y) = x), and a ≠ 0, so a = S(b) for some b. If b were a standard number n, then a would be n + 1, also standard. (c) Without it, T could have a finite model and an infinite one; for example the empty theory in the empty language with equality is κ-categorical for every infinite κ, but it is not complete: it neither proves nor refutes "there are at least two elements".
