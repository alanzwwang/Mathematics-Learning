Key idea of this section

Syntax can be coded by numbers, and provability becomes a Σ₁ property of numbers.
Diagonal lemma: for every φ(x) there is σ with T ⊢ σ ↔ φ(⌜σ⌝).
G1: a consistent, c.e. theory containing Q is incomplete. G2: it does not prove Con(T).

Arithmetic and its axioms

Work in the language LA = {0, S, +, ·, <}. Write n̄ for the numeral S(S(…S(0)…)) with n copies of S. Robinson arithmetic Q (1950) consists of the seven axioms

S(x) ≠ 0                        S(x) = S(y) → x = y
x ≠ 0 → ∃y (x = S(y))           x + 0 = x            x + S(y) = S(x + y)
x · 0 = 0                       x · S(y) = x · y + x

(universally closed), with x < y defined as ∃z (S(z) + x = y) or taken as primitive with a suitable axiom. Peano arithmetic PA adds the induction scheme: for every formula φ(x, y⃗), the universal closure of φ(0) ∧ ∀x (φ(x) → φ(S(x))) → ∀x φ(x). Q is very weak — it does not prove x + y = y + x — but it is strong enough for incompleteness.

A formula is Δ₀ (bounded) if all its quantifiers are bounded, ∀x < t or ∃x < t; Σ₁ if it is ∃x⃗ ψ with ψ bounded.

Theorem 11.1 (Σ₁-completeness of Q). Every Σ₁ sentence true in 𝔑 is provable in Q.

Proof sketch. Q proves every true atomic and negated atomic sentence about numerals (by computing with the recursion axioms), and Q ⊢ ∀x (x < n̄ ↔ x = 0̄ ∨ … ∨ x = k̄), where k = n − 1, so bounded quantifiers reduce to finite conjunctions and disjunctions. A true ∃x ψ(x) has a true instance ψ(m̄), which Q proves, and ∃I finishes. ∎

Gödel numbering

Assign each symbol of LA a code number, and code a finite sequence (a₁, …, aₖ) of numbers by 2a₁+1 · 3a₂+1 · … · pₖaₖ+1, where pₖ is the k-th prime. Then formulas, and finite sequences of formulas such as derivations, receive Gödel numbers ⌜φ⌝ and ⌜D⌝. Inside formulas we write ⌜φ⌝ also for the numeral of the number ⌜φ⌝. The key point is that all the syntactic operations — "x codes a formula", "x codes the negation of the formula coded by y", "the substitution of the numeral for z into the formula coded by y has code x", "d codes a derivation from T of the formula coded by x" — are computable relations on numbers, indeed primitive recursive when T has a primitive recursive set of axioms.

Theorem 11.2 (Representability). Every computable relation R ⊆ ℕᵏ is representable in Q by a Σ₁ formula ρ(x⃗): if R(n⃗) then Q ⊢ ρ(n̄⃗), and if not R(n⃗) then Q ⊢ ¬ρ(n̄⃗). Every computable function f is represented by a formula ψf(x⃗, y) with Q ⊢ ∀y (ψf(n̄⃗, y) ↔ y = m̄), where m = f(n⃗).

The proof codes Turing machine computations (or, following Gödel, the recursive definitions of primitive recursive functions) using Gödel's β-function lemma: for every finite sequence a₀, …, aₙ there are c, d with aᵢ = c mod (1 + (i + 1)d) for all i ≤ n, by the Chinese remainder theorem. This lets a single pair of numbers code a sequence, using only + and ·.

Let T be a c.e. theory extending Q. Then "d codes a T-derivation of x" is a computable relation PrfT(d, x), and ProvT(x) := ∃d PrfT(d, x) is a Σ₁ formula with T ⊢ σ ⟹ 𝔑 ⊨ ProvT(⌜σ⌝) ⟹ Q ⊢ ProvT(⌜σ⌝).

The diagonal lemma

Lemma 11.3 (Diagonal or fixed-point lemma; Gödel, Carnap). For every formula φ(x) with one free variable there is a sentence σ such that Q ⊢ σ ↔ φ(⌜σ⌝).

Proof. Let diag be the computable function sending the code of a formula χ(x) to the code of χ(⌜χ⌝), and let δ(x, y) represent it. Put ψ(x) := ∃y (δ(x, y) ∧ φ(y)), let m = ⌜ψ⌝, and let σ := ψ(m̄). Then diag(m) = ⌜σ⌝, so Q ⊢ ∀y (δ(m̄, y) ↔ y = ⌜σ⌝), and therefore Q ⊢ σ ↔ ∃y (y = ⌜σ⌝ ∧ φ(y)) ↔ φ(⌜σ⌝). ∎

The sentence σ says, in a precise arithmetical sense, "I have property φ". It is a formalised version of the liar sentence, but with provability in place of truth there is no paradox, only incompleteness.

The first incompleteness theorem

Theorem 11.4 (Gödel 1931, Rosser 1936). Let T be a consistent, computably axiomatisable theory extending Q. Then there is a sentence GT such that T ⊬ GT and T ⊬ ¬GT.

Proof (Gödel's version, under the assumption that T is ω-consistent, or simply sound). Apply the diagonal lemma to ¬ProvT(x) to get G with T ⊢ G ↔ ¬ProvT(⌜G⌝). If T ⊢ G, then T ⊢ ProvT(⌜G⌝) by Σ₁-completeness and T ⊢ ¬ProvT(⌜G⌝) by the fixed point, so T is inconsistent. Hence T ⊬ G. Therefore no n is the code of a derivation of G, so T ⊢ ¬PrfT(n̄, ⌜G⌝) for every n by representability. If T ⊢ ¬G, then T ⊢ ∃d PrfT(d, ⌜G⌝), so T would prove an existential statement while refuting each instance: T would be ω-inconsistent, contradicting the assumption. ∎

Rosser's trick removes ω-consistency: diagonalise instead on the formula "for every derivation of x there is a shorter derivation of the negation of x". Then for consistent T neither the Rosser sentence nor its negation is provable. Note also that G is true in 𝔑 whenever T is consistent, since it asserts its own unprovability, which holds.

A computability-theoretic proof

A proof of a weaker form via Lesson 10 is instructive. Suppose T is c.e., sound (all its theorems true in 𝔑) and contains Q. The set K is Σ₁-definable: e ∈ K iff 𝔑 ⊨ κ(ē) for a Σ₁ formula κ. If T decided every sentence κ(ē), then, being sound, T ⊢ ¬κ(ē) iff e ∉ K, so the complement of K would be c.e. (enumerate the theorems of T), contradicting Theorem 10.2. Hence there is some e ∉ K with T ⊬ ¬κ(ē): a true Π₁ sentence that T does not prove. Moreover the set of true sentences of arithmetic is not c.e., and not even arithmetically definable.

Tarski's undefinability theorem

Theorem 11.5 (Tarski 1933/36). There is no formula True(x) of LA such that 𝔑 ⊨ True(⌜σ⌝) ↔ σ for every sentence σ.

Proof. Apply the diagonal lemma to ¬True(x): we obtain λ with 𝔑 ⊨ λ ↔ ¬True(⌜λ⌝), and with True this gives 𝔑 ⊨ λ ↔ ¬λ. ∎

Truth is not arithmetically definable, whereas provability is (it is Σ₁). Since the two notions have different definability properties, they cannot coincide: this is the shortest route to the incompleteness of every arithmetically definable sound theory.

The second incompleteness theorem

Let Con(T) be the sentence ¬ProvT(⌜0 = 1⌝). The Hilbert–Bernays–Löb derivability conditions, valid for PA and for every c.e. theory containing it (with the natural formalisation of ProvT), are:

D1:  if T ⊢ φ, then T ⊢ Prov(⌜φ⌝)
D2:  T ⊢ Prov(⌜φ → ψ⌝) → (Prov(⌜φ⌝) → Prov(⌜ψ⌝))
D3:  T ⊢ Prov(⌜φ⌝) → Prov(⌜Prov(⌜φ⌝)⌝)

D3 is formalised Σ₁-completeness, and its verification is the technical heart of the theorem.

Theorem 11.6 (Gödel 1931). If T is a consistent c.e. extension of PA, then T ⊬ Con(T).

Proof. Let G satisfy T ⊢ G ↔ ¬Prov(⌜G⌝). From T ⊢ G → ¬Prov(⌜G⌝) and D1, D2 one gets T ⊢ Prov(⌜G⌝) → Prov(⌜¬Prov(⌜G⌝)⌝). By D3, T ⊢ Prov(⌜G⌝) → Prov(⌜Prov(⌜G⌝)⌝). Since T proves that a formula and its negation together yield 0 = 1, D1 and D2 give T ⊢ Prov(⌜G⌝) → Prov(⌜0 = 1⌝), that is, T ⊢ Con(T) → ¬Prov(⌜G⌝), hence T ⊢ Con(T) → G. If T ⊢ Con(T), then T ⊢ G, contradicting the first theorem. ∎

The theorem ended Hilbert's programme in its original form: a consistency proof for arithmetic or analysis cannot be carried out in a weaker, finitary system that is itself formalisable in PA. Gentzen (1936) proved Con(PA) in primitive recursive arithmetic augmented by transfinite induction up to the ordinal ε₀ = sup{ω, ωω, ωωω, …}, which locates exactly the strength of PA.

Löb's theorem (1955), proved by the same method, says that if T ⊢ Prov(⌜φ⌝) → φ, then T ⊢ φ. It answers Henkin's question about the sentence asserting its own provability: such a sentence is provable.

Natural independent statements

For two decades the only known independent statements of arithmetic were metamathematical. Paris and Harrington (1977) found a strengthened finite Ramsey theorem that is true but unprovable in PA, and Kirby and Paris (1982) showed the same for Goodstein's theorem, that every Goodstein sequence (write n in hereditary base b, replace b by b + 1, subtract 1, repeat) eventually reaches 0. Both are proved by transfinite induction up to ε₀.

Exercise

  • (a)
    Compute the Gödel number of the sequence (1, 0, 2) under the coding 2a₁+1 · 3a₂+1 · 5a₃+1.
  • (b)
    Why does the first incompleteness theorem not apply to Th(𝔑), the set of all true sentences?
  • (c)
    Does the second incompleteness theorem show that PA might be inconsistent?
Show solution

Answers: (a) 2² · 3¹ · 5³ = 4 · 3 · 125 = 1500. (b) Th(𝔑) is consistent and complete, but it is not computably enumerable, so the hypothesis "computably axiomatisable" fails. (c) No. It shows only that the consistency of PA cannot be proved by means formalisable in PA itself. PA is consistent because 𝔑 is a model of it, an argument that uses the set ℕ and the notion of truth in 𝔑, which go beyond PA.
