Problem Set

60 problems

Overview12345678910111213ProblemsAssessment

The problems are grouped by difficulty. The Core problems check fluency with the definitions and the basic results; the Advanced problems require short proofs or careful calculations; the Challenge problems are substantial theorems, several of them classical, and are best attempted after the whole course.

Core (Problems 1–20)

  • 1.
    How many rows does the truth table of a formula in 5 atoms have? Up to logical equivalence, how many formulas are there in the 3 atoms p, q, r?
  • 2.
    Decide whether ((p → q) ∧ (q → r)) → (p → r) is a tautology.
  • 3.
    Decide whether (p → q) ∨ (q → p) is a tautology, and comment on its meaning.
  • 4.
    Give the full DNF of p ⊕ q ⊕ r (exclusive or) and state how many terms it has.
  • 5.
    Give a CNF equivalent to p ↔ q.
  • 6.
    Express ¬p, p ∨ q and p ∧ q using only ↓ (NOR).
  • 7.
    Prove that {∧, ∨, →} is not functionally complete.
  • 8.
    Give a natural deduction derivation of φ ∧ ψ → ψ ∧ φ.
  • 9.
    Give a natural deduction derivation of ¬(φ ∨ ψ) ⊢ ¬φ ∧ ¬ψ.
  • 10.
    Give a resolution refutation of {{p}, {¬p, q}, {¬q, r}, {¬r}}.
  • 11.
    Apply the Horn marking algorithm to: facts p, r; rules p → q, q ∧ r → s, s ∧ t → u; goal clause ¬s ∨ ¬q. Is the set satisfiable?
  • 12.
    Find the free variables of ∃x (P(x, y) ∧ ∀y Q(y, z)) ∨ R(x).
  • 13.
    Decide which of these sentences are true in (ℕ, <): (i) ∀x ∃y (y < x); (ii) ∃x ∀y ¬(y < x); (iii) ∀x ∃y (x < y ∧ ∀z ¬(x < z ∧ z < y)).
  • 14.
    Write a sentence in the empty language (with equality) that is true exactly in the structures with exactly two elements.
  • 15.
    Put ∃x P(x) → ∀y Q(y) into prenex form.
  • 16.
    Give the Skolem normal form of ∀x ∃y ∀z ∃w R(x, y, z, w).
  • 17.
    Using the coding (a₁, a₂, a₃) ↦ 2a₁+1 · 3a₂+1 · 5a₃+1, compute the code of (2, 1, 1), and decode the number 360.
  • 18.
    Prove that there is no algorithm deciding, for a given e, whether φₑ(0) is defined.
  • 19.
    Compute the ordinals 3 + ω · 2 and ω · 2 + 3. Are they equal?
  • 20.
    Prove in ZF that there is no set containing every singleton {x}.

Advanced (Problems 21–45)

  • 21.
    Count the binary Boolean functions that are monotone, and list them.
  • 22.
    Show that the number of self-dual Boolean functions of n variables is 22ⁿ⁻¹. Evaluate it for n = 3.
  • 23.
    Show that the number of affine Boolean functions of n variables is 2ⁿ⁺¹. Evaluate it for n = 3.
  • 24.
    Prove that {¬, ↔} is not functionally complete.
  • 25.
    Is {M, ¬} functionally complete, where M is the ternary majority function?
  • 26.
    Put ¬((p → q) ∧ ¬(r ∨ ¬p)) into negation normal form and simplify it to a single clause.
  • 27.
    Prove that every DNF of x₁ ⊕ x₂ ⊕ x₃ has at least 4 terms.
  • 28.
    Apply the Tseitin transformation to (p ∧ q) ∨ r, introducing a ↔ (p ∧ q) and b ↔ (a ∨ r). How many clauses result?
  • 29.
    Derive ∃x ∀y R(x, y) → ∀y ∃x R(x, y) and show by a counterexample that the converse is not valid.
  • 30.
    Prove that ∀x (P(x) ∨ ψ) ≡ ∀x P(x) ∨ ψ when x is not free in ψ, and show that the condition is necessary.
  • 31.
    Show that if the eigenvariable condition on ∀I were dropped, one could derive P(y) ⊢ ∀x P(x), and explain why this would contradict soundness.
  • 32.
    Let σ be a sentence in the language of rings true in every field of characteristic 0. Prove that σ is true in every field of characteristic p for all sufficiently large primes p.
  • 33.
    Prove that the class of torsion groups (every element has finite order) is not first-order axiomatisable.
  • 34.
    Show that the class of infinite structures is axiomatisable by a set of sentences but not by a single sentence.
  • 35.
    Decide whether F = (x ∨ y) ∧ (¬x ∨ y) ∧ (¬y ∨ z) ∧ (¬z ∨ x) ∧ (¬x ∨ ¬z) is satisfiable, using the implication graph.
  • 36.
    Which of the following sets are computable? (i) {e : φₑ(3) = 5}; (ii) {e : the machine coded by e has at most 10 states}; (iii) {e : φₑ halts on input 0 within 1000 steps}.
  • 37.
    Prove that Fin = {e : the domain of φₑ is finite} is not computable.
  • 38.
    Show that K ≤ H and H ≤ K by many-one reductions.
  • 39.
    Let BB(n) be the maximum number of steps made by an n-state Turing machine (fixed alphabet {0, 1}) that halts on the blank tape. Prove that BB is not computable.
  • 40.
    Prove that there is a sentence σ with PA ⊢ σ ↔ Prov(⌜σ⌝), and determine whether PA proves σ.
  • 41.
    Prove, using Tarski's theorem and the representability of the theorems of PA, that Th(𝔑) ≠ {σ : PA ⊢ σ}.
  • 42.
    Assume PA is consistent. Prove that PA + ¬Con(PA) is consistent, that it is not sound, and that it is ω-inconsistent.
  • 43.
    A CNF has three clauses, of lengths 5, 4 and 6. How many new variables and how many clauses does the 3-SAT splitting produce for them?
  • 44.
    Apply the CLIQUE reduction to (x ∨ y ∨ z) ∧ (¬x ∨ ¬y ∨ z): give the number of vertices, the number of edges and the clique size sought, and exhibit a clique.
  • 45.
    Compute (ω + 1) · 2 and 2 · (ω + 1).

Challenge (Problems 46–60)

  • 46.
    Show that the ternary Boolean functions definable from the atoms using only ∧ and ∨ are exactly the monotone functions other than the two constants, and count them.
  • 47.
    Prove the Craig interpolation theorem for propositional logic: if ⊨ φ → ψ, then there is a formula θ, built from ⊤, ⊥ and atoms occurring in both φ and ψ, with ⊨ φ → θ and ⊨ θ → ψ.
  • 48.
    Derive König's lemma (every infinite, finitely branching tree has an infinite branch) from the compactness theorem for propositional logic.
  • 49.
    Prove the "if" direction of Post's theorem (Theorem 2.3).
  • 50.
    Prove that any two countable dense linear orders without endpoints are isomorphic.
  • 51.
    Let T∞ be the theory, in the empty language with equality, axiomatised by {λₙ : n ≥ 1}. Prove that T∞ is complete and decidable.
  • 52.
    Let 𝔐 be a nonstandard model of Th(𝔑). Prove that the set of standard elements is not definable in 𝔐, even with parameters (overspill).
  • 53.
    Prove Löb's theorem from the derivability conditions and the diagonal lemma.
  • 54.
    Prove that a consistent, complete, computably axiomatisable theory is decidable.
  • 55.
    Prove that the set of true Σ₁ sentences of arithmetic is c.e. but not computable.
  • 56.
    Suppose an oracle decides SAT. Show how to find a satisfying assignment of a satisfiable formula in n atoms with at most n oracle calls after the first, and conclude that if P = NP then satisfying assignments can be found in polynomial time.
  • 57.
    Prove that satisfiability of DNF formulas is in P, while deciding whether a DNF is a tautology is coNP-complete.
  • 58.
    Prove the Cantor–Schröder–Bernstein theorem without using the axiom of choice.
  • 59.
    Compute the Goodstein sequence starting at 3 until it reaches 0, and the first four terms of the Goodstein sequence starting at 4.
  • 60.
    Prove that (ℚ, <) is an elementary substructure of (ℝ, <), using the Tarski–Vaught test.
