Key idea of this section

Unrestricted comprehension {x : φ(x)} is inconsistent (Russell 1901).
ZFC: sets are built in stages; Separation, Power Set, Replacement, Choice.
Cantor: |P(X)| > |X|. CH is independent of ZFC (Gödel 1938, Cohen 1963).

Russell's paradox

Frege's Grundgesetze (1893, 1903) contained a principle equivalent to unrestricted comprehension: for every property φ(x) there is a set {x : φ(x)}. Russell observed in 1901, and wrote to Frege in 1902, that the property x ∉ x then yields R = {x : x ∉ x}, with R ∈ R iff R ∉ R. The theory is inconsistent. The paradox is a diagonal argument of exactly the same shape as Cantor's theorem, the halting problem and the Gödel sentence.

The axioms of ZFC

Zermelo (1908) proposed an axiomatisation, completed by Fraenkel and Skolem (1922) with Replacement and by von Neumann with Foundation. In the language {∈}:

  • 1.
    Extensionality: sets with the same elements are equal.
  • 2.
    Empty set: there is a set with no elements.
  • 3.
    Pairing: for all a, b there is {a, b}.
  • 4.
    Union: for every set a there is ⋃a, the set of members of members of a.
  • 5.
    Power Set: for every a there is P(a) = {x : x ⊆ a}.
  • 6.
    Separation (a scheme): for every set a and formula φ, {x ∈ a : φ(x)} exists.
  • 7.
    Replacement (a scheme): if φ(x, y) defines a function on a set a, its image {y : ∃x ∈ a φ(x, y)} is a set.
  • 8.
    Infinity: there is a set containing ∅ and closed under x ↦ x ∪ {x}.
  • 9.
    Foundation: every nonempty set has an ∈-minimal element.
  • 10.
    Choice: every set of nonempty sets has a choice function.

Separation only carves subsets out of existing sets, which blocks Russell's argument: applied to a set a it shows that {x ∈ a : x ∉ x} is not a member of a. Consequently there is no set of all sets. The intended picture is the cumulative hierarchy V(0) = ∅, V(α + 1) = P(V(α)), and V(λ) = the union of the V(α) for α < λ when λ is a limit; Foundation says that every set appears at some stage.

Ordinals

A set is transitive if every element of it is a subset of it. An ordinal is a transitive set well-ordered by ∈. Von Neumann's ordinals are 0 = ∅, 1 = {0}, 2 = {0, 1}, …, ω = {0, 1, 2, …}, ω + 1 = ω ∪ {ω}, and so on. Every well-ordered set is isomorphic to a unique ordinal, and the ordinals are themselves well-ordered by ∈; the collection of all ordinals is not a set (the Burali-Forti paradox, 1897). Transfinite induction and recursion over ordinals generalise induction and recursion over ℕ. Ordinal arithmetic is not commutative: 1 + ω = ω ≠ ω + 1, and 2 · ω = ω ≠ ω · 2 = ω + ω.

Cardinals

|X| = |Y| means there is a bijection, |X| ≤ |Y| an injection. The Cantor–Schröder–Bernstein theorem (provable without Choice) says |X| ≤ |Y| and |Y| ≤ |X| imply |X| = |Y|. With Choice every set is well-orderable (Zermelo 1904), so every set has a cardinality |X|, the least ordinal in bijection with X. The infinite cardinals are ℵ₀ = ω, ℵ₁, ℵ₂, …, ℵω, ….

Theorem 13.1 (Cantor 1891). For every set X, |X| < |P(X)|.

Proof. x ↦ {x} is an injection X → P(X). Suppose f : X → P(X) were surjective, and let D = {x ∈ X : x ∉ f(x)}, a set by Separation. Then D = f(d) for some d, and d ∈ D iff d ∉ f(d) = D. ∎

In particular |ℝ| = |P(ℕ)| = 2ℵ₀ > ℵ₀. Cardinal arithmetic of infinite cardinals is simple for sums and products — κ + λ = κ · λ = max(κ, λ) if one of them is infinite and neither is 0 — but exponentiation is deep.

The continuum hypothesis

CH asserts 2ℵ₀ = ℵ₁: every infinite set of reals is either countable or in bijection with ℝ. It was the first of Hilbert's 23 problems (1900). Gödel (1938) showed that if ZF is consistent, then so is ZFC + CH, by constructing the inner model L of constructible sets, in which both Choice and the generalised continuum hypothesis hold. Cohen (1963) invented forcing to show that if ZF is consistent, so is ZFC + ¬CH; indeed 2ℵ₀ can consistently be ℵ₂, or any ℵα with cofinality greater than ω (König's theorem forbids cofinality ω, so 2ℵ₀ ≠ ℵω). Cohen also showed that Choice is independent of ZF. By the second incompleteness theorem, ZFC cannot prove its own consistency, so these are relative consistency results: Con(ZF) → Con(ZFC + CH), and similarly for ¬CH.

Foundations

ZFC serves as the standard foundation of mathematics: essentially every theorem of ordinary mathematics can be formalised and proved in it, and the formal proofs can in principle be checked mechanically — a programme now realised in proof assistants such as Lean, Coq, Isabelle and Mizar. Gödel's theorems show that no such foundation can be complete or prove its own consistency; large cardinal axioms, such as the existence of inaccessible or measurable cardinals, form a hierarchy of ever stronger extensions of ZFC, linearly ordered by consistency strength in all known cases.

Exercise

  • (a)
    Show that there is no set of all sets, using only Separation.
  • (b)
    List the elements of the von Neumann ordinal 3, written in terms of ∅.
  • (c)
    Compute ω + 3 and 3 + ω as ordinals, and say whether they are equal.
Show solution

Answers: (a) If V were a set, Separation gives R = {x ∈ V : x ∉ x}, and R ∈ V since V contains all sets, so R ∈ R iff R ∉ R. (b) 3 = {0, 1, 2} = {∅, {∅}, {∅, {∅}}}. (c) 3 + ω is the order type of three points followed by a copy of ω, which is again ω. ω + 3 is ω followed by three points, which has a largest element, so ω + 3 ≠ ω = 3 + ω.
