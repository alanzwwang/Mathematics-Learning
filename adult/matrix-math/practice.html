Problem Set

60 problems

Overview123456789101112ProblemsAssessment

The problems are arranged in three tiers. The Core problems are computations that every reader should be able to carry out quickly and correctly by hand. The Advanced problems combine computation with proof and develop results used or quoted in the lessons. The Challenge problems are theorems of the kind found on graduate qualifying examinations; several of them complete proofs that the lessons deferred. Matrices are written row by row with semicolons separating rows.

Core (Problems 1–20)

  • 1.
    Compute det [ 1 2 0 ; 3 1 4 ; 0 5 2 ] by cofactor expansion, and check the result by row reduction.
  • 2.
    Find the reduced row echelon form, the rank and a basis of the null space of B = [ 1 2 1 3 ; 2 4 0 2 ; 3 6 1 5 ].
  • 3.
    Find the LU factorization of [ 2 3 ; 4 7 ].
  • 4.
    Find the LU factorization of A = [ 1 1 1 ; 2 3 5 ; 4 6 8 ] and use it to compute det A.
  • 5.
    The permutation σ ∈ S₅ has one-line notation 3 4 5 2 1, that is, σ(1) = 3, σ(2) = 4, σ(3) = 5, σ(4) = 2, σ(5) = 1. Count its inversions, write it as a product of disjoint cycles, and find sgn σ in two ways.
  • 6.
    Invert the upper unitriangular matrix [ 1 2 0 ; 0 1 3 ; 0 0 1 ].
  • 7.
    Use Cramer's rule to find y in the system 2x + y = 1, x + 3y + z = 0, y + 2z = 3, and then find the full solution.
  • 8.
    Find the eigenvalues and eigenvectors of [ 1 2 ; 2 −2 ].
  • 9.
    Find the eigenvalues and eigenspaces of [ 2 1 1 ; 1 2 1 ; 1 1 2 ].
  • 10.
    Use the Cayley–Hamilton theorem to compute the inverse of [ 2 1 ; 1 1 ].
  • 11.
    Show that A = [ 1 1 ; 0 1 ] is not diagonalizable, and compute Aⁿ for all n ≥ 1.
  • 12.
    Diagonalize A = [ 4 1 ; 2 3 ] and give a closed formula for Aⁿ.
  • 13.
    Apply the Gram–Schmidt process to (1, 0, 1), (1, 1, 0), (0, 1, 1) and write the QR factorization of the matrix with these columns.
  • 14.
    Find the least-squares line y = c₀ + c₁t through the points (−1, 0), (0, 1), (1, 3), (2, 4).
  • 15.
    Find the matrix of orthogonal projection onto the plane x + y + z = 0 in ℝ³, and project (1, 2, 6) onto it.
  • 16.
    Orthogonally diagonalize S = [ 5 2 ; 2 2 ].
  • 17.
    Show that T = [ 2 −1 0 ; −1 2 −1 ; 0 −1 2 ] is positive definite in two ways, and find its eigenvalues.
  • 18.
    Find the singular values of [ 1 1 ; 0 1 ].
  • 19.
    Find the stationary distribution of the Markov chain P = [ 0.8 0.2 0 ; 0.1 0.8 0.1 ; 0 0.4 0.6 ].
  • 20.
    Compute κ∞ of [ 1 2 ; 3 4 ] and κ₂ of [ 5 2 ; 2 2 ].

Advanced (Problems 21–45)

  • 21.
    Let A ∈ 𝔽m×n and B ∈ 𝔽n×p. Prove rank(AB) ≤ min(rank A, rank B) and Sylvester's rank inequality rank A + rank B − n ≤ rank(AB).
  • 22.
    Evaluate the Vandermonde determinant for the nodes 1, 2, 3, 4.
  • 23.
    Let Tn be the n × n tridiagonal matrix with 2 on the diagonal and −1 on the sub- and superdiagonals. Prove det Tn = n + 1.
  • 24.
    Prove that det [ A B ; 0 D ] = det A · det D for square blocks A and D.
  • 25.
    Let M be the n × n matrix with every diagonal entry equal to a and every off-diagonal entry equal to b. Find det M and the eigenvalues of M.
  • 26.
    Let A ∈ 𝔽m×n and B ∈ 𝔽n×m. Prove that λⁿ pAB(λ) = λm pBA(λ). Deduce that AB and BA have the same nonzero eigenvalues with the same algebraic multiplicities.
  • 27.
    Let u = (1, 1, 1)ᵀ. Use the Sherman–Morrison formula and the matrix determinant lemma to find (I + uuᵀ)⁻¹ and det(I + uuᵀ).
  • 28.
    The Laplacian of a graph is L = D − A, where D is the diagonal matrix of degrees and A is the adjacency matrix. Kirchhoff's matrix-tree theorem states that every cofactor of L equals the number of spanning trees. Use it to count the spanning trees of the complete graph K₄, and then of Kₙ, using the eigenvalues of L.
  • 29.
    Give two 4 × 4 matrices with the same characteristic polynomial and the same minimal polynomial that are not similar.
  • 30.
    Find the Jordan normal form of A = [ 5 4 2 1 ; 0 1 −1 −1 ; −1 −1 3 0 ; 1 1 −1 2 ], given that pA(λ) = (λ − 1)(λ − 2)(λ − 4)².
  • 31.
    N is a nilpotent 6 × 6 matrix with rank N = 3, rank N² = 1 and N³ = 0. Find its Jordan form and its minimal polynomial.
  • 32.
    Compute exp(tA) for A = [ 0 1 ; −1 0 ] and use it to solve x″ + x = 0 with x(0) = x₀, x′(0) = v₀.
  • 33.
    Let A² = A. Prove that A is diagonalizable with eigenvalues in {0, 1}, and that rank A = tr A.
  • 34.
    Prove that two commuting diagonalizable matrices are simultaneously diagonalizable.
  • 35.
    Find the QR factorization of [ 3 1 ; 4 7 ] with R having positive diagonal.
  • 36.
    Let A ∈ ℝm×n have full column rank and P = A(AᵀA)⁻¹Aᵀ. Prove that Pᵀ = P, P² = P, col(P) = col(A), and that I − P is the orthogonal projection onto null(Aᵀ).
  • 37.
    Prove that a normal matrix with real eigenvalues is Hermitian, and a normal matrix whose eigenvalues all have modulus 1 is unitary. Show by example that normality cannot be dropped.
  • 38.
    Let K be real skew-symmetric. Prove that the eigenvalues of K are purely imaginary, and that exp(K) is orthogonal with determinant 1.
  • 39.
    A is real symmetric with eigenvalues 10, 5, 1, and E is real symmetric with ‖E‖₂ ≤ 0.3. Locate the eigenvalues of A + E, and decide whether A + E is necessarily positive definite.
  • 40.
    For which real t is [ 1 t 0 ; t 1 t ; 0 t 1 ] positive definite?
  • 41.
    Compute the Cholesky factorization of [ 9 3 −6 ; 3 5 0 ; −6 0 14 ].
  • 42.
    Compute the pseudoinverse of A = [ 1 2 ; 2 4 ] and the minimum-norm least-squares solution of Ax = (1, 0)ᵀ.
  • 43.
    A 3 × 3 matrix A has singular values 5, 3, 1. Find ‖A‖₂, ‖A‖F, ‖A⁻¹‖₂, κ₂(A), and the errors of the best rank-one approximation in the spectral and Frobenius norms.
  • 44.
    For 0 < a ≤ 1 and 0 < b ≤ 1, let P = [ 1 − a a ; b 1 − b ]. Find Pⁿ in closed form and the stationary distribution, and show that Pⁿ converges unless a = b = 1.
  • 45.
    Prove the Gershgorin circle theorem: every eigenvalue of A lies in some disc |z − aii| ≤ ∑j≠i |aij|. Deduce that a strictly diagonally dominant matrix is invertible, and locate the eigenvalues of [ 4 1 0 ; 1 5 1 ; 0 1 6 ].

Challenge (Problems 46–60)

  • 46.
    Give a second proof of the Cayley–Hamilton theorem over ℂ: verify it for diagonalizable matrices and conclude by a density and continuity argument.
  • 47.
    Prove Hadamard's inequality |det A| ≤ ∏j ‖aj‖₂ for A = [ a₁ ⋯ aₙ ] ∈ ℂn×n, and determine the cases of equality.
  • 48.
    Prove the Frobenius-norm part of the Eckart–Young theorem. Hint: first prove Weyl's inequality for singular values, σi+j−1(X + Y) ≤ σi(X) + σj(Y).
  • 49.
    Let A ≥ 0 be irreducible. Prove that (I + A)n−1 > 0, and use Perron's theorem for (I + A)n−1 to show that ρ(A) is an algebraically simple eigenvalue of A with a positive eigenvector.
  • 50.
    Prove Gelfand's formula ρ(A) = limk→∞ ‖Ak‖1/k, valid for every matrix norm.
  • 51.
    Prove that det(exp A) = etr A for every A ∈ ℂn×n.
  • 52.
    Prove that every A ∈ ℂn×n is similar to its transpose Aᵀ.
  • 53.
    Prove the polar decomposition: every A ∈ ℂn×n can be written A = UP with U unitary and P positive semidefinite; P is unique, and U is unique when A is invertible.
  • 54.
    Prove that the Hilbert matrix Hn = (1/(i + j − 1)) is positive definite for every n, and compute det H₂ and det H₃.
  • 55.
    Prove that the number of invertible n × n matrices over the finite field with q elements is ∏k=0n−1 (qⁿ − qk). Evaluate it for n = 2, q = 3 and for n = 3, q = 2.
  • 56.
    Let Wn be the n × n matrix with 1 on the diagonal, −1 below the diagonal, 1 in the last column and 0 elsewhere. Show that Gaussian elimination with partial pivoting produces unn = 2n−1, so the growth factor is 2n−1.
  • 57.
    Let A be diagonalizable with eigenvalues |λ₁| > |λ₂| ≥ ⋯ ≥ |λₙ| and eigenvectors v₁, …, vₙ. Prove that if x₀ has a nonzero v₁-component, the power iteration xk = Ak x₀/‖Ak x₀‖ satisfies dist(xk, span v₁) = O(|λ₂/λ₁|k).
  • 58.
    Prove the Cauchy–Binet formula: for A ∈ 𝔽k×n and B ∈ 𝔽n×k with k ≤ n, det(AB) = ∑S det A:,S det BS,:, the sum over all k-element subsets S of {1, …, n}. Deduce that det(AAᵀ) ≥ 0 for real A.
  • 59.
    Prove Ky Fan's maximum principle: for Hermitian A with eigenvalues λ₁ ≥ ⋯ ≥ λₙ, λ₁ + ⋯ + λk = max tr(Q*AQ), the maximum over all Q ∈ ℂn×k with Q*Q = I.
  • 60.
    Prove the Cauchy interlacing theorem: if B is obtained from Hermitian A ∈ ℂn×n by deleting row i and column i, then λk(A) ≥ λk(B) ≥ λk+1(A) for k = 1, …, n − 1.
