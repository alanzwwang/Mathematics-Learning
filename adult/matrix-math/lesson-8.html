Adjoints and special classes of matrices

With the standard inner product, ⟨Ax, y⟩ = ⟨x, A*y⟩ for all x, y, so the conjugate transpose is the adjoint of A. A matrix is Hermitian (real symmetric, in the real case) if A* = A, unitary (real orthogonal) if U*U = I, skew-Hermitian if A* = −A, and normal if AA* = A*A. Hermitian, skew-Hermitian and unitary matrices are all normal. Unitary matrices preserve inner products, ⟨Ux, Uy⟩ = ⟨x, y⟩, hence lengths and angles; their eigenvalues have modulus 1.

Lemma 8.1. The eigenvalues of a Hermitian matrix are real, and eigenvectors belonging to distinct eigenvalues are orthogonal.

Proof. If Av = λv with v ≠ 0, then λ‖v‖² = ⟨Av, v⟩ = ⟨v, Av⟩ = λ̄‖v‖², so λ is real. If also Aw = μw with μ ≠ λ, then λ⟨v, w⟩ = ⟨Av, w⟩ = ⟨v, Aw⟩ = μ⟨v, w⟩ (μ is real), so ⟨v, w⟩ = 0. ∎

Schur triangularization

Theorem 8.2 (Schur, 1909). Every A ∈ ℂn×n is unitarily similar to an upper triangular matrix: A = UTU* with U unitary and T upper triangular. The diagonal of T consists of the eigenvalues of A, in any prescribed order.

Proof. Induct on n. Let u₁ be a unit eigenvector, Au₁ = λ₁u₁, and extend it to a unitary matrix U₁ = [ u₁ U′ ]. Then U₁*AU₁ = [ λ₁ w* ; 0 A′ ] for some vector w and some (n − 1) × (n − 1) matrix A′, because the first column of U₁*AU₁ is U₁*λ₁u₁ = λ₁e₁. By induction A′ = U₂T′U₂*, and U = U₁(1 ⊕ U₂) triangularizes A. ∎

Unlike the Jordan form, the Schur form is computed stably: it is the output of the QR algorithm of Lesson 12. If A is real with real eigenvalues, U may be taken real orthogonal; for general real A there is a real Schur form, quasi-triangular with 2 × 2 diagonal blocks for complex conjugate pairs.

The spectral theorem

Theorem 8.3 (Spectral theorem). A matrix A ∈ ℂn×n is normal if and only if A = UΛU* for some unitary U and diagonal Λ. In particular every Hermitian matrix is unitarily diagonalizable with real Λ, and every real symmetric matrix is orthogonally diagonalizable: A = QΛQᵀ with Q real orthogonal and Λ real.

Proof. If A = UΛU*, then AA* = UΛΛ̄U* = UΛ̄ΛU* = A*A. Conversely, let A be normal and write A = UTU* by Schur. Then T is normal as well. Compare the (1, 1) entries of TT* and T*T: the first is ∑j |t1j|² and the second is |t₁₁|², because the first column of T is t₁₁e₁. Hence t1j = 0 for j > 1. Deleting the first row and column leaves a normal upper triangular matrix, and induction shows T is diagonal. For Hermitian A, Λ = U*AU is Hermitian and diagonal, hence real. For real symmetric A the eigenvalues are real, so at each step of the Schur induction one may choose a real unit eigenvector and real orthogonal completions; the resulting real triangular T is symmetric, hence diagonal. ∎

Writing the columns of U as q₁, …, qₙ, the spectral theorem reads A = ∑ λi qi qi*: a Hermitian matrix is a real combination of orthogonal rank-one projections. This yields a functional calculus, f(A) = ∑ f(λi) qi qi*, which defines √A, log A or exp A for Hermitian A consistently with the power-series definitions wherever those apply. The theorem has a long history: Cauchy proved in 1829 that the eigenvalues of a real symmetric matrix are real, in connection with quadric surfaces and principal axes, and Hilbert's work on integral equations (1904–1910) extended the theory to infinite dimensions and introduced the word spectrum.

Worked example: A = [ 2 1 ; 1 2 ] has eigenvalues 3 and 1 with unit eigenvectors (1, 1)/√2 and (1, −1)/√2, so A = QΛQᵀ with Q = (1/√2) [ 1 1 ; 1 −1 ] and Λ = diag(3, 1); equivalently A = 3 · (1/2)[ 1 1 ; 1 1 ] + 1 · (1/2)[ 1 −1 ; −1 1 ].

Variational characterization of eigenvalues

For Hermitian A let λ₁ ≥ λ₂ ≥ ⋯ ≥ λₙ be its eigenvalues with orthonormal eigenvectors q₁, …, qₙ. The Rayleigh quotient is R(x) = x*Ax/x*x for x ≠ 0. Expanding x = ∑ ci qi gives R(x) = ∑ λi |ci|² / ∑ |ci|², a weighted average of eigenvalues; hence max R = λ₁ and min R = λₙ.

Theorem 8.4 (Courant–Fischer min-max). For k = 1, …, n,

λk = maxdim S = k  minx ∈ S, x ≠ 0 R(x)  =  mindim S = n−k+1  maxx ∈ S, x ≠ 0 R(x)

Proof. Let S have dimension k. The subspace T = span(qk, …, qₙ) has dimension n − k + 1, so dim(S ∩ T) ≥ k + (n − k + 1) − n = 1. For nonzero x ∈ S ∩ T, R(x) is a weighted average of λk, …, λₙ, so R(x) ≤ λk; thus min over S of R is at most λk. For S = span(q₁, …, qk) the minimum equals λk. This proves the first formula; the second follows in the same way, or by applying the first to −A. ∎

Corollary 8.5 (Weyl's inequalities). For Hermitian A and B, λk(A) + λₙ(B) ≤ λk(A + B) ≤ λk(A) + λ₁(B). Consequently |λk(A + E) − λk(A)| ≤ ‖E‖₂ for every Hermitian perturbation E.

Proof. For every x ≠ 0, RA(x) + λₙ(B) ≤ RA+B(x) ≤ RA(x) + λ₁(B). Taking the minimum over a k-dimensional S and then the maximum over S preserves these inequalities. For the second statement note that ‖E‖₂ = max(|λ₁(E)|, |λₙ(E)|). ∎

Weyl's inequalities say that the eigenvalues of Hermitian matrices are perfectly conditioned: a perturbation of norm ε moves each eigenvalue by at most ε. Another consequence of Courant–Fischer is the Cauchy interlacing theorem: if B is the (n − 1) × (n − 1) matrix obtained from Hermitian A by deleting row and column i, then λk(A) ≥ λk(B) ≥ λk+1(A) for 1 ≤ k ≤ n − 1 (Practice Problem 60).

Exercise

  • (a)
    Find the eigenvalues of A = [ 0 1 1 ; 1 0 1 ; 1 1 0 ].
  • (b)
    Find the maximum of 2x² + 2xy + 2y² on the unit circle x² + y² = 1, and where it is attained.
  • (c)
    Show that N = [ 0 1 ; 0 0 ] is not normal, and explain why this is consistent with Theorem 8.3.
Show solution

Answers: (a) A = J − I where J is the all-ones matrix with eigenvalues 3, 0, 0, so A has eigenvalues 2, −1, −1. (b) The form is xᵀAx with A = [ 2 1 ; 1 2 ], so the maximum is λ₁ = 3, attained at ±(1, 1)/√2. (c) NN* = [ 1 0 ; 0 0 ] while N*N = [ 0 0 ; 0 1 ]. Indeed N is not even diagonalizable, being the Jordan block J₂(0), so it cannot be unitarily diagonalizable.
