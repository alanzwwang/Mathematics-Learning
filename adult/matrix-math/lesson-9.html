Key idea of this section

x*Ax > 0  ⇔  all λi > 0  ⇔  A = B*B (B invertible)  ⇔  A = LL*  ⇔  all leading minors > 0
the inertia (n₊, n₋, n₀) is invariant under congruence A ↦ S*AS

Five characterizations

A Hermitian matrix A is positive definite (A ≻ 0) if x*Ax > 0 for every x ≠ 0, and positive semidefinite (A ⪰ 0) if x*Ax ≥ 0 for every x. Positive definite matrices are exactly the Gram matrices of linearly independent vectors, the covariance matrices of nondegenerate random vectors, the Hessians at strict local minima satisfying the second-order sufficient condition, and the matrices of inner products: ⟨x, y⟩_A = y*Ax is an inner product precisely when A ≻ 0.

Theorem 9.1. For Hermitian A ∈ 𝔽n×n the following are equivalent:

  • (i)
    x*Ax > 0 for all x ≠ 0
  • (ii)
    every eigenvalue of A is positive
  • (iii)
    A = B*B for some invertible B
  • (iv)
    A = LL* for a lower triangular L with positive diagonal (Cholesky factorization), and L is unique
  • (v)
    every leading principal minor det Ak (k = 1, …, n) is positive (Sylvester's criterion)

Proof. (i) ⇔ (ii): if Aq = λq with ‖q‖ = 1, then q*Aq = λ; conversely, writing x = ∑ ci qi in an orthonormal eigenbasis, x*Ax = ∑ λi |ci|². (ii) ⇒ (iii): by the spectral theorem A = UΛU*; take B = Λ1/2U*. (iii) ⇒ (i): x*B*Bx = ‖Bx‖² > 0 since B is injective. (i) ⇒ (v): for x ∈ 𝔽k \ {0}, padding x with zeros gives x*Akx > 0, so Ak satisfies (i), hence (ii), and det Ak is a product of positive numbers. (v) ⇒ (iv): by Theorem 2.3, A = LU with L unit lower triangular, and u₁₁ ⋯ ukk = det Ak > 0, so every ukk > 0. Write U = DM with D = diag(ukk) and M unit upper triangular. Then A = LDM, and A = A* = M*D L* is another factorization of the same type, so uniqueness gives M = L*. Hence A = (LD1/2)(LD1/2)*. Uniqueness of the Cholesky factor follows from the uniqueness of LU. (iv) ⇒ (iii) is immediate with B = L*. ∎

The Cholesky factor is computed column by column from the identity A = LL*: for real A,

ljj = ( ajj − ∑k<j ljk² )1/2,        lij = ( aij − ∑k<j lik ljk ) / ljj   (i > j)

at a cost of about n³/3 operations, half that of LU, and no pivoting is needed for stability. If a radicand is not positive, A is not positive definite: Cholesky is also the cheapest practical test of definiteness. The method is due to André-Louis Cholesky, an officer in the French army geodetic service, and was published posthumously in 1924.

Worked example: for A = [ 4 2 2 ; 2 5 3 ; 2 3 6 ] the formulas give l₁₁ = 2, l₂₁ = 1, l₃₁ = 1, l₂₂ = √(5 − 1) = 2, l₃₂ = (3 − 1 · 1)/2 = 1 and l₃₃ = √(6 − 1 − 1) = 2. Hence

[ 4  2  2 ]   [ 2  0  0 ] [ 2  1  1 ]
[ 2  5  3 ] = [ 1  2  0 ] [ 0  2  1 ]
[ 2  3  6 ]   [ 1  1  2 ] [ 0  0  2 ]

The leading minors are 4, 16 and 64 = (2 · 2 · 2)², all positive, as Sylvester's criterion predicts.

Semidefinite matrices and square roots

For semidefinite matrices the analogues of (i)–(iv) hold with "positive" replaced by "nonnegative" and invertibility dropped, but (v) fails: A = [ 0 0 ; 0 −1 ] has leading minors 0 and 0 yet is not semidefinite. The correct criterion is that all principal minors, not merely the leading ones, are nonnegative. Every A ⪰ 0 has a unique positive semidefinite square root A1/2 = UΛ1/2U*. Uniqueness holds because any positive semidefinite B with B² = A commutes with A, hence preserves each eigenspace of A, and on the eigenspace for λ it is a positive semidefinite matrix whose square is λI, so it acts there as √λ times the identity.

Congruence and Sylvester's law of inertia

Matrices A and S*AS with S invertible are congruent; they represent the same Hermitian form x ↦ x*Ax in different coordinates. Congruence does not preserve eigenvalues, but it preserves their signs. Let n₊(A), n₋(A), n₀(A) be the numbers of positive, negative and zero eigenvalues, counted with multiplicity; the triple is the inertia of A.

Theorem 9.2 (Sylvester's law of inertia, 1852). Congruent Hermitian matrices have the same inertia.

Proof. First, n₊(A) is the largest dimension of a subspace W on which x*Ax > 0 for all nonzero x ∈ W. Indeed the span of the eigenvectors for positive eigenvalues is such a subspace, and any subspace of larger dimension meets the span of the remaining eigenvectors, of dimension n − n₊(A), in a nonzero x with x*Ax ≤ 0. Now if x*S*ASx > 0 on W \ {0}, then y*Ay > 0 on SW \ {0}, and dim SW = dim W because S is invertible. Hence n₊(S*AS) ≤ n₊(A), and applying the same argument with S⁻¹ gives equality. The same reasoning applies to n₋, and n₀ = n − rank A is preserved because rank is. ∎

Consequently a real quadratic form can be reduced by a change of variables to ∑i ≤ p yi² − ∑p < i ≤ p+q yi², and the pair (p, q) is an invariant. In optimization, the inertia of the Hessian at a critical point classifies it as a local minimum, a local maximum or a saddle whenever n₀ = 0. In the LDL* factorization of a Hermitian matrix with nonzero leading minors, the inertia can be read off from the signs of the pivots dk = det Ak / det Ak−1.

Exercise

  • (a)
    For which real t is [ 1 t ; t 4 ] positive definite?
  • (b)
    Find the inertia of [ 1 2 ; 2 1 ].
  • (c)
    Show that if A ≻ 0 then aii > 0 for all i and |aij|² < aii ajj for all i ≠ j.
Show solution

Answers: (a) The leading minors are 1 > 0 and 4 − t² > 0, so exactly for −2 < t < 2. (b) The eigenvalues are 3 and −1 (trace 2, determinant −3), so the inertia is (1, 1, 0): the matrix is indefinite although all its entries are positive. (c) aii = ei*Aei > 0, and the 2 × 2 principal submatrix in rows and columns i, j is positive definite by the argument for (i) ⇒ (v) (applied after a permutation), so its determinant aii ajj − |aij|² is positive.
