Key idea of this section

Eigenvalues and the characteristic polynomial

A scalar λ is an eigenvalue of A ∈ 𝔽n×n if Av = λv for some nonzero vector v, an eigenvector. Equivalently A − λI is singular, that is, λ is a root of the characteristic polynomial pA(λ) = det(λI − A). By the Leibniz formula pA is monic of degree n, and expanding gives

pA(λ) = λⁿ − (tr A) λn−1 + E₂(A) λn−2 − ⋯ + (−1)ⁿ det A

where Ek(A) is the sum of all k × k principal minors. Over ℂ the fundamental theorem of algebra factors pA(λ) = ∏ (λ − λi), so tr A = ∑ λi, det A = ∏ λi, and in general Ek(A) is the k-th elementary symmetric function of the eigenvalues. Similar matrices have the same characteristic polynomial, since det(λI − P⁻¹AP) = det(P⁻¹(λI − A)P) = det(λI − A). The converse fails: I and [ 1 1 ; 0 1 ] share the polynomial (λ − 1)² but are not similar, since only I is similar to I.

Over ℝ a matrix need not have any eigenvalue: the rotation [ 0 −1 ; 1 0 ] has p(λ) = λ² + 1. This is why most of spectral theory is done over ℂ, or over an algebraically closed field.

Multiplicities

The algebraic multiplicity of λ is its multiplicity as a root of pA; the geometric multiplicity is dim ker(A − λI).

Proposition 5.1. The geometric multiplicity never exceeds the algebraic multiplicity.

Proof. Let v₁, …, vg be a basis of ker(A − λI) and extend it to a basis of 𝔽ⁿ. In this basis A has block form [ λIg X ; 0 Y ], so pA(t) = (t − λ)g pY(t), and (t − λ)g divides pA. ∎

Proposition 5.2. Eigenvectors belonging to distinct eigenvalues are linearly independent.

Proof. Suppose not, and take a shortest nontrivial relation c₁v₁ + ⋯ + ckvk = 0 among eigenvectors with distinct eigenvalues λ₁, …, λk; all ci ≠ 0 and k ≥ 2. Applying A − λk I gives ∑i<k ci(λi − λk)vi = 0, a shorter nontrivial relation, a contradiction. ∎

Worked example: A = [ 4 1 ; 2 3 ] has tr A = 7 and det A = 10, so pA(λ) = λ² − 7λ + 10 = (λ − 5)(λ − 2). For λ = 5, A − 5I = [ −1 1 ; 2 −2 ] has kernel spanned by (1, 1); for λ = 2, A − 2I = [ 2 1 ; 2 1 ] has kernel spanned by (1, −2). By Proposition 5.2 these two eigenvectors form a basis of 𝔽².

The Cayley–Hamilton theorem

For a polynomial q(t) = c₀ + c₁t + ⋯ + ck tk define q(A) = c₀I + c₁A + ⋯ + ckAk. The map q ↦ q(A) is a ring homomorphism from 𝔽[t] to the commutative subalgebra 𝔽[A] of matrices.

Theorem 5.3 (Cayley–Hamilton). Every square matrix satisfies its own characteristic polynomial: pA(A) = 0.

Proof. The tempting argument "substitute λ = A into det(λI − A)" is not valid, because det(AI − A) is the scalar det 0, whereas pA(A) is a matrix. Instead, apply Theorem 4.1 to λI − A over the polynomial ring: (λI − A) adj(λI − A) = pA(λ) I. The entries of adj(λI − A) are polynomials in λ of degree at most n − 1, so adj(λI − A) = B₀ + B₁λ + ⋯ + Bn−1λn−1 with constant matrices Bk. Write pA(λ) = c₀ + c₁λ + ⋯ + λⁿ and compare coefficients of λk:

−A B₀ = c₀ I,     Bk−1 − A Bk = ck I  (1 ≤ k ≤ n − 1),     Bn−1 = I

Multiply the equation for λk on the left by Ak and add all of them. The left sides telescope: −AB₀ + (AB₀ − A²B₁) + ⋯ + (An−1Bn−2 − AⁿBn−1) + AⁿBn−1 = 0. The right sides add up to c₀I + c₁A + ⋯ + Aⁿ = pA(A). ∎

Cayley stated the theorem in 1858, verified it for 2 × 2 matrices and reported checking the 3 × 3 case; Hamilton had met a special case in his work on quaternions. The first general proof is due to Frobenius (1878). The theorem holds over every commutative ring, and the proof above works verbatim in that generality.

For the matrix A = [ 4 1 ; 2 3 ] above, Cayley–Hamilton says A² = 7A − 10I. Consequently every power of A is a combination of A and I, and A⁻¹ = (7I − A)/10 = (1/10)[ 3 −1 ; −2 4 ]. More generally, if det A ≠ 0 then A⁻¹ is a polynomial in A of degree at most n − 1.

The minimal polynomial

The set of polynomials q with q(A) = 0 is a nonzero ideal of 𝔽[t] (it contains pA), so it is generated by a unique monic polynomial mA, the minimal polynomial. By Cayley–Hamilton mA divides pA. Conversely every eigenvalue is a root of mA: if Av = λv then 0 = mA(A)v = mA(λ)v. Hence mA and pA have the same roots, possibly with smaller multiplicities in mA. The minimal polynomial is the right object for deciding diagonalizability, as Lesson 6 shows.

Exercise

  • (a)
    Find the eigenvalues of A = [ 2 0 0 ; 1 3 0 ; 4 5 6 ].
  • (b)
    With A = [ 4 1 ; 2 3 ], use Cayley–Hamilton to express A³ as αA + βI.
  • (c)
    Give a 3 × 3 matrix with characteristic polynomial (λ − 2)³ and minimal polynomial (λ − 2)².
Show solution

Answers: (a) The matrix is lower triangular, so det(λI − A) = (λ − 2)(λ − 3)(λ − 6) and the eigenvalues are 2, 3, 6. (b) A³ = A · A² = A(7A − 10I) = 7A² − 10A = 7(7A − 10I) − 10A = 39A − 70I; one checks A³ = [ 86 39 ; 78 47 ] = 39A − 70I. (c) For example [ 2 1 0 ; 0 2 0 ; 0 0 2 ]: with N = A − 2I we have N ≠ 0 but N² = 0, so the minimal polynomial is (λ − 2)².
