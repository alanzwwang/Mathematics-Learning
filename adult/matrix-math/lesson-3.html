Permutations and their signs

The symmetric group Sₙ consists of the n! bijections of {1, …, n}. An inversion of σ is a pair i < j with σ(i) > σ(j), and sgn(σ) = (−1)inv(σ). A transposition of two adjacent values changes the number of inversions by exactly one, and every transposition is a product of an odd number of adjacent ones, so composing with any transposition flips the sign. Since every permutation is a product of transpositions, sgn is a homomorphism Sₙ → {±1}; a k-cycle has sign (−1)k−1.

The axiomatic characterization

Regard a function D : 𝔽n×n → 𝔽 as a function of the n columns of its argument. Call D multilinear if it is linear in each column when the others are fixed, and alternating if D(A) = 0 whenever two columns of A are equal.

Lemma 3.1. An alternating multilinear D changes sign when two columns are exchanged.

Proof. Put x + y in both positions i and j: 0 = D(…, x + y, …, x + y, …) = D(…, x, …, y, …) + D(…, y, …, x, …), because the terms with x, x and y, y vanish. ∎

Theorem 3.2 (Leibniz formula). There is exactly one alternating multilinear function D with D(I) = 1, namely

det A = ∑σ ∈ Sₙ sgn(σ) ∏j=1n aσ(j) j

Moreover, every alternating multilinear D satisfies D(A) = D(I) · det A.

Proof. Write column j as ∑i aij ei and expand by multilinearity: D(A) = ∑f (∏j af(j) j) D(ef(1), …, ef(n)), the sum over all functions f : {1, …, n} → {1, …, n}. If f is not injective, two arguments coincide and the term vanishes. If f = σ is a permutation, then by Lemma 3.1 sorting the columns eσ(1), …, eσ(n) into the order e₁, …, eₙ by transpositions multiplies D by sgn(σ), so D(eσ(1), …, eσ(n)) = sgn(σ) D(I). This proves D(A) = D(I) det A and hence uniqueness. For existence, check that the Leibniz sum has the three properties: each term is linear in each column, since it contains exactly one entry from each column; D(I) = 1 since only σ = id contributes; and if columns k and l are equal, the terms for σ and σ ∘ (k l) are equal in absolute value and opposite in sign, so they cancel in pairs. ∎

Corollary 3.3. det Aᵀ = det A. Consequently det is also alternating and multilinear in the rows, and may be expanded along any row or column (Laplace expansion).

Proof. Substituting τ = σ⁻¹, which is a bijection of Sₙ with sgn τ = sgn σ, gives ∏j aσ(j) j = ∏i ai τ(i), so the Leibniz sums for A and Aᵀ agree term by term. ∎

Theorem 3.4 (Multiplicativity). For all A, B ∈ 𝔽n×n, det(AB) = det A · det B.

Proof. Fix A and define D(B) = det(AB). The j-th column of AB is A bj, which depends linearly on bj, so D is multilinear in the columns of B; and if two columns of B are equal, the same two columns of AB are equal, so D(B) = 0. By the last statement of Theorem 3.2, D(B) = D(I) det B = det A · det B. ∎

Corollary 3.5. A is invertible if and only if det A ≠ 0, and then det(A⁻¹) = 1/det A. Similar matrices have equal determinants.

Proof. If A is invertible, 1 = det I = det A · det A⁻¹. If A is not invertible, its columns are dependent, say ak = ∑j≠k cj aj; substituting into column k and expanding by multilinearity gives a sum of determinants each with a repeated column, so det A = 0. Finally det(P⁻¹AP) = det P⁻¹ det A det P = det A. ∎

Geometric meaning and computation

For real A, |det A| is the factor by which the map x ↦ Ax multiplies n-dimensional volume, and the sign records whether orientation is preserved. This is the origin of the Jacobian determinant in the change-of-variables formula for multiple integrals. Computationally, the Leibniz formula has n! terms and is useless beyond tiny n. Instead one factors PA = LU, and then det A = sgn(P) u₁₁ u₂₂ ⋯ uₙₙ at a cost of O(n³). For the matrix of Lesson 2, det [ 2 1 1 ; 4 3 3 ; 8 7 9 ] = 2 · 1 · 2 = 4.

Theorem 3.6 (Vandermonde determinant). For V = (xij−1), the n × n matrix whose i-th row is (1, xi, xi², …, xin−1),

det V = ∏1 ≤ i < j ≤ n (xj − xi)

Proof. Induct on n; n = 1 is trivial. Replace xn by a variable t. The determinant is a polynomial in t of degree at most n − 1 whose coefficient of tn−1 is, by expansion along the last row, the Vandermonde determinant of x₁, …, xn−1. It vanishes at t = x₁, …, xn−1 because two rows then coincide. If the xi are distinct, the polynomial therefore equals Vn−1 ∏i<n (t − xi), and setting t = xn completes the induction. The identity then holds for all values because both sides are polynomials that agree on a dense set. ∎

Consequently a polynomial of degree less than n is determined by its values at n distinct points: Lagrange interpolation is precisely the statement that V is invertible.

Exercise

  • (a)
    Evaluate the Vandermonde determinant for x₁ = 1, x₂ = 2, x₃ = 4.
  • (b)
    Compute det of the permutation matrix [ 0 1 0 ; 0 0 1 ; 1 0 0 ].
  • (c)
    Show that every real skew-symmetric matrix (Aᵀ = −A) of odd size is singular.
Show solution

Answers: (a) (2 − 1)(4 − 1)(4 − 2) = 1 · 3 · 2 = 6. (b) The matrix sends e₁ ↦ e₃, e₂ ↦ e₁, e₃ ↦ e₂, a 3-cycle, whose sign is (−1)² = +1, so the determinant is 1. (c) det A = det Aᵀ = det(−A) = (−1)ⁿ det A = −det A for odd n, so det A = 0.
