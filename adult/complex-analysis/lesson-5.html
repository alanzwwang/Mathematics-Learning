Paths and the integral

A path is a continuous, piecewise continuously differentiable map γ : [a, b] → ℂ; it is closed if γ(a) = γ(b). For f continuous on the trace γ* = γ([a, b]) define ∫γ f(z) dz = ∫ₐᵇ f(γ(t)) γ′(t) dt. The chain rule shows that the integral is unchanged by an orientation-preserving reparametrisation and changes sign under reversal of orientation. Writing f = u + iv and dz = dx + i dy, the contour integral is the pair of real line integrals ∫ (u dx − v dy) + i ∫ (v dx + u dy). The length of γ is L(γ) = ∫ₐᵇ |γ′(t)| dt, and the estimate |∫γ f dz| ≤ sup over γ* of |f| · L(γ), often called the ML-inequality, follows from |∫ g| ≤ ∫ |g| for complex-valued g. Circles |z − a| = r are always oriented counterclockwise unless stated otherwise.

The fundamental computation

Parametrise the circle by γ(t) = a + r eit, 0 ≤ t ≤ 2π, so γ′(t) = i r eit. For n ∈ ℤ,

∮ (z − a)ⁿ dz = ∫₀2π rⁿ eint · i r eit dt = i rn+1 ∫₀2π ei(n+1)t dt,

which is 2πi when n = −1 and 0 otherwise, because eikt integrates to 0 over a full period when k ≠ 0. Almost every theorem in this course is, in the end, a sophisticated reduction to this one computation.

Primitives

Theorem 5.1. If f is continuous on an open set U and has a primitive F there (F holomorphic with F′ = f), then for every path γ in U from p to q, ∫γ f dz = F(q) − F(p). In particular ∮γ f dz = 0 for every closed path γ in U.

Proof. On each C¹ piece, (F ∘ γ)′(t) = F′(γ(t)) γ′(t) by the chain rule, so the integral telescopes by the fundamental theorem of calculus applied to real and imaginary parts.

Combining this with the fundamental computation: the function 1/z has no primitive on ℂ \ {0}, because its integral over the unit circle is 2πi ≠ 0. Equivalently, there is no continuous logarithm on the punctured plane. On the other hand, every integer power zⁿ with n ≠ −1 has the primitive zn+1/(n + 1); so ∫ over any path from 0 to 1 + i of z² dz equals (1 + i)³/3 = (−2 + 2i)/3.

Integration and limits

If fₙ → f uniformly on γ*, then ∫γ fₙ dz → ∫γ f dz, by the ML-inequality. In particular a uniformly convergent series of continuous functions may be integrated term by term along a path. This simple remark is what turns Cauchy's integral formula into power series expansions in Lesson 7.

Green's theorem and a first glimpse of Cauchy

If f is C¹ on a neighbourhood of a closed region Ω with piecewise smooth positively oriented boundary, Green's theorem applied to the real and imaginary parts gives

∮ over ∂Ω of f dz = 2i ∬ over Ω of ∂f/∂z̄ dA.

For holomorphic f with continuous derivative the right side is 0, which is Cauchy's original (1825) form of his theorem. The test case f = z̄ has ∂f/∂z̄ = 1, and indeed ∮ over |z| = 1 of z̄ dz = ∫₀2π e−it i eit dt = 2πi = 2i · π. Lesson 6 removes the hypothesis that f′ be continuous, which is essential for a theory built on the bare definition of holomorphy.

The winding number

For a closed path γ and a point a ∉ γ*, define the winding number (index) n(γ, a) = (1/2πi) ∮γ dz/(z − a).

Theorem 5.2. n(γ, a) is an integer; it is constant on each connected component of ℂ \ γ* and is 0 on the unbounded component.

Proof. Parametrise γ on [α, β] and let φ(t) = ∫ from α to t of γ′(s)/(γ(s) − a) ds, so that φ(β) = 2πi n(γ, a). The function e−φ(t)(γ(t) − a) has derivative e−φ(γ′ − φ′(γ − a)) = 0 wherever γ is differentiable, so it is constant; comparing t = α with t = β and using γ(α) = γ(β) gives eφ(β) = 1, hence φ(β) ∈ 2πiℤ. The index is a continuous integer-valued function of a, hence locally constant, and it tends to 0 as |a| → ∞ by the ML-inequality.

Exercise

  • (a)
    Compute ∮ over |z| = 2 of z⁻³ dz.
  • (b)
    Compute ∫ dz/z along the upper half of the unit circle from 1 to −1.
  • (c)
    Show that |∮ over |z| = R of dz/(z² + 1)| ≤ 2πR/(R² − 1) for R > 1, and deduce the limit as R → ∞.
Show solution

Answers: (a) 0, since z⁻³ has the primitive −z⁻²/2 on ℂ \ {0}. (b) With z = eit, 0 ≤ t ≤ π, the integral is ∫₀π i dt = iπ. (c) On |z| = R, |z² + 1| ≥ R² − 1 by the reverse triangle inequality, and the length is 2πR; the bound tends to 0. (Lesson 9 shows the integral is in fact exactly 0 for every R > 1.)
