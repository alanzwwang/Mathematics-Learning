The exponential and Euler's formula

For z = x + iy define ez = ex (cos y + i sin y). In Lesson 4 we show that this agrees with the everywhere convergent power series ∑ zⁿ/n!; for now note that splitting that series into even and odd powers of iy gives, term by term,

∑ (iy)ⁿ/n! = (1 − y²/2! + y⁴/4! − …) + i (y − y³/3! + y⁵/5! − …) = cos y + i sin y,

which is Euler's formula eiy = cos y + i sin y. The addition formulas for sine and cosine are equivalent to the law ei(α+β) = eiα eiβ, and the special case eiπ + 1 = 0 links the five fundamental constants. The exponential is periodic with period 2πi, never vanishes, and maps ℂ onto ℂ \ {0}; the horizontal strip {0 ≤ Im z < 2π} is mapped bijectively onto ℂ \ {0}.

Polar form and arguments

Every z ≠ 0 can be written z = r eiθ with r = |z| > 0. The angle θ is determined only modulo 2π, so arg z is a set, a coset of 2πℤ in ℝ. The principal argument Arg z is the unique representative in (−π, π]. From eiα eiβ = ei(α+β),

(r eiα)(s eiβ) = rs ei(α+β),   (r eiθ)ⁿ = rⁿ einθ  (de Moivre).

Example. 1 + i = √2 eiπ/4, so (1 + i)¹⁰ = 2⁵ e10πi/4 = 32 e5πi/2 = 32 eiπ/2 = 32i. The same computation by the binomial theorem requires eleven terms.

Roots and roots of unity

Let w = ρ eiφ with ρ > 0. Then zⁿ = w if and only if |z| = ρ1/n and n arg z ≡ φ (mod 2π), so the solutions are

zk = ρ1/n ei(φ + 2πk)/n,   k = 0, 1, …, n − 1,

the vertices of a regular n-gon centred at 0. For example, −8 = 8 eiπ has cube roots 2eiπ/3 = 1 + i√3, 2eiπ = −2 and 2e5πi/3 = 1 − i√3.

The n-th roots of unity μₙ = {1, ω, ω², …, ωn−1}, ω = e2πi/n, form a cyclic group of order n under multiplication. Since they are exactly the roots of zⁿ − 1,

zⁿ − 1 = ∏ (z − ωk)  over k = 0, …, n − 1.

Comparing the coefficient of zn−1 shows that the roots sum to 0 for n ≥ 2, so ∑ cos(2πk/n) = ∑ sin(2πk/n) = 0. Dividing by z − 1 gives 1 + z + … + zn−1 = ∏ (z − ωk) over k = 1, …, n − 1, and evaluating at z = 1,

∏ (1 − ωk) = n   (k = 1, …, n − 1).

Taking moduli and using |1 − eiθ| = 2 sin(θ/2) gives the classical identity ∏ 2 sin(πk/n) = n. A root ζ is primitive if it generates μₙ; there are φ(n) of them (Euler's totient), namely ωk with gcd(k, n) = 1. The cyclotomic polynomial Φₙ(z) = ∏ (z − ζ) over primitive ζ has integer coefficients, zⁿ − 1 = ∏ Φd(z) over the divisors d of n, and the sum of the primitive n-th roots of unity equals the Möbius function μ(n). Gauss's construction of the regular 17-gon (1796) rests on the fact that φ(17) = 16 is a power of 2, so that the field generated by e2πi/17 is reached by a tower of quadratic extensions.

The logarithm and complex powers

A logarithm of z ≠ 0 is any w with ew = z. Writing w = u + iv, this means eu = |z| and v ∈ arg z, so

log z = ln|z| + i arg z   (a set),   Log z = ln|z| + i Arg z   (principal value).

Log is continuous, indeed holomorphic, on the slit plane ℂ \ (−∞, 0], but it jumps by 2πi across the negative real axis. The familiar rules fail for principal values: Log((−1)(−1)) = Log 1 = 0, while Log(−1) + Log(−1) = 2πi. For a ∈ ℂ one defines za = ea log z, again a set, with principal value ea Log z. For instance ii = ei·(iπ/2 + 2πik) = e−π/2 − 2πk, a set of positive real numbers whose principal value is e−π/2 ≈ 0.2079. The multivaluedness of log and of za is not a defect to be patched; it is the first appearance of monodromy, which Lesson 13 treats systematically.

Exercise

  • (a)
    Compute (1 − i√3)⁶.
  • (b)
    Find all fourth roots of −16.
  • (c)
    Find Log(−1 − i).
Show solution

Answers: (a) 1 − i√3 = 2e−iπ/3, so the sixth power is 64 e−2πi = 64. (b) −16 = 16eiπ, so the roots are 2ei(π + 2πk)/4, k = 0, 1, 2, 3, that is √2 + i√2, −√2 + i√2, −√2 − i√2, √2 − i√2. (c) |−1 − i| = √2 and Arg(−1 − i) = −3π/4, so Log(−1 − i) = (1/2) ln 2 − 3πi/4.
