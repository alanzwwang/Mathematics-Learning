Complex Differentiability and the Cauchy–Riemann Equations

Lesson 3 of 14

Overview1234567891011121314ProblemsAssessment

Key idea of this section

f = u + iv is complex differentiable at z₀ = x₀ + iy₀
⇔ (u, v) is real differentiable at (x₀, y₀) and
      ux = vy,   uy = −vx   (Cauchy–Riemann);
then f′(z₀) = ux + i vx.

Definitions

Let U ⊆ ℂ be open and f : U → ℂ. We say f is complex differentiable at z₀ ∈ U if the limit

f′(z₀) = lim (f(z₀ + h) − f(z₀))/h   as h → 0, h ∈ ℂ \ {0},

exists. The function is holomorphic on U if it is complex differentiable at every point of U, and entire if it is holomorphic on all of ℂ. The usual rules (sum, product, quotient, chain rule) hold with the usual proofs, so polynomials are entire and rational functions are holomorphic away from the zeros of their denominators.

The requirement that the limit be the same along all directions is severe. For f(z) = z̄ the difference quotient is h̄/h, which equals 1 for real h and −1 for imaginary h; so z̄ is nowhere complex differentiable, although as a map of ℝ² it is linear and hence infinitely smooth.

The Cauchy–Riemann equations

Theorem 3.1. Write f = u + iv with u, v real. Then f is complex differentiable at z₀ = x₀ + iy₀ if and only if u and v are differentiable at (x₀, y₀) as real functions and satisfy ux = vy and uy = −vx there.

Proof. Suppose f′(z₀) = a + ib exists. Then f(z₀ + h) = f(z₀) + (a + ib)h + o(|h|). Writing h = s + it and taking real and imaginary parts, u(x₀ + s, y₀ + t) = u + as − bt + o and v(x₀ + s, y₀ + t) = v + bs + at + o. Hence u, v are real differentiable with Jacobian matrix having rows (a, −b) and (b, a), which says precisely ux = a = vy and uy = −b = −vx. Conversely, if u and v are real differentiable and satisfy the equations, put a = ux, b = vx; the real Jacobian then has rows (a, −b) and (b, a), which is the matrix of multiplication by a + ib, so f(z₀ + h) − f(z₀) = (a + ib)h + o(|h|), and f′(z₀) = a + ib.

The proof exhibits the geometric content: the real derivative of a holomorphic map at a point is a rotation composed with a dilation, the matrix model of a + ib from Lesson 1. In particular the Jacobian determinant is a² + b² = |f′(z₀)|² ≥ 0, so holomorphic maps preserve orientation, and where f′(z₀) ≠ 0 they preserve angles between curves. This is the starting point of conformal geometry (Lesson 12).

A sufficient condition used in practice: if u, v have continuous first partial derivatives on U satisfying the Cauchy–Riemann equations, then f is holomorphic on U, since continuous partials imply real differentiability. Merely having partial derivatives satisfying the equations at a point is not enough: the function equal to e−1/z⁴ for z ≠ 0 and 0 at 0 satisfies the Cauchy–Riemann equations at every point, including 0, yet is not even continuous at 0 (along the line z = t eiπ/4 it equals e1/t⁴). The Looman–Menchoff theorem says that continuity of f together with the existence of the partials and the Cauchy–Riemann equations everywhere on U does suffice; its proof is deep.

Example. Let f(z) = |z|² = x² + y², so u = x² + y² and v = 0. The equations read 2x = 0 and 2y = 0, so f is complex differentiable at 0 only (with f′(0) = 0) and holomorphic nowhere: holomorphy is a property of open sets.

Wirtinger derivatives

Define the operators ∂/∂z = (1/2)(∂/∂x − i ∂/∂y) and ∂/∂z̄ = (1/2)(∂/∂x + i ∂/∂y). For a real differentiable f, the Cauchy–Riemann equations are equivalent to the single complex equation ∂f/∂z̄ = 0, and then f′ = ∂f/∂z. These operators act on polynomials in z and z̄ as if z and z̄ were independent variables: ∂(z²z̄)/∂z̄ = z², which is nonzero away from 0, so z²z̄ is not holomorphic on any open set. Heuristically, a holomorphic function is a function of z alone.

Harmonic functions

If f = u + iv is holomorphic and u, v are of class C² (we shall see in Lesson 7 that this is automatic), then uxx = vyx and uyy = −vxy, so

Δu = uxx + uyy = 0,   and likewise Δv = 0.

The real and imaginary parts of a holomorphic function are harmonic, and v is called a harmonic conjugate of u. Conversely, on a simply connected domain every harmonic u has a harmonic conjugate, unique up to an additive constant: the 1-form −uy dx + ux dy is closed because Δu = 0, so it is exact on a simply connected domain, and its primitive v satisfies the Cauchy–Riemann equations. On the punctured plane, u = ln|z| is harmonic but has no single-valued harmonic conjugate, since the conjugate would be a continuous branch of arg z.

Example. Let u = x² − y² + 3x. Then ux = 2x + 3 = vy gives v = 2xy + 3y + φ(x), and vx = 2y + φ′(x) must equal −uy = 2y, so φ is constant. Thus v = 2xy + 3y + C and f = u + iv = z² + 3z + iC.

Exercise

  • (a)
    At which points is f(x + iy) = x² + i y² complex differentiable? Is it holomorphic anywhere?
  • (b)
    Find a harmonic conjugate of u = ex cos y and identify f = u + iv.
  • (c)
    Show that u = ln(x² + y²) is harmonic on ℂ \ {0}.
Show solution

Answers: (a) ux = 2x, vy = 2y, uy = 0, vx = 0, so the equations hold exactly on the line y = x; f is differentiable there but holomorphic nowhere, since the line contains no open set. (b) v = ex sin y, and f = ez. (c) u = 2 Re Log z locally, or directly uxx = 2(y² − x²)/(x² + y²)² and uyy = 2(x² − y²)/(x² + y²)², which sum to 0.
