The Moran–Hutchinson Theorem, Overlaps and Self-Affine Sets

Lesson 8 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

Under the open set condition, a self-similar set has dimH = dimB = s, where ∑ riˢ = 1.
For self-affine carpets the dimensions can differ:
dimH = logm ∑j tjlog m/log n   versus   dimB = logm r + logn(N/r)

A packing lemma

Lemma 8.1. Let {Vi} be a collection of disjoint open subsets of ℝⁿ such that each Vi contains a ball of radius a₁ρ and is contained in a ball of radius a₂ρ. Then any ball B of radius ρ meets at most q = (1 + 2a₂)ⁿ a₁−n of the closures V̄i.

Proof. If V̄i meets B = B(x, ρ), then V̄i ⊂ B(x, (1 + 2a₂)ρ), because V̄i has diameter at most 2a₂ρ. If q′ of the closures meet B, then the corresponding disjoint balls of radius a₁ρ all lie in B(x, (1 + 2a₂)ρ), and comparing volumes, q′ (a₁ρ)ⁿ ≤ ((1 + 2a₂)ρ)ⁿ. ∎

Proof of the Moran–Hutchinson theorem

Recall the setting: similarities f₁, …, fN of ℝⁿ with ratios ri, attractor F, similarity dimension s, and an open set V witnessing the OSC. Write rw = rw₁⋯rwk for a word w = w₁…wk, and rmin = min ri.

Step 1 (stopping sets). For 0 < ρ < 1 let Qρ be the set of finite words w = w₁…wk with rw ≤ ρ < rw₁…wk−1 (the empty word has ratio 1). Every infinite word has exactly one prefix in Qρ, so the cylinders [w], w ∈ Qρ, partition Σ. Consequently ∑w∈Qρ rwˢ = 1. Indeed, ∑|w|=k rwˢ = (∑ riˢ)k = 1, and a finite partition of Σ into cylinders can be refined to the partition by all words of length k by repeatedly replacing a word w by its N children, which preserves the sum since ∑i (rw ri)ˢ = rwˢ. Also rmin ρ < rw ≤ ρ for w ∈ Qρ.

Step 2 (upper bound). F = ⋃w∈Qρ Fw, and |Fw| = rw|F| ≤ ρ|F|. Hence 𝓗ˢρ|F|(F) ≤ ∑w∈Qρ rwˢ |F|ˢ = |F|ˢ, so 𝓗ˢ(F) ≤ |F|ˢ < ∞ and dimH F ≤ s. Also #Qρ · (rmin ρ)ˢ < ∑ rwˢ = 1, so Nρ|F|(F) ≤ #Qρ < (rmin ρ)−s, and dimB̄ F ≤ s. Step 2 does not use the OSC.

Step 3 (disjointness). If w, v ∈ Qρ are distinct, then neither is a prefix of the other, so they first differ at some position: w = u i w′, v = u j v′ with i ≠ j. Then fw(V) ⊂ fu(fi(V)) and fv(V) ⊂ fu(fj(V)), and these are disjoint because fi(V) ∩ fj(V) = ∅ and fu is injective. Thus {fw(V) : w ∈ Qρ} is a disjoint family of open sets.

Step 4 (lower bound). Choose a₁, a₂ such that V contains a ball of radius a₁ and is contained in a ball of radius a₂. Then fw(V) contains a ball of radius rw a₁ ≥ rmin a₁ ρ and is contained in a ball of radius rw a₂ ≤ a₂ ρ. By Lemma 8.1 (with a₁ replaced by rmin a₁), any ball of radius ρ meets at most q = (1 + 2a₂)ⁿ (rmin a₁)−n of the closures fw(V̄). Since T(V̄) ⊂ V̄, iterating gives F ⊂ V̄, hence Fw ⊂ fw(V̄).

Let ν be the Bernoulli measure on Σ with weights riˢ, so ν([w]) = rwˢ, and let μ = ν ∘ π⁻¹, a probability measure on F. Let U be a set with |U| = ρ < 1, and B a ball of radius ρ containing U. If π(i) ∈ U, the prefix w of i in Qρ has π(i) ∈ Fw ⊂ fw(V̄), so fw(V̄) meets B. Hence

μ(U) ≤ ∑{ ν([w]) : w ∈ Qρ, fw(V̄) ∩ B ≠ ∅ } ≤ q ρˢ = q|U|ˢ

By the mass distribution principle, 𝓗ˢ(F) ≥ 1/q > 0, so dimH F ≥ s. Combining with Step 2 and dimH ≤ dimB̲ ≤ dimB̄, all three dimensions equal s. ∎

Overlaps

Without separation, dimH F ≤ min{s, n} always holds and may be strict. Consider the IFS on ℝ

f₁(x) = λx,   f₂(x) = λx + 1,   f₃(x) = λx + t

with similarity dimension log 3 / log(1/λ). For t = λ we have f₁ ∘ f₂(x) = λ²x + λ = f₃ ∘ f₁(x): two distinct words of length 2 give the same map. Such an exact overlap reduces the effective number of pieces, and the dimension of the attractor is then strictly less than s (hence less than min{1, s} whenever s ≤ 1; for s > 1 it can equal 1, e.g. λ = t = 1/2 gives the attractor [0, 2]). A breakthrough of Hochman (2014) shows that in ℝ exact overlaps are essentially the only obstruction: if the IFS satisfies an exponential separation condition — which holds, for instance, whenever all parameters are algebraic and there are no exact overlaps — then dimH F = min{1, s}. Whether exact overlaps are the only obstruction for all self-similar sets on the line is the exact overlaps conjecture, still open in general.

Self-affine carpets

Replace similarities by affine maps x ↦ Ai x + bi. The simplest non-conformal examples are the Bedford–McMullen carpets (Bedford 1984, McMullen 1984). Fix integers n > m ≥ 2, divide the unit square into a grid of n columns and m rows, so each rectangle has width 1/n and height 1/m, and choose a set D of N of these rectangles. The maps (x, y) ↦ (x/n, y/m) + (a/n, b/m), one for each chosen rectangle (a, b), generate a carpet F. Let tj be the number of chosen rectangles in row j and r the number of rows with tj ≥ 1.

Theorem 8.2 (McMullen, 1984). With θ = log m / log n,

dimH F = logm ( ∑j=1m tjθ )
dimB F = logm r + logn (N/r)

and dimH F < dimB F unless all non-zero tj are equal.

Proof of the box formula. Let l ≥ 1, δ = m−l, and k = ⌊θl⌋, so that n−k is comparable to m−l = δ. An approximate square of level l is the set of points of F whose first k column digits and first l row digits are prescribed; it is contained in a rectangle of width n−k and height m−l, both comparable to δ. Choosing such a square amounts to choosing k chosen rectangles (Nk possibilities, which fix both digits at levels 1, …, k) and then l − k rows (r possibilities each). The approximate squares are disjoint pieces of F of size comparable to δ, so Nδ(F) ≍ Nk rl−k, and

log Nδ / (−log δ) = [k log N + (l − k) log r] / (l log m)
                   → θ log N / log m + (1 − θ) log r / log m
                   = logn N + logm r − logn r = logm r + logn(N/r)

using θ/log m = 1/log n. The Hausdorff formula requires the McMullen measure, the Bernoulli measure giving each rectangle in row j weight tjθ−1/∑i tiθ, together with a law of large numbers along approximate squares. ∎

Worked example. Take n = 3, m = 2, one rectangle in the top row and two in the bottom row (N = 3, r = 2, t = (1, 2)). Then θ = log 2 / log 3 ≈ 0.6309 and

dimH F = log₂(1 + 20.6309) = log₂(2.5486) ≈ 1.3497
dimB F = log₂ 2 + log₃(3/2) = 1 + 0.3691 ≈ 1.3691

The Hausdorff dimension is strictly smaller, a phenomenon impossible for self-similar sets with the OSC. Moreover, when the non-zero tj are not all equal, the Hausdorff measure of the carpet in its own dimension is infinite (Peres, 1994).

Affinity dimension

For a general self-affine IFS, Falconer (1988) introduced the singular value function: if σ₁ ≥ ⋯ ≥ σₙ are the singular values of a matrix A and 0 ≤ s ≤ n, write s = k + η with k an integer and 0 ≤ η < 1, and set φˢ(A) = σ₁⋯σk σk+1η. The affinity dimension is the unique d with

limk→∞ ( ∑|w|=k φᵈ(Aw) )1/k = 1

where Aw = Aw₁⋯Awk; for similarities it reduces to Moran's equation.

Theorem 8.3 (Falconer 1988; Solomyak 1998). If ‖Ai‖ < 1/2 for all i, then for Lebesgue-almost every choice of translations (b₁, …, bN), the attractor satisfies dimH F = dimB F = min{d, n}.

Falconer proved this with the bound 1/3, and Solomyak observed that 1/2 suffices; the bound cannot be relaxed to 1. The carpets show that "almost every" cannot be dropped: their translations are special, aligned to a grid. Bárány, Hochman and Rapaport (2019) proved that for planar self-affine sets satisfying strong separation and an irreducibility condition on the linear parts, the Hausdorff dimension equals the affinity dimension.

Exercise

  • (a)
    Verify Step 1 for the Cantor set: what is Qρ when ρ = 1/9?
  • (b)
    Compute dimH and dimB of the carpet with n = 4, m = 2, two rectangles in the top row and one in the bottom row.
  • (c)
    Show that if all non-zero tj equal t, then both McMullen formulas reduce to logm r + logn t.
  • (d)
    For a Bedford–McMullen carpet with N = n·m (all rectangles chosen), what are the dimensions?
Show solution

Answers: (a) Q1/9 consists of the 4 words of length 2, since rw = 1/9 ≤ 1/9 < 1/3 = rw₁; and ∑ rwˢ = 4·(1/9)ˢ = 4·(1/4) = 1. (b) θ = log 2/log 4 = 1/2; dimH = log₂(21/2 + 1) = log₂(2.4142) ≈ 1.2716; dimB = log₂ 2 + log₄(3/2) = 1 + 0.2925 ≈ 1.2925. (c) ∑ tjθ = r tθ, so dimH = logm r + θ logm t = logm r + log t/log n = logm r + logn t; and N = rt, so dimB = logm r + logn t as well. (d) The carpet is the whole square: tj = n for all m rows, and both formulas give logm m + logn n = 2.
