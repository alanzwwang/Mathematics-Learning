Problem Set

60 problems

Overview12345678910111213ProblemsAssessment

The problems are grouped in three tiers. Core problems check the definitions and the standard computations; Advanced problems require combining several results or carrying out a short proof; Challenge problems are proofs at the level of a graduate qualifying examination or a research seminar. Unless stated otherwise, C denotes the middle-third Cantor set, sC = log 2 / log 3, and logarithms without a base are natural.

Core (Problems 1–20)

  • 1.
    Compute the Hausdorff distance h([0, 2], [1, 4]) in ℝ.
  • 2.
    Compute h({0, 1}, [0, 1]).
  • 3.
    In ℝ², compute h(S, {0}), where S is the unit circle.
  • 4.
    Let f(x) = x/3 + 2 on ℝ and x₀ = 0. Find the fixed point, the least n for which the a priori bound of Theorem 2.1 guarantees |xₙ − x*| < 0.01, and the actual error |xₙ − x*|.
  • 5.
    Show that [0, 1] is the attractor of x ↦ x/2 and x ↦ x/2 + 1/2, and find the similarity dimension of this IFS.
  • 6.
    The Vicsek fractal is the attractor of 5 similarities of ratio 1/3 (the centre and four corner subsquares). Find its dimension.
  • 7.
    Solve Moran's equation for the ratios 1/2, 1/3, 1/6.
  • 8.
    Find the dimension of the Sierpinski carpet.
  • 9.
    Find the addresses in {1, 2}ℕ of the points 1/4 and 3/4 of C for the IFS f₁(x) = x/3, f₂(x) = x/3 + 2/3.
  • 10.
    Find the box dimension of {0} ∪ {k−3 : k ∈ ℕ}.
  • 11.
    Find the Hausdorff, box and packing dimensions of ℚ ∩ [0, 1].
  • 12.
    Express 𝓗sC(C ∩ [0, 1/3]) in terms of 𝓗sC(C).
  • 13.
    Find the Hausdorff dimension of the middle-3/5 Cantor set.
  • 14.
    Find the Hausdorff dimension of the set of x ∈ [0, 1] whose decimal digits are all odd.
  • 15.
    Find the Hausdorff dimension of C × [0, 1].
  • 16.
    Find the parameter c of the quadratic family whose attracting fixed point has multiplier −1/2, and find that fixed point.
  • 17.
    Decide whether each of c = −1.9, c = 0.26 and c = −2.01 belongs to M.
  • 18.
    For c = 1, find the first n with |fcⁿ(0)| > 2.
  • 19.
    For the logistic map with r = 2.5, find the non-zero fixed point, its multiplier, and its type.
  • 20.
    Using r₁ = 3, r₂ = 1 + √6 and δ ≈ 4.669202, predict r₃ and compare with r₃ ≈ 3.544090.

Advanced (Problems 21–45)

  • 21.
    Let Cₙ be the union of the 2ⁿ level-n intervals of the Cantor construction. Prove that h(Cₙ, C) = 3−(n+1)/2.
  • 22.
    Apply the collage theorem to A = Cₙ for the Cantor IFS, and compare the bound with the true distance from Problem 21.
  • 23.
    Solve Moran's equation for the ratios 1/2, 1/4, 1/8, giving s to four decimal places.
  • 24.
    The quadratic Koch curve of type 2 is generated by 8 similarities of ratio 1/4. Find its dimension.
  • 25.
    Find the box dimension of {0} ∪ {1/log k : k ≥ 2}.
  • 26.
    Find the box dimension of {0} ∪ {k−1/2 : k ∈ ℕ}.
  • 27.
    Prove that the Cantor function φ : [0, 1] → [0, 1] is not α-Hölder for any α > sC.
  • 28.
    A Bedford–McMullen carpet has n = 4 columns and m = 3 rows, with one chosen rectangle in one row, two in a second row and none in the third. Compute dimH and dimB.
  • 29.
    Prove that the Cantor dust C × C is totally disconnected, and find its dimension.
  • 30.
    Compute the s-energy of Lebesgue measure on [0, 1] and find the values of s for which it is finite.
  • 31.
    Find the Hausdorff dimension of the set of x ∈ [0, 1] whose ternary digits 0, 1, 2 have asymptotic frequencies 1/2, 1/4, 1/4.
  • 32.
    For c = −2, find the 2-cycle of fc, its multiplier, and the corresponding angles under the substitution z = 2 cos θ.
  • 33.
    For c = −2, find both fixed points and their multipliers, and explain why both lie in J₋₂.
  • 34.
    For c = i, find the preperiod and period of the critical value and the multiplier of the cycle it lands on.
  • 35.
    Find all real c for which fc has an attracting 2-cycle, and find the 2-cycle for c = −1.
  • 36.
    Show that the escape radius 2 in Theorem 10.1 cannot be lowered: exhibit c ∈ M and n with |fcⁿ(0)| = 2.
  • 37.
    Show that for r = 1 + √5 the 2-cycle of the logistic map contains the critical point 1/2, and find the other point of the cycle.
  • 38.
    Find the parameter c of the quadratic family conjugate to the logistic map with r = 1 + √5.
  • 39.
    Find the Lyapunov exponent of the tent map T(x) = 1 − |1 − 2x| at every point whose orbit avoids 1/2.
  • 40.
    Find the values of r for which the logistic map is conjugate to f₀ and to f₋₂.
  • 41.
    Find the dimensions of the graph of fractional Brownian motion with H = 0.75 and of its path in ℝ².
  • 42.
    Compute the box dimension of the graph of the Weierstrass function with a = 0.6 and b = 3.
  • 43.
    For the binomial measure with p = 0.2, find αmin and αmax.
  • 44.
    For the binomial measure with p = 0.2, compute the correlation dimension D₂.
  • 45.
    With b = 9, find the value of a for which the graph of the Weierstrass function has the same dimension as the graph of Brownian motion.

Challenge (Problems 46–60)

  • 46.
    Prove that dimH(E × F) ≥ dimH E + dimH F for Borel sets E ⊂ ℝⁿ, F ⊂ ℝᵐ.
  • 47.
    Prove that the graph of the Cantor function has length 2 and Hausdorff dimension 1.
  • 48.
    Prove that every c with |c| ≤ 1/4 belongs to M.
  • 49.
    Prove that every c with |c| < 1/4 lies in the main cardioid, that is, fc has an attracting fixed point.
  • 50.
    Prove that the Sierpinski triangle Δ of side 1 satisfies 0 < 𝓗ˢ(Δ) ≤ 1 with s = log 3/log 2.
  • 51.
    Use the characterisation of packing dimension to show dimP(ℚ ∩ [0, 1]) = 0, and contrast with box dimension.
  • 52.
    Let λ₁, λ₂ be the multipliers of the two fixed points of fc, both different from 1. Prove that 1/(1 − λ₁) + 1/(1 − λ₂) = 0, and deduce that if one fixed point is attracting the other is repelling.
  • 53.
    Prove that ρ(x) = 1/(π√(x(1 − x))) is an invariant density for the logistic map g₄.
  • 54.
    Compute the Lyapunov exponent ∫ log|g₄′(x)| ρ(x) dx of g₄ with respect to the invariant density.
  • 55.
    Show that the zero set Z of linear Brownian motion on [0, 1] satisfies dimH Z ≤ 1/2 almost surely, using P(B has a zero in [t, t + h]) = (2/π) arctan √(h/t).
  • 56.
    Compute E|Z|−s for a standard normal vector Z in ℝ², and use it to complete the energy argument showing that the planar Brownian path has dimension 2.
  • 57.
    For the binomial measure with p = 1/3, compute f(1), the dimension of the set of points with local dimension exactly 1.
  • 58.
    Estimate r∞ from r₄ = 3.564407 and r₅ = 3.568759 by assuming the gaps rk+1 − rk decrease exactly geometrically with ratio 1/δ.
  • 59.
    Let F be the attractor of an IFS of similarities satisfying the OSC, with similarity dimension s. Prove that 𝓗ˢ(fi(F) ∩ fj(F)) = 0 for i ≠ j.
  • 60.
    Prove that dimB̄ F ≤ s for every IFS of similarities, whether or not it satisfies the OSC, and give an example with dimH F < s.
