Computing Hausdorff Dimension — The Cantor Set and the Mass Distribution Principle

Lesson 7 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

Upper bounds come from exhibiting covers.
Lower bounds come from measures:  μ(U) ≤ c|U|ˢ for all small U  ⇒  𝓗ˢ(F) ≥ μ(F)/c.

Upper bounds are easy, lower bounds are hard

To show dimH F ≤ s it suffices to exhibit, for each δ, one δ-cover with ∑|Ui|ˢ bounded. To show dimH F ≥ s one must control every cover, and covers can be cleverly shaped. The standard way around this is to construct a measure on F that is spread out evenly enough that no set can carry much of it relative to its size.

Theorem 7.1 (Mass distribution principle). Let μ be a finite Borel measure with μ(F) > 0, and suppose there are c > 0 and δ₀ > 0 such that μ(U) ≤ c|U|ˢ for all sets U with |U| ≤ δ₀. Then 𝓗ˢ(F) ≥ μ(F)/c, and in particular dimH F ≥ s.

Proof. If {Ui} is any δ-cover of F with δ ≤ δ₀, then μ(F) ≤ μ(⋃Ui) ≤ ∑ μ(Ui) ≤ c ∑|Ui|ˢ (replacing each Ui by its closure if necessary, so that it is Borel, without changing its diameter). Taking the infimum, 𝓗ˢδ(F) ≥ μ(F)/c for all δ ≤ δ₀, and letting δ → 0 gives the claim. ∎

The middle-third Cantor set

Let C = ⋂k Ck, where Ck is the union of the 2k closed intervals of length 3−k remaining after k steps of removing open middle thirds. Put s = log 2 / log 3, so that 3ˢ = 2 and 2k (3−k)ˢ = 1.

Theorem 7.2. 1/2 ≤ 𝓗ˢ(C) ≤ 1. In particular dimH C = dimB C = log 2 / log 3 ≈ 0.6309.

Proof. Upper bound: the 2k level-k intervals cover C and have diameter 3−k, so 𝓗ˢ3−k(C) ≤ 2k 3−ks = 1. Letting k → ∞, 𝓗ˢ(C) ≤ 1.

Lower bound: let μ be the Cantor measure, the unique Borel probability measure giving mass 2−k to each level-k interval (equivalently, the distribution of ∑ 2Xk 3−k with Xk independent fair bits, or the Lebesgue–Stieltjes measure of the Cantor function). Two facts about the geometry: level-k intervals have length 3−k, and any two distinct level-k intervals are separated by a gap of length at least 3−k, since the gaps created at step j ≤ k have length 3−j ≥ 3−k.

Let U be a set with 0 < |U| < 1, and let k ≥ 0 be the integer with 3−(k+1) ≤ |U| < 3−k. Because the gaps between level-k intervals are at least 3−k > |U|, the set U meets at most one level-k interval. Hence

μ(U) ≤ 2−k = (3−k)ˢ = 3ˢ (3−(k+1))ˢ ≤ 3ˢ |U|ˢ = 2|U|ˢ

By the mass distribution principle with c = 2, 𝓗ˢ(C) ≥ μ(C)/2 = 1/2. Since 0 < 𝓗ˢ(C) < ∞, dimH C = s. The box dimension is squeezed between dimH C = s and the covering bound N3−k(C) ≤ 2k, so it equals s too. ∎

With more work one shows 𝓗ˢ(C) = 1 exactly: one reduces an arbitrary finite cover by intervals to a cover by level-k intervals without increasing ∑|Ui|ˢ, using the concavity of t ↦ tˢ (Falconer, Fractal Geometry, Example 2.7, proves the bounds above and outlines the sharp value). Exact values of Hausdorff measures are known for few fractals; for the Sierpinski triangle only numerical bounds are known.

Frostman's lemma

The mass distribution principle has a converse, which makes it the universal method.

Theorem 7.3 (Frostman, 1935). Let F ⊂ ℝⁿ be a Borel set with 𝓗ˢ(F) > 0. Then there exist a compact E ⊂ F, a Borel probability measure μ supported on E, and a constant c, such that μ(B(x, r)) ≤ c rˢ for all x ∈ ℝⁿ and r > 0.

For compact F the proof builds μ on dyadic cubes: start at a fine scale 2−k with mass |Q|ˢ on each dyadic cube Q of side 2−k meeting F, then move up the dyadic tree, scaling down the mass in any cube Q whose total exceeds |Q|ˢ. The resulting measure satisfies μ(Q) ≤ |Q|ˢ for every dyadic cube, and the maximal cubes in which a scaling occurred, together with the unscaled fine cubes, cover F and carry their full allotted mass; so the total mass is at least a constant times the dyadic Hausdorff content of F, which is positive. A weak-* limit as k → ∞ gives the measure.

The energy method

For a measure μ, the s-energy is

Is(μ) = ∫∫ |x − y|−s dμ(x) dμ(y)

Theorem 7.4. If F supports a probability measure with Is(μ) < ∞, then dimH F ≥ s. Conversely, if dimH F > s, then F supports a probability measure with Is(μ) < ∞. Hence dimH F = sup{ s : F supports μ with Is(μ) < ∞ }, the capacitary characterisation of Hausdorff dimension.

Proof of the first statement. The potential φ(x) = ∫|x − y|−s dμ(y) is finite for μ-almost every x, so there is M with E = {x : φ(x) ≤ M} satisfying μ(E) > 1/2. For x ∈ E and any r > 0, μ(B(x, r)) r−s ≤ ∫B(x,r) |x − y|−s dμ(y) ≤ M. If U meets E and x ∈ U ∩ E, then U ⊂ B(x, |U|), so the restriction ν of μ to E satisfies ν(U) ≤ M|U|ˢ. The mass distribution principle applied to ν gives 𝓗ˢ(F) ≥ ν(E)/M > 0. ∎

For the converse, apply Frostman's lemma at a dimension t with s < t < dimH F: if μ(B(x, r)) ≤ c rᵗ, then ∫|x − y|−s dμ(y) = ∫₀∞ μ{y : |x − y|−s > u} du is bounded uniformly in x, since the integrand is at most min{1, c u−t/s} and t/s > 1. The energy method is the main tool for random fractals, because the expected energy of a random measure is often computable by Fubini's theorem even when nothing about individual covers is. We use it for Brownian motion in Lesson 12.

Digit frequencies

Theorem 7.5 (Besicovitch 1934, Eggleston 1949). Let b ≥ 2 and let p₀, …, pb−1 ≥ 0 sum to 1. The set of x ∈ [0, 1] whose base-b expansion contains each digit i with asymptotic frequency pi has Hausdorff dimension

−∑i pi log pi / log b

that is, its entropy divided by log b. For example, the numbers whose binary digits have asymptotic frequency 1/3 of ones have dimension (log 3 − (2/3) log 2)/log 2 ≈ 0.9183. The proof of the lower bound applies a local form of the mass distribution principle, due to Billingsley, to the Bernoulli measure with weights pi, using the strong law of large numbers to estimate the measure of b-adic intervals.

Exercise

  • (a)
    Show that the middle-λ Cantor set (remove the open middle interval of relative length λ at each stage, 0 < λ < 1) has Hausdorff dimension log 2 / log(2/(1 − λ)). Evaluate it for λ = 1/2.
  • (b)
    Find the Hausdorff dimension of the set of x ∈ [0, 1] whose decimal expansion never uses the digit 7.
  • (c)
    Explain why the mass distribution principle is needed even though covers by level-k intervals give the correct exponent.
  • (d)
    Show that the Cantor measure satisfies μ([0, x]) = xˢ for x of the form 3−k, and deduce that μ(B(0, r)) ≤ 2rˢ for all 0 < r < 1.
Show solution

Answers: (a) The set is generated by two similarities of ratio r = (1 − λ)/2 with disjoint images. The level-k intervals have length rk and are separated by gaps of length at least λ rk−1 > λ rk. Repeating the proof of Theorem 7.2 with this separation, a set U with λ rk+1 ≤ |U| < λ rk meets at most one level-k interval, so μ(U) ≤ 2−k = (rk)ˢ ≤ (λr)−s|U|ˢ, where s = log 2/log(1/r). Hence dimH = log 2 / log(2/(1 − λ)); for λ = 1/2 it is log 2 / log 4 = 1/2. (b) Nine similarities of ratio 1/10 satisfying the OSC with V = (0, 1), so log 9 / log 10 ≈ 0.9542. (c) Covers by level-k intervals give only an upper bound; an arbitrary cover might use sets of many different sizes and be more efficient. The measure controls every cover simultaneously. (d) [0, 3−k] is a level-k interval, of mass 2−k = (3−k)ˢ. For 0 < r < 1, choose k with 3−(k+1) ≤ r < 3−k; the part of C in B(0, r) lies in [0, r] ⊂ [0, 3−k], so μ(B(0, r)) ≤ 2−k = 2·(3−(k+1))ˢ ≤ 2rˢ.
