Julia Sets of Quadratic Polynomials

Lesson 9 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

For fc(z) = z² + c, the filled Julia set is Kc = { z ∈ ℂ : (fcⁿ(z)) is bounded },
and the Julia set is Jc = ∂Kc.
If |z| > max{2, |c|}, then fcⁿ(z) → ∞.

The fractals of Lessons 2–8 were defined by contractions. Julia sets arise from the opposite mechanism: a single expanding map whose repelling behaviour on a compact invariant set creates fine structure at all scales. Their study was founded by Pierre Fatou and Gaston Julia around 1918–1920, using Montel's theory of normal families, decades before the first computer pictures.

Escape radius

Lemma 9.1. Let R = max{2, |c|}. If |z| > R, then |fcⁿ(z)| ≥ λⁿ |z| with λ = |z| − 1 > 1; in particular fcⁿ(z) → ∞.

Proof. Since |c| ≤ R < |z|,

|z² + c| ≥ |z|² − |c| > |z|² − |z| = |z|(|z| − 1) = λ|z|

So |fc(z)| > λ|z| > |z| > R. The point fc(z) again satisfies the hypothesis, and |fc(z)| − 1 > |z| − 1 = λ, so by induction |fcⁿ(z)| > λⁿ|z|. ∎

Corollary 9.2. Kc = ⋂n≥0 fc−n(D̄R), where D̄R is the closed disc of radius R. Hence Kc is compact; it is non-empty because it contains the fixed points of fc; and it is completely invariant: fc−1(Kc) = Kc = fc(Kc).

Proof. A point outside D̄R escapes by Lemma 9.1, and so does any point with some iterate outside D̄R; conversely a point whose orbit stays in D̄R has bounded orbit. Each fc−n(D̄R) is closed, and they are nested because fc−1(D̄R) ⊂ D̄R (if |z| > R then |fc(z)| > R). Complete invariance holds because z and fc(z) have the same orbit from the second term on, and fc is surjective. ∎

The escape-time pictures of Julia sets colour each z by the first n with |fcⁿ(z)| > R; by Lemma 9.1 this is a rigorous test.

Fatou and Julia sets

The Fatou set Fc is the set of z having a neighbourhood on which the iterates {fcⁿ} form a normal family (every sequence has a subsequence converging locally uniformly, possibly to ∞). For polynomials, the Julia set Jc = ℂ \ Fc coincides with ∂Kc: on the interior of Kc the iterates are uniformly bounded, hence normal by Montel's theorem, and on ℂ \ Kc they converge to ∞ locally uniformly; at a point of ∂Kc, any neighbourhood contains points with bounded orbits and points escaping, so no subsequence converges locally uniformly.

Theorem 9.3 (Fatou, Julia). Jc is a non-empty, compact, perfect, completely invariant set with empty interior. It is the closure of the set of repelling periodic points. For every z ∈ Jc, the backward orbit ⋃ₙ fc−n(z) is dense in Jc; and for every open U meeting Jc, ⋃ₙ fcⁿ(U) covers ℂ except at most one point.

The last property, a consequence of Montel's theorem that a family of holomorphic maps omitting two values is normal, says that Jc is where the dynamics is chaotic: arbitrarily small neighbourhoods of a point of Jc are eventually spread over the whole plane. The density of backward orbits gives the inverse iteration method for drawing Jc: iterate z ↦ ±√(z − c) with random signs, exactly as in the chaos game of Lesson 3. Indeed, when c ∉ M (Lesson 10) the two branches of fc−1 are contractions in a suitable metric, and Jc is literally the attractor of a non-linear IFS.

Two exactly solvable examples

For c = 0, f₀(z) = z². Points with |z| < 1 converge to 0, points with |z| > 1 escape, and the unit circle is invariant, so K₀ is the closed unit disc and J₀ is the unit circle. In the angle coordinate z = e2πiθ, f₀ acts on J₀ as the doubling map θ ↦ 2θ mod 1, which is chaotic.

For c = −2, consider the substitution z = w + 1/w with |w| ≥ 1, which maps {|w| > 1} conformally onto ℂ \ [−2, 2] and the unit circle two-to-one onto [−2, 2]. Then

f₋₂(w + 1/w) = w² + 2 + w−2 − 2 = w² + w−2

so f₋₂ is conjugate on ℂ \ [−2, 2] to w ↦ w² on {|w| > 1}, and every point off [−2, 2] escapes. On [−2, 2], writing z = 2 cos θ, f₋₂(2 cos θ) = 4 cos²θ − 2 = 2 cos 2θ, so [−2, 2] is invariant. Hence K₋₂ = J₋₂ = [−2, 2], a segment of dimension 1, and f₋₂ on it is a Chebyshev polynomial semiconjugate to angle doubling.

Fixed points and multipliers

The fixed points of fc are the roots of z² − z + c = 0,

z± = (1 ± √(1 − 4c))/2,   with multipliers λ± = fc′(z±) = 2z±,   λ₊ + λ₋ = 2

A periodic point of period p with multiplier λ = (fcᵖ)′(z) is attracting if |λ| < 1 (superattracting if λ = 0), repelling if |λ| > 1, and indifferent if |λ| = 1. Since λ₊ + λ₋ = 2, at most one fixed point can be attracting.

Theorem 9.4 (Fatou). The immediate basin of every attracting cycle of a polynomial contains a critical point.

Since fc has a single critical point, 0, it has at most one attracting cycle, and if it has one, the orbit of 0 converges to it. The critical orbit governs everything — the observation that leads to the Mandelbrot set.

The fundamental dichotomy

Theorem 9.5 (Fatou, Julia). (i) If the critical orbit (fcⁿ(0)) is bounded, then Kc and Jc are connected. (ii) If fcⁿ(0) → ∞, then Kc = Jc is a Cantor set: compact, perfect and totally disconnected.

Proof sketch. Let D = D̄R with R as in Lemma 9.1 (enlarged slightly so that its boundary avoids the critical orbit), and Dₙ = fc−n(D), so that Kc = ⋂ Dₙ. The map fc : Dn+1 → Dₙ is a proper holomorphic map of degree 2 branched only over the critical value c. By the Riemann–Hurwitz formula, if Dₙ is a closed topological disc containing c, then Dn+1 is a closed topological disc; if Dₙ is a disc not containing c, then Dn+1 consists of two disjoint discs, each mapped conformally onto Dₙ.

  • (i)
    If the critical orbit is bounded, it lies in Kc, so c = fc(0) ∈ Dₙ for every n, and every Dₙ is a disc. A nested intersection of compact connected sets is connected, so Kc is connected, and so is its boundary Jc (for a compact connected set in the plane whose complement is connected, the boundary is connected).
  • (ii)
    If the critical orbit escapes, then c ∉ DN for some N, so DN+1 splits into two discs, DN+2 into four, and so on. The inverse branches of fc on these discs are uniformly contracting in the hyperbolic metric of DN, so the components of Dₙ have diameters tending to zero, and Kc is a Cantor set — the attractor of a two-map conformal IFS. In particular Kc has no interior, so Kc = Jc. ∎

For |c| large the two inverse branches z ↦ ±√(z − c) contract by a factor of about 1/(2|c|1/2) on Jc, and a conformal version of Moran's equation gives dimH Jc ~ 2 log 2 / log |c| as |c| → ∞.

Dimension of Julia sets

For c = 0 and c = −2 the Julia set is smooth and has dimension 1; these are the only real-analytic Julia sets in the family. For small c ≠ 0, Jc is a quasicircle — a Jordan curve that is the image of the circle under a quasiconformal map — whose dimension is strictly greater than 1. Ruelle (1982) proved

dimH Jc = 1 + |c|²/(4 log 2) + o(|c|²)   as c → 0

using the thermodynamic formalism: for hyperbolic c, dimH Jc is the unique zero t of the pressure function P(−t log|fc′|), Bowen's formula (1979). At the other extreme, Shishikura (1998) proved that there are parameters c with dimH Jc = 2, and Buff and Chéritat (2012) constructed quadratic Julia sets of positive Lebesgue measure.

Exercise

  • (a)
    Show that the critical orbit for c = i is eventually periodic, and conclude that Ki is connected.
  • (b)
    Find the fixed points of fc for c = −3/4 and classify them.
  • (c)
    For c = −2, verify that 2 cos(2π/7), 2 cos(4π/7), 2 cos(6π/7) form a cycle of period 3. Is it repelling?
  • (d)
    For c = 0.3, is Jc connected?
Show solution

Answers: (a) 0 ↦ i ↦ i² + i = −1 + i ↦ (−1 + i)² + i = −2i + i = −i ↦ (−i)² + i = −1 + i. So the orbit is 0, i, −1 + i, −i, −1 + i, −i, …, bounded, and Ki is connected by Theorem 9.5 (it is a dendrite with empty interior). (b) z² − z − 3/4 = 0 gives z = 3/2 and z = −1/2, with multipliers 3 (repelling) and −1 (indifferent; parabolic, since −1 is a root of unity). (c) With z = 2 cos θ, f₋₂ doubles θ: 2π/7 → 4π/7 → 8π/7, and cos(8π/7) = cos(6π/7); then 12π/7 ≡ −2π/7 gives cos(12π/7) = cos(2π/7). So the three points form a 3-cycle. The multiplier is ∏ 2zi = 8·∏ 2cos(2πk/7) = 8·8·cos(2π/7)cos(4π/7)cos(6π/7) = 8·8·(1/8) = 8, so the cycle is repelling, as every cycle in J₋₂ other than the fixed point 2 must be: differentiating f₋₂ᵖ(2 cos θ) = 2 cos(2ᵖθ) shows a period-p cycle off ±2 has multiplier ±2ᵖ. (d) No: 0 ↦ 0.3 ↦ 0.39 ↦ 0.4521 ↦ … The real orbit of 0 for real c > 1/4 is increasing with no fixed point to converge to (z² + c > z for all real z when 1 − 4c < 0), so it escapes and J0.3 is a Cantor set.
