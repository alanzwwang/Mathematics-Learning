Box-Counting Dimension

Lesson 5 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

dimB F = limδ→0 log Nδ(F) / (−log δ),
where Nδ(F) is the least number of sets of diameter at most δ that cover F.
Upper and lower box dimensions use lim sup and lim inf.

Definitions

Let F ⊂ ℝⁿ be non-empty and bounded, and let Nδ(F) be the smallest number of sets of diameter at most δ that cover F. The lower and upper box-counting dimensions are

dimB̲ F = lim infδ→0 log Nδ(F) / (−log δ)
dimB̄ F = lim supδ→0 log Nδ(F) / (−log δ)

and when they agree the common value is the box-counting (or box, or Minkowski–Bouligand) dimension dimB F. Informally, Nδ(F) ≈ δ−d with d = dimB F: a curve of dimension 1 needs about δ⁻¹ boxes, a surface about δ⁻², and the Koch curve about δ−1.2619.

Equivalent forms

Proposition 5.1. The box dimensions are unchanged if Nδ(F) is replaced by any of: (i) the number of δ-mesh cubes [m₁δ, (m₁+1)δ] × ⋯ × [mₙδ, (mₙ+1)δ] that meet F; (ii) the smallest number of closed balls of radius δ that cover F; (iii) the largest number of disjoint closed balls of radius δ with centres in F.

Proof. Each count is bounded above and below by constant multiples of the others at comparable scales, and such constants disappear in the limit because log(cδ)/log δ → 1. For (i): a mesh cube of side δ has diameter δ√n, so Nδ√n(F) ≤ N′δ(F); and a set of diameter at most δ lies in at most 3ⁿ mesh cubes of side δ, so N′δ(F) ≤ 3ⁿ Nδ(F). For (ii): a ball of radius δ has diameter 2δ, and a set of diameter δ lies in a ball of radius δ. For (iii): let B(x₁, δ), …, B(xk, δ) be a maximal disjoint family with centres in F. By maximality every point of F lies within 2δ of some xi, so the balls B(xi, 2δ), of diameter 4δ, cover F and N4δ(F) ≤ k. Conversely, the centres are more than 2δ apart, so a set of diameter at most δ contains at most one of them; since each centre lies in some set of a minimal δ-cover, k ≤ Nδ(F). ∎

A further simplification: it suffices to let δ → 0 through a geometric sequence δk = ck (0 < c < 1). If ck+1 ≤ δ < ck, then Nck ≤ Nδ ≤ Nck+1, and log Nδ / (−log δ) is squeezed between log Nck / (−(k+1) log c) and log Nck+1 / (−k log c), whose limits coincide.

Worked example: the Koch curve. At scale δ = 3−k, the curve is covered by its 4k level-k pieces, each of diameter 3−k, so N3−k ≤ 4k. Conversely, the level-k pieces satisfy the open set condition, and a volume argument (Lemma 8.1 below) shows that a set of diameter 3−k meets at most a bounded number M of them; hence N3−k ≥ 4k / M. Therefore

dimB K = lim log 4k / log 3k = log 4 / log 3 ≈ 1.2619

Minkowski content and parallel bodies

A second classical formulation uses the volume of the δ-parallel body Fδ = {x : d(x, F) ≤ δ}. One shows

dimB̄ F = n − lim infδ→0 log Lⁿ(Fδ) / log δ
dimB̲ F = n − lim supδ→0 log Lⁿ(Fδ) / log δ

where Lⁿ is Lebesgue measure. The idea: Fδ is covered by the Nδ(F) sets of diameter δ, each fattened to diameter 3δ, so Lⁿ(Fδ) ≤ c Nδ(F) δⁿ; and Fδ contains the disjoint balls of (iii), so Lⁿ(Fδ) ≥ c′ N′′δ(F) δⁿ with N′′ the packing count. When Lⁿ(Fδ) ~ M δn−d with 0 < M < ∞, the constant M is (up to normalisation) the d-dimensional Minkowski content of F. For the middle-third Cantor set the ratio L¹(Cδ)/δ1−d oscillates and does not converge, a phenomenon called lacunarity; for self-similar subsets of ℝ the Minkowski content exists precisely when the logarithms of the ratios ri do not all lie in a common lattice aℤ (Lapidus and van Frankenhuijsen; Falconer 1995).

The sequence {1/k}

Proposition 5.2. Let F = {0} ∪ {1/k : k ∈ ℕ}. Then dimB F = 1/2.

Proof. The gap between 1/k and 1/(k + 1) is 1/(k(k + 1)), which decreases in k. Fix a small δ > 0 and let K be the largest integer with K(K + 1) < 1/δ; then K ~ δ−1/2.

Lower bound: the gaps between consecutive points among 1, 1/2, …, 1/(K + 1) are all at least 1/(K(K + 1)) > δ, so these K + 1 points are pairwise more than δ apart, and a set of diameter at most δ contains at most one of them. Hence Nδ(F) ≥ K + 1.

Upper bound: by maximality of K, (K + 1)(K + 2) ≥ 1/δ. Cover the K points 1, …, 1/K by K singletons, and the rest of F, which lies in [0, 1/(K + 1)], by at most 1/((K + 1)δ) + 1 ≤ K + 3 intervals of length δ. Hence Nδ(F) ≤ 2K + 3.

Since K + 1 ≤ Nδ(F) ≤ 2K + 3 and K ~ δ−1/2, log Nδ(F)/(−log δ) → 1/2. ∎

The same argument shows that {0} ∪ {k−p : k ∈ ℕ} has box dimension 1/(1 + p) for every p > 0: the gap after k−p is about p k−p−1, so the points are δ-separated for k ≲ δ−1/(p+1), and the remaining interval [0, k−p] has length about δp/(p+1), which needs about δ−1/(p+1) intervals of length δ.

Properties and defects

Proposition 5.3. (a) dimB̲ and dimB̄ are monotone, and dimB̄ is finitely stable: dimB̄(E ∪ F) = max{dimB̄ E, dimB̄ F}. (b) If f is Lipschitz then dimB̄ f(F) ≤ dimB̄ F, and bi-Lipschitz maps preserve both box dimensions. (c) dimB̲ F̄ = dimB̲ F and dimB̄ F̄ = dimB̄ F, where F̄ is the closure of F.

Proof. (a) Nδ(E ∪ F) ≤ Nδ(E) + Nδ(F) ≤ 2 max{Nδ(E), Nδ(F)}. (b) If f is L-Lipschitz, the images of a δ-cover form an Lδ-cover. (c) The closure of a set of diameter δ has diameter δ, so a finite cover of F by closed sets of diameter at most δ also covers F̄. ∎

Property (c) is the decisive defect. The rationals in [0, 1] form a countable set with closure [0, 1], so their box dimension is 1; but a countable set should be "zero-dimensional". Box dimension is not countably stable: ℚ ∩ [0, 1] is a countable union of points of dimension 0, yet has dimension 1. The set {1/k} shows the same defect more subtly. Box dimension is nevertheless indispensable: it is computable, it is what experimentalists estimate from log–log plots, and for most well-behaved self-similar sets it coincides with the Hausdorff dimension defined next.

Exercise

  • (a)
    Compute the box dimension of the Sierpinski triangle by counting at scales 2−k.
  • (b)
    Find dimB of {0} ∪ {k−2 : k ∈ ℕ}, and of {0} ∪ {2−k : k ∈ ℕ}.
  • (c)
    Give a compact set whose lower and upper box dimensions differ.
  • (d)
    Show that if dimB̲ F < n then F has Lebesgue measure zero.
Show solution

Answers: (a) At level k the triangle is covered by its 3k level-k pieces, each of diameter 2−k times the side, and by the open set condition a set of diameter 2−k meets boundedly many of them, so N ≍ 3k at scale 2−k, and dimB = log 3 / log 2 ≈ 1.585. (b) 1/(1 + 2) = 1/3 for k−2. For 2−k: at scale δ the points 2−k > 2δ are δ-separated, and there are about log₂(1/δ) of them, while [0, 2δ] needs 2 more intervals; so Nδ ~ log₂(1/δ), and dimB = 0. (c) Let F ⊂ [0, 1] be the set of x whose decimal digit in position k is 0 whenever (2j)! < k ≤ (2j + 1)! for some j, with the other digits arbitrary. At δ = 10−k we have Nδ(F) ≍ 10a(k), where a(k) is the number of free positions up to k. At k = (2j + 1)!, a(k) ≤ (2j)! = o(k); at k = (2j + 2)!, a(k) ≥ k − (2j + 1)! = k(1 − o(1)). Hence dimB̲ F = 0 and dimB̄ F = 1. (d) Lⁿ(F) ≤ Lⁿ(Fδ) ≤ c Nδ(F) δⁿ. If dimB̲ F < s < n, then Nδ(F) ≤ δ−s along a sequence δ → 0, so Lⁿ(F) ≤ c δn−s → 0 along that sequence.
