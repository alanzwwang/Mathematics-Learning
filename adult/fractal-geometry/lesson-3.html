Coding, Addresses and the Chaos Game

Lesson 3 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

The coding map π : {1, …, N}ℕ → F,
π(i₁i₂i₃…) = limn→∞ fi₁ ∘ fi₂ ∘ ⋯ ∘ fiₙ(x₀)
is a continuous surjection from the symbol space onto the attractor.

Symbolic space

Let Σ = {1, …, N}ℕ be the space of infinite words i = i₁i₂i₃… with the metric ρ(i, j) = 2−k, where k is the length of the longest common prefix of i and j (and ρ(i, i) = 0). Then Σ is a compact metric space homeomorphic to the Cantor set; the cylinder sets [i₁…iₙ] = {j : j₁ = i₁, …, jₙ = iₙ} are the closed (and open) balls. Write fi₁…iₙ = fi₁ ∘ ⋯ ∘ fiₙ and Fi₁…iₙ = fi₁…iₙ(F).

Theorem 3.1. For every i ∈ Σ, the sets Fi₁…iₙ are nested and |Fi₁…iₙ| ≤ cⁿ|F| → 0, so ⋂ₙ Fi₁…iₙ is a single point π(i). The map π : Σ → F is continuous and surjective, and π(i) = lim fi₁…iₙ(x₀) for every x₀ ∈ X.

Proof. Nesting: Fi₁…iₙ₊₁ = fi₁…iₙ(fiₙ₊₁(F)) ⊂ fi₁…iₙ(F) because fj(F) ⊂ F. The diameter bound follows from Lemma 1.4. A nested sequence of non-empty compact sets with diameters tending to 0 has one-point intersection. If ρ(i, j) ≤ 2−n, then π(i), π(j) ∈ Fi₁…iₙ, so |π(i) − π(j)| ≤ cⁿ|F|: π is uniformly continuous. Surjectivity: iterating F = ⋃ fi(F) gives F = ⋃|w|=n Fw for each n, so a point x ∈ F lies in some Fi₁ ∩ Fi₁i₂ ∩ ⋯ by König's lemma (or compactness of Σ). Finally, both fi₁…iₙ(x₀) and π(i) lie in fi₁…iₙ(F ∪ {x₀}), whose diameter is at most cⁿ|F ∪ {x₀}| → 0, which gives the last claim. ∎

For the Cantor set, π(i₁i₂…) = ∑ 2(ik − 1) 3−k: the attractor consists exactly of the numbers in [0, 1] having a ternary expansion with digits 0 and 2 only, and π is a homeomorphism. For the interval [0, 1] with the two halving maps, π is the binary expansion map, which is two-to-one at dyadic rationals; so coding maps need not be injective, and the failure of injectivity is measured precisely by how much the pieces fi(F) overlap.

Shift dynamics

The left shift σ(i₁i₂i₃…) = i₂i₃… satisfies π(i) = fi₁(π(σi)). When the pieces fi(F) are pairwise disjoint (the strong separation condition), π is a homeomorphism and the map g : F → F defined by g = fi⁻¹ on fi(F) is conjugate to σ. Since the shift has a dense orbit and dense periodic points and is sensitive to initial conditions, g is chaotic in the sense of Devaney; this is the first example of the link between fractal sets and chaotic dynamics that Lessons 9–11 develop.

The chaos game

Fix probabilities p₁, …, pN > 0 with ∑ pi = 1. Start at x₀ ∈ X, and repeatedly set xk+1 = fik(xk), where i₀, i₁, i₂, … are independent with P(ik = j) = pj. Note the order: the new map is applied on the outside, so xk = fik−1 ∘ ⋯ ∘ fi₀(x₀) — this is a backward composition relative to π, which is why the points xk do not converge but wander over F.

Theorem 3.2 (Elton, 1987, in simplified form). With probability one, the orbit {xk} accumulates on all of F; indeed d(xk, F) ≤ ck d(x₀, F), and every cylinder Fw is visited infinitely often. Moreover the empirical measures (1/n)∑k<n δxk converge weakly to the self-similar measure μ, the unique Borel probability measure with

μ = ∑i=1N pi · μ ∘ fi⁻¹

Proof of the first part. d(xk+1, F) ≤ d(fik(xk), fik(F)) ≤ c d(xk, F), since fik(F) ⊂ F. For a fixed word w = w₁…wm, the event that the next m symbols are wm, …, w₁ (in that order, so that xk+m = fw₁…wm(xk)) has probability pw₁⋯pwm > 0 independently in disjoint blocks, so by the second Borel–Cantelli lemma it happens infinitely often; when it happens, xk+m lies within cm d(xk, F) + (diameter of Fw) of Fw. ∎

The existence and uniqueness of μ is itself a contraction argument: on the space of Borel probability measures on F with the Wasserstein (Kantorovich–Rubinstein) metric, the operator ν ↦ ∑ pi ν ∘ fi⁻¹ is a contraction with ratio c. The measure μ is the image under π of the Bernoulli product measure (p₁, …, pN)ℕ on Σ. Self-similar measures reappear as the prototypical multifractals in Lesson 13.

Exercise

  • (a)
    Find π(1222…) and π(2111…) for the Cantor IFS, and explain why the coding map is nevertheless injective.
  • (b)
    For the IFS x ↦ x/2, x ↦ x/2 + 1/2, show that π(1222…) = π(2111…).
  • (c)
    For the Sierpinski IFS fi(x) = (x + pi)/2, which point has address 123123123…?
Show solution

Answers: (a) π(1222…) = ∑k≥2 2·3−k = 2·(1/9)/(2/3) = 1/3, and π(2111…) = 2/3. Different words give different points because the two first-level pieces [0, 1/3] and [2/3, 1] are disjoint, and by self-similarity the same holds at every level. (b) π(1222…) = ∑k≥2 2−k = 1/2 = π(2111…), the two binary expansions 0.0111… and 0.1000… of 1/2. (c) It is the fixed point of f₁ ∘ f₂ ∘ f₃, namely x = f₁(f₂(f₃(x))) = x/8 + p₃/8 + p₂/4 + p₁/2, so x = (4p₁ + 2p₂ + p₃)/7.
