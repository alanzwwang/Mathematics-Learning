The Mandelbrot Set

Lesson 10 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

M = { c ∈ ℂ : (fcⁿ(0)) is bounded } = { c : Kc is connected }
M ⊂ { |c| ≤ 2 },   c ∈ M  ⇔  |fcⁿ(0)| ≤ 2 for all n,   M ∩ ℝ = [−2, 1/4]

By the dichotomy of Theorem 9.5, the parameter plane splits into the parameters for which Kc is connected and those for which it is a Cantor set. The first set is the Mandelbrot set M, the connectedness locus of the quadratic family. It was first drawn by Brooks and Matelski (1978) and made famous by Mandelbrot (1980); its systematic theory was created by Douady and Hubbard in the Orsay notes (1984–1985).

The radius-2 criterion

Theorem 10.1. If |c| > 2 then c ∉ M. If |c| ≤ 2, then c ∈ M if and only if |fcⁿ(0)| ≤ 2 for every n. Consequently M is a compact subset of the closed disc of radius 2.

Proof. Write zₙ = fcⁿ(0), so z₁ = c and z₂ = c² + c. Suppose |c| > 2. Then |z₂| ≥ |c|² − |c| = |c|(|c| − 1) > |c| > 2, so z₂ satisfies |z₂| > max{2, |c|}, and the orbit escapes by Lemma 9.1. Now suppose |c| ≤ 2. If |zₙ| > 2 for some n, then |zₙ| > 2 = max{2, |c|}, and the orbit escapes. Conversely if c ∈ M then all |zₙ| ≤ 2, since otherwise the orbit would escape. Finally M = ⋂ₙ {c : |fcⁿ(0)| ≤ 2}, an intersection of closed sets (each fcⁿ(0) is a polynomial in c), contained in the closed disc of radius 2. ∎

The real slice

Theorem 10.2. M ∩ ℝ = [−2, 1/4].

Proof. If c > 1/4, then z² − z + c > 0 for all real z, since the discriminant 1 − 4c is negative. So the real orbit of 0 is strictly increasing; a bounded increasing sequence would converge to a fixed point of fc, of which there are none on ℝ. So the orbit is unbounded. If c < −2, then z₁ = c and z₂ = c² + c = |c|(|c| − 1) > |c| > 2, so the orbit escapes.

Now let −2 ≤ c ≤ 1/4 and β = (1 + √(1 − 4c))/2, the larger fixed point; β ≥ 1/2. We claim fc maps I = [−β, β] into itself. On I, fc(z) = z² + c ranges over [c, β² + c] = [c, β], so it suffices to show c ≥ −β, i.e. √(1 − 4c) ≥ −2c − 1. If c ≥ −1/2 the right side is at most 0, and the inequality holds. If −2 ≤ c < −1/2, both sides are non-negative and squaring gives 1 − 4c ≥ 4c² + 4c + 1, i.e. 0 ≥ 4c(c + 2), which holds for −2 ≤ c ≤ 0. Since 0 ∈ I, the orbit of 0 stays in I and is bounded. ∎

Hyperbolic components

A parameter c is hyperbolic if fc has an attracting cycle. The set of hyperbolic parameters in M is open, and its connected components are the hyperbolic components; each has a well-defined period p, and the multiplier map λ : W → 𝔻, sending c to the multiplier of its attracting p-cycle, is a conformal isomorphism onto the unit disc (Douady–Hubbard). The parameter λ⁻¹(0) is the centre of W, where 0 itself is periodic.

The main cardioid. fc has an attracting fixed point z with multiplier μ = 2z, |μ| < 1, exactly when c = z − z² with z = μ/2:

c = μ/2 − μ²/4,   |μ| < 1

The boundary, traced by μ = eiθ, is a cardioid with cusp at c = 1/4 (μ = 1) and leftmost point c = −3/4 (μ = −1). Its centre is c = 0.

The period-2 disc. The 2-cycles of fc are the roots of fc²(z) − z divided by the fixed-point factor:

fc²(z) − z = (z² − z + c)(z² + z + c + 1)

The roots z₁, z₂ of z² + z + c + 1 satisfy z₁ + z₂ = −1 and z₁z₂ = c + 1, so the multiplier of the 2-cycle is (fc²)′ = fc′(z₁) fc′(z₂) = 4z₁z₂ = 4(c + 1). The cycle is attracting exactly when |c + 1| < 1/4: the hyperbolic component of period 2 is the open disc of radius 1/4 centred at −1, tangent to the cardioid at c = −3/4.

Bulbs. At each point c(θ) = eiθ/2 − e2iθ/4 of the cardioid with θ = 2πp/q (p/q in lowest terms), a fixed point becomes parabolic with multiplier a primitive q-th root of unity, and a hyperbolic component of period q is attached there, the p/q-bulb. For example, the 1/3-bulb is attached at

c = e2πi/3/2 − e4πi/3/4 = −1/8 + (3√3/8) i ≈ −0.125 + 0.6495 i

Connectedness and the Böttcher map

Theorem 10.3 (Douady–Hubbard, 1982). M is connected. More precisely, the map Φ(c) = φc(c), where φc is the Böttcher coordinate of fc near ∞ (the conformal map with φc(fc(z)) = φc(z)² and φc(z) ~ z), extends to a conformal isomorphism Φ : ℂ \ M → ℂ \ D̄, with Φ(c) ~ c at ∞.

Since ℂ \ M is conformally a punctured disc around ∞, M is connected and full (its complement is connected), and its logarithmic capacity equals 1. The external rays Φ⁻¹({re2πiθ : r > 1}) organise the combinatorics of M; rays with rational angles land: those with odd denominator at roots of hyperbolic components, those with even denominator at Misiurewicz points (parameters whose critical orbit is strictly preperiodic, like c = i).

Geometry and open problems

Shishikura (1998) proved that ∂M has Hausdorff dimension 2, the largest possible, as does Jc for generic c ∈ ∂M. Whether ∂M has positive area is unknown. The area of M is known only numerically, approximately 1.5066. The central open problem is the MLC conjecture: M is locally connected. Douady and Hubbard showed that MLC would imply the density of hyperbolicity (every component of the interior of M is hyperbolic), and Yoccoz proved local connectivity of M at all parameters that are not infinitely renormalisable. The small copies of M visible everywhere along its boundary — at the tips of the antennae, along the real axis near −1.75 — are explained by renormalisation: certain iterates fcᵖ, restricted to small discs, behave like quadratic polynomials, giving homeomorphic copies of M inside M (Douady–Hubbard tuning).

The real slice of M is precisely the logistic family of Lesson 11 in disguise, and the period-doubling cascade of the logistic map is the sequence of hyperbolic components of periods 1, 2, 4, 8, … strung along the real axis between c = 1/4 and the Feigenbaum point c ≈ −1.4012.

Exercise

  • (a)
    Find c on the main cardioid's interior with attracting fixed-point multiplier μ = 1/2, and the fixed point itself.
  • (b)
    For c = −1.1, find the multiplier of the 2-cycle and decide whether it is attracting.
  • (c)
    Decide whether c = 1 + i is in M.
  • (d)
    Show that the period-2 disc and the main cardioid are tangent at c = −3/4 by computing the fixed-point and 2-cycle multipliers there.
Show solution

Answers: (a) c = μ/2 − μ²/4 = 1/4 − 1/16 = 3/16, with fixed point z = μ/2 = 1/4. Check: (1/4)² + 3/16 = 1/16 + 3/16 = 1/4. (b) 4(c + 1) = 4(−0.1) = −0.4; |−0.4| < 1, so the 2-cycle is attracting and c lies in the period-2 component. (c) z₁ = 1 + i, z₂ = (1 + i)² + 1 + i = 1 + 3i with |z₂| = √10 > 2, so c ∉ M by Theorem 10.1. (d) At c = −3/4 the fixed point z = −1/2 has multiplier −1 (boundary of the cardioid, μ = −1), and the 2-cycle multiplier 4(c + 1) = 1 (boundary of the disc |c + 1| < 1/4). At this point the two fixed points of fc² that form the 2-cycle collide with the fixed point z = −1/2: z² + z + 1/4 = (z + 1/2)².
