Hausdorff Measure and Hausdorff Dimension

Lesson 6 of 13

Key idea of this section

𝓗ˢ(F) = limδ→0 inf{ ∑ |Ui|ˢ : F ⊂ ⋃ Ui, |Ui| ≤ δ }
dimH F = inf{ s ≥ 0 : 𝓗ˢ(F) = 0 } = sup{ s : 𝓗ˢ(F) = ∞ }

The Carathéodory construction

Let F ⊂ ℝⁿ, s ≥ 0 and δ > 0. A δ-cover of F is a countable (or finite) collection {Ui} of sets with |Ui| ≤ δ and F ⊂ ⋃ Ui. Define

𝓗ˢδ(F) = inf{ ∑i |Ui|ˢ : {Ui} is a δ-cover of F }

As δ decreases the class of admissible covers shrinks, so 𝓗ˢδ(F) increases, and the limit

𝓗ˢ(F) = limδ→0 𝓗ˢδ(F) = supδ>0 𝓗ˢδ(F) ∈ [0, ∞]

exists. It is the s-dimensional Hausdorff measure of F. (Many authors include a normalising constant so that 𝓗ⁿ agrees with Lebesgue measure on ℝⁿ; we use the unnormalised version, which changes nothing about dimensions.)

The restriction |Ui| ≤ δ is essential. Without it, one obtains the Hausdorff content 𝓗ˢ∞, which sees only the coarsest covers: 𝓗¹∞ of a circle of radius 1 is at most 2, its diameter, rather than its length 2π. Forcing the covers to be fine lets 𝓗ˢ see the small-scale geometry. The content is not a Borel measure but is useful in potential theory, and it has the same null sets as 𝓗ˢ.

Theorem 6.1. 𝓗ˢ is a metric outer measure on ℝⁿ; consequently every Borel set is 𝓗ˢ-measurable and 𝓗ˢ restricted to the Borel sets is a measure.

Proof. Countable subadditivity: given F ⊂ ⋃ Fj and ε > 0, take δ-covers of Fj with sums less than 𝓗ˢδ(Fj) + ε 2−j; their union is a δ-cover of F, so 𝓗ˢδ(F) ≤ ∑ 𝓗ˢδ(Fj) + ε ≤ ∑ 𝓗ˢ(Fj) + ε. Metric additivity: if dist(E, F) > 0 and δ < dist(E, F), no set of diameter at most δ meets both E and F, so a δ-cover of E ∪ F splits into a δ-cover of E and one of F, and 𝓗ˢδ(E ∪ F) = 𝓗ˢδ(E) + 𝓗ˢδ(F) for such δ. Carathéodory's criterion then says a metric outer measure makes all Borel sets measurable. ∎

Basic properties

  • (a)
    Scaling: if g is a similarity of ratio λ, then 𝓗ˢ(g(F)) = λˢ 𝓗ˢ(F), since g maps δ-covers bijectively to λδ-covers and multiplies each |Ui|ˢ by λˢ. More generally, if g is Lipschitz with constant L, 𝓗ˢ(g(F)) ≤ Lˢ 𝓗ˢ(F).
  • (b)
    Hölder maps: if |g(x) − g(y)| ≤ c|x − y|α, then 𝓗s/α(g(F)) ≤ cs/α 𝓗ˢ(F), because a set of diameter |U| is mapped into a set of diameter at most c|U|α.
  • (c)
    Counting and Lebesgue: 𝓗⁰ is counting measure. 𝓗¹ on ℝ is Lebesgue measure, and on ℝⁿ, 𝓗¹ of a simple rectifiable curve equals its length. In general 𝓗ⁿ = (2ⁿ/ωn) Lⁿ on ℝⁿ, where ωn = πn/2/Γ(n/2 + 1) is the volume of the unit ball; the inequality 𝓗ⁿ ≥ (2ⁿ/ωn) Lⁿ is the isodiametric inequality Lⁿ(U) ≤ ωn (|U|/2)ⁿ, and the reverse needs a Vitali covering argument.

The dimension jump

Lemma 6.2. If 𝓗ˢ(F) < ∞ and t > s, then 𝓗ᵗ(F) = 0. If 𝓗ᵗ(F) > 0 and s < t, then 𝓗ˢ(F) = ∞.

Proof. For any δ-cover, ∑ |Ui|ᵗ ≤ δt−s ∑ |Ui|ˢ. Taking infima, 𝓗ᵗδ(F) ≤ δt−s 𝓗ˢδ(F) ≤ δt−s 𝓗ˢ(F) → 0. The second statement is the contrapositive. ∎

So the graph of s ↦ 𝓗ˢ(F) is ∞ for s < d and 0 for s > d, for a unique critical value d ∈ [0, n]: this is the Hausdorff dimension,

dimH F = inf{ s : 𝓗ˢ(F) = 0 } = sup{ s : 𝓗ˢ(F) = ∞ }

At s = d itself, 𝓗ᵈ(F) may be 0, positive and finite, or ∞. A set with 0 < 𝓗ᵈ(F) < ∞ is called a d-set; the Cantor set is a (log 2/log 3)-set (Lesson 7), and so is every self-similar set satisfying the open set condition (Lesson 8).

Properties of Hausdorff dimension

Theorem 6.3. (i) Monotonicity: E ⊂ F ⇒ dimH E ≤ dimH F. (ii) Countable stability: dimH ⋃j Fj = supj dimH Fj. (iii) Countable sets have Hausdorff dimension 0. (iv) Open subsets of ℝⁿ have dimension n; smooth m-dimensional submanifolds have dimension m. (v) If g is α-Hölder, dimH g(F) ≤ (1/α) dimH F; bi-Lipschitz maps preserve dimH. (vi) dimH F ≤ dimB̲ F ≤ dimB̄ F for bounded F.

Proof. (i) is immediate from monotonicity of 𝓗ˢ. (ii) The inequality ≥ is (i). If s > sup dimH Fj, then 𝓗ˢ(Fj) = 0 for all j and 𝓗ˢ(⋃Fj) ≤ ∑ 𝓗ˢ(Fj) = 0. (iii) follows from (ii) since a point has dimension 0. (iv) Lⁿ(V) > 0 for open V gives 𝓗ⁿ(V) > 0, while 𝓗ᵗ(ℝⁿ) = 0 for t > n by covering unit cubes with kⁿ cubes of side 1/k; for submanifolds use local bi-Lipschitz charts. (v) is property (b) above. (vi) If dimB̲ F < t < s, there are δk → 0 with Nδk(F) ≤ δk−t. Then 𝓗ˢδk(F) ≤ Nδk(F) δkˢ ≤ δks−t → 0, and since 𝓗ˢδ increases to 𝓗ˢ as δ ↓ 0, 𝓗ˢ(F) = limk 𝓗ˢδk(F) = 0. Hence dimH F ≤ s. ∎

The inequality in (vi) can be strict: ℚ ∩ [0, 1] has Hausdorff dimension 0 and box dimension 1, and {1/k} ∪ {0} has Hausdorff dimension 0 and box dimension 1/2.

Packing dimension

Dual to Hausdorff measure, which uses efficient covers by small sets, is the packing measure of Tricot (1982) and Taylor–Tricot (1985), which uses efficient packings by small disjoint balls centred in the set. The resulting packing dimension dimP satisfies

dimH F ≤ dimP F ≤ dimB̄ F
dimP F = inf{ supj dimB̄ Fj : F ⊂ ⋃j Fj }

so packing dimension is the countably stable regularisation of upper box dimension. For every self-similar set with the OSC, all of dimH, dimP, dimB̲ and dimB̄ agree.

Exercise

  • (a)
    Show that a line segment L of length ℓ in ℝ² has 𝓗¹(L) = ℓ and dimH L = 1.
  • (b)
    Prove that the graph of a Lipschitz function g : [0, 1] → ℝ has Hausdorff dimension 1.
  • (c)
    Show directly from the definition that 𝓗ˢ(ℚ ∩ [0, 1]) = 0 for every s > 0.
  • (d)
    What is the box dimension of E = [0, 1] × C, with C the middle-third Cantor set?
Show solution

Answers: (a) Covering L by k pieces of length ℓ/k gives 𝓗¹ℓ/k(L) ≤ ℓ. Projecting any cover orthogonally onto the line through L does not increase diameters and gives a cover of an interval of length ℓ by sets whose convex hulls are intervals, so ∑|Ui| ≥ ℓ by subadditivity of length. Hence 𝓗¹(L) = ℓ ∈ (0, ∞) and dimH L = 1. (b) The map x ↦ (x, g(x)) is bi-Lipschitz from [0, 1] onto the graph, so dimH of the graph equals dimH [0, 1] = 1. (c) Enumerate the rationals q₁, q₂, …; cover qj by an interval of diameter (ε 2−j)1/s. Then ∑|Uj|ˢ = ε and all diameters are at most ε1/s. Letting ε → 0 gives 𝓗ˢδ = 0 for every δ, so 𝓗ˢ = 0. (d) At scale 3−k, E is covered by 3k · 2k squares of side 3−k, and the count is sharp up to a constant, so dimB E = log 6 / log 3 = 1 + log 2 / log 3 ≈ 1.6309.
