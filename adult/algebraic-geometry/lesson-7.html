Singular Points, Tangent Cones and Multiplicity

Lesson 7 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

P ∈ V(f) is singular  ⟺  f(P) = ∂f/∂x(P) = ∂f/∂y(P) = 0

Smooth and singular points of plane curves

Let f ∈ k[x, y] be squarefree and nonconstant, with k algebraically closed, and let C = V(f). A point P = (p₁, p₂) ∈ C is singular (a singularity) if both partial derivatives fₓ and fy vanish at P; otherwise P is smooth (nonsingular), and the tangent line to C at P is

fₓ(P)(x − p₁) + fy(P)(y − p₂) = 0

The curve is smooth if all of its points are smooth. Over ℂ, the holomorphic implicit function theorem shows that near a smooth point C is a one-dimensional complex manifold.

Multiplicity and tangent cone

Translate P to the origin and expand f as a sum of homogeneous parts, f = fm + fm+1 + ⋯ + fd with fm ≠ 0. The integer m = mP(C) ≥ 1 is the multiplicity of C at P; P is smooth iff m = 1, in which case the tangent line is f₁ = 0. Over k algebraically closed the lowest form factors into linear forms, fm = ∏ Lᵢrᵢ, and the lines Lᵢ = 0 are the tangent lines at P, with multiplicities rᵢ; their union is the tangent cone. A singular point is ordinary if it has m distinct tangent lines. An ordinary double point is a node; the double point of y² = x³, with a single tangent line counted twice, is the simplest cusp.

Example (the nodal cubic). Let f = y² − x³ − x². Then fₓ = −3x² − 2x and fy = 2y. A singular point needs y = 0 and x(3x + 2) = 0, and must lie on the curve. At x = 0 the point (0, 0) is on the curve. At x = −2/3, f(−2/3, 0) = 8/27 − 4/9 = −4/27 ≠ 0. So the origin is the only singular point. The lowest form is f₂ = y² − x² = (y − x)(y + x): a node with tangent lines y = x and y = −x.

Example (the cusp). For f = y² − x³ the origin is the only singular point, with tangent cone y² = 0: one tangent line, the x-axis, of multiplicity 2.

Example (the folium of Descartes). For f = x³ + y³ − 3xy, the conditions fₓ = 3x² − 3y = 0 and fy = 3y² − 3x = 0 give y = x² and x = x⁴, so x = 0 or x³ = 1. For x³ = 1 we get y = x² and f = x³ + x⁶ − 3x³ = 1 + 1 − 3 = −1 ≠ 0. Hence only the origin is singular; f₂ = −3xy, so it is a node whose tangents are the two coordinate axes.

Finiteness of the singular locus

Lemma. If f, g ∈ k[x, y] have no common factor, then V(f, g) is finite.

Proof. Regard f and g as polynomials in y over the field k(x). By Gauss's lemma they have no common factor there either, so there are a, b ∈ k(x)[y] with af + bg = 1. Clearing denominators gives a′f + b′g = d(x) with a′, b′ ∈ k[x, y] and 0 ≠ d ∈ k[x]. Any common zero (x₀, y₀) has d(x₀) = 0, leaving finitely many possible x₀. Symmetrically there are finitely many possible y₀. ∎

Proposition. In characteristic 0, a plane curve C = V(f) with f squarefree has only finitely many singular points.

Proof. A singular point of C is either a singular point of one irreducible component or a point lying on two components, and two distinct components meet in finitely many points by the lemma. For an irreducible nonconstant f, at least one partial derivative, say fₓ, is a nonzero polynomial of smaller degree (characteristic 0), so f ∤ fₓ, and since f is irreducible, f and fₓ have no common factor. The singular points lie in V(f, fₓ), which is finite by the lemma. ∎

In characteristic p the same argument works unless both partial derivatives vanish identically, which happens only when f is a polynomial in xᵖ and yᵖ; over a perfect field such an f is a p-th power, contradicting squarefreeness.

Singular Weierstrass cubics

Consider C: y² = x³ + ax + b, that is, f = y² − x³ − ax − b, in characteristic ≠ 2, 3. Then fy = 2y and fₓ = −(3x² + a). A singular point must have y = 0, x³ + ax + b = 0 and 3x² + a = 0; that is, x must be a repeated root of the cubic x³ + ax + b. This happens exactly when the discriminant of the cubic vanishes:

C is singular  ⟺  4a³ + 27b² = 0

For example x³ − 3x + 2 = (x − 1)²(x + 2) has 4(−27) + 27·4 = 0, and the singular point is (1, 0). Writing u = x − 1, the equation becomes y² = u²(u + 3), whose tangent cone at u = y = 0 is y² = 3u²: a node with tangents y = ±√3 (x − 1). In general, if 4a³ + 27b² = 0 and a ≠ 0, eliminating x² between 3x² + a = 0 and x³ + ax + b = 0 gives (2a/3)x + b = 0, so the double root is x₀ = −3b/(2a) and the singularity is a node; if a = b = 0 the curve is the cusp y² = x³.

The Jacobian criterion

For an irreducible algebraic set X ⊆ 𝔸ⁿ of dimension d with I(X) = ⟨f₁, …, fr⟩, a point P is smooth iff the Jacobian matrix (∂fᵢ/∂xⱼ(P)) has rank n − d. Intrinsically, the Zariski tangent space at P is the dual of 𝔪P/𝔪P², where 𝔪P is the maximal ideal of the local ring 𝒪X,P, and P is smooth iff dimk 𝔪P/𝔪P² = dim X, that is, iff 𝒪X,P is a regular local ring. For the cusp y² = x³ at the origin, 𝔪/𝔪² is spanned by the classes of x and y and has dimension 2 > 1, confirming that the origin is singular.

Exercise

  • (a)
    Find the singular points in 𝔸²(ℝ) of the quartic f = (x² + y²)² − (x² − y²) (the lemniscate of Bernoulli) and the tangent lines there.
  • (b)
    Show that the conic x² + y² − 1 is smooth.
  • (c)
    For which values of b is y² = x³ − 12x + b singular? Find the singular point in each case.
Show solution

Answers: (a) fₓ = 4x(x² + y²) − 2x = 2x(2(x² + y²) − 1) and fy = 4y(x² + y²) + 2y = 2y(2(x² + y²) + 1). Over ℝ the second factor of fy is positive, so fy = 0 forces y = 0. Then fₓ = 0 gives x = 0 or x² = 1/2, and f(x, 0) = x⁴ − x² vanishes at x = 0 but equals 1/4 − 1/2 ≠ 0 when x² = 1/2. So only the origin is singular in the real plane; the lowest form is −(x² − y²), a node with tangents y = x and y = −x. (b) fₓ = 2x and fy = 2y vanish only at (0, 0), which is not on the curve. (c) 4(−12)³ + 27b² = 0 gives b² = 256, b = ±16. For b = 16: x³ − 12x + 16 = (x − 2)²(x + 4), singular point (2, 0). For b = −16: x³ − 12x − 16 = (x + 2)²(x − 4), singular point (−2, 0).
