Hilbert's Nullstellensatz

Lesson 4 of 13

Overview12345678910111213ProblemsAssessment

Key idea of this section

k = k̄:   I(V(J)) = √J   for every ideal J ⊆ k[x₁, …, xₙ]

Two versions of one theorem

The Nullstellensatz ("theorem of the zeros") of Hilbert (1893) answers the question left open in Lesson 1: which ideals are of the form I(X)? Over a field that is not algebraically closed the answer is messy: in ℝ[x], the ideal ⟨x² + 1⟩ is maximal (hence radical) but V(x² + 1) = ∅, so I(V(x² + 1)) = ℝ[x] ≠ ⟨x² + 1⟩. Over an algebraically closed field the answer is as clean as possible.

Theorem (weak Nullstellensatz). Let k be algebraically closed. If J ⊊ k[x₁, …, xₙ] is a proper ideal, then V(J) ≠ ∅. Equivalently, every maximal ideal of k[x₁, …, xₙ] has the form 𝔪a = ⟨x₁ − a₁, …, xₙ − aₙ⟩ for a unique point a ∈ kⁿ.

The two formulations are equivalent: a proper ideal lies in some maximal ideal 𝔪 (Zorn, or simply the Noetherian property), and if 𝔪 = 𝔪a then a ∈ V(J); conversely if V(𝔪) contains a point a, then 𝔪 ⊆ 𝔪a and maximality forces equality. (𝔪a is maximal because k[x]/𝔪a ≅ k via evaluation at a.)

The heart of the matter is the following algebraic statement.

Zariski's lemma. If K is a field that is finitely generated as an algebra over a field k, then K is a finite extension of k.

Given Zariski's lemma, the weak Nullstellensatz follows at once: if 𝔪 is maximal, K = k[x]/𝔪 is a field finitely generated as a k-algebra, so K is finite (in particular algebraic) over k; as k is algebraically closed, the inclusion k → K is an isomorphism. Let aᵢ ∈ k be the element corresponding to the image of xᵢ. Then xᵢ − aᵢ ∈ 𝔪 for each i, so 𝔪a ⊆ 𝔪, and equality holds by maximality of 𝔪a.

A complete proof for uncountable fields

We prove Zariski's lemma, and hence the weak Nullstellensatz, in the important case where k is uncountable, such as k = ℂ. (The general case is usually proved via Noether normalization or by the Artin–Tate lemma; see Atiyah–Macdonald, Chapter 7.)

Proof. Let K = k[x₁, …, xₙ]/𝔪 be a field. As a k-vector space, K is spanned by the images of the countably many monomials, so dimk K is at most countable. Suppose some t ∈ K is transcendental over k. Then the elements 1/(t − c), for c ∈ k, are linearly independent over k: a relation ∑ λᵢ/(t − cᵢ) = 0 with distinct cᵢ, after multiplying by ∏(t − cᵢ), becomes a polynomial identity in t, which must be the zero polynomial because t is transcendental; evaluating that polynomial at t = cⱼ shows λⱼ ∏i≠j(cⱼ − cᵢ) = 0, so λⱼ = 0. This gives uncountably many linearly independent elements in a space of countable dimension, a contradiction. Hence K is algebraic over k, and being finitely generated, it is a finite extension. ∎

The strong Nullstellensatz

Theorem (strong Nullstellensatz). Let k be algebraically closed and J ⊆ k[x₁, …, xₙ] an ideal. If f vanishes at every point of V(J), then fᴺ ∈ J for some N ≥ 1. That is, I(V(J)) = √J.

Proof (the Rabinowitsch trick, 1929). By the basis theorem J = ⟨f₁, …, fr⟩. We may assume f ≠ 0. Introduce a new variable t and consider the ideal J′ = ⟨f₁, …, fr, 1 − t f⟩ ⊆ k[x₁, …, xₙ, t]. A common zero (a, b) of J′ would satisfy fᵢ(a) = 0 for all i, hence f(a) = 0, and then 1 − b f(a) = 1 ≠ 0. So V(J′) = ∅, and by the weak Nullstellensatz J′ is the unit ideal:

1 = ∑ gᵢ(x, t) fᵢ(x) + h(x, t)(1 − t f(x))

This is an identity in k[x, t]; map it into the field of rational functions k(x) by t ↦ 1/f. The last term vanishes, and we get 1 = ∑ gᵢ(x, 1/f) fᵢ(x). Multiply by fᴺ, where N is at least the largest t-degree of the gᵢ, to clear denominators: fᴺ = ∑ Gᵢ(x) fᵢ(x) with Gᵢ = fᴺ gᵢ(x, 1/f) ∈ k[x]. Hence fᴺ ∈ J. ∎

The dictionary

Combining the Nullstellensatz with Lessons 1–3, we obtain an inclusion-reversing bijection, for k algebraically closed:

{ radical ideals of k[x₁, …, xₙ] }  ⟷  { algebraic subsets of 𝔸ⁿ }
{ prime ideals }                    ⟷  { irreducible algebraic subsets }
{ maximal ideals }                  ⟷  { points of 𝔸ⁿ }

given by J ↦ V(J) and X ↦ I(X). Intersections of algebraic sets correspond to radicals of sums of ideals: X ∩ Y ↔ √(I(X) + I(Y)). The radical is genuinely needed: the parabola y = x² and its tangent line y = 0 meet only at the origin, and I(X) + I(Y) = ⟨y − x², y⟩ = ⟨x², y⟩, whose radical is ⟨x, y⟩. The non-radical ideal ⟨x², y⟩ records the tangency, a theme we take up in Lesson 9.

Certificates of infeasibility

The weak Nullstellensatz has a computational reading: a system f₁ = ⋯ = fr = 0 has no solution over k̄ if and only if there are polynomials gᵢ with ∑ gᵢ fᵢ = 1. Such a relation is a certificate of infeasibility. For example, the system x² = 0, 1 + xy = 0 has no solutions, and indeed

(1 − xy)(1 + xy) + y² · x² = 1 − x²y² + x²y² = 1

Similarly the two concentric circles x² + y² = 1 and x² + y² = 4 never meet, and (1/3)(x² + y² − 1) − (1/3)(x² + y² − 4) = 1. The degrees of the gᵢ needed in general can be large; Kollár (1988) proved the sharp effective bound deg(gᵢfᵢ) ≤ max(3, d)ⁿ, where d bounds the degrees of the fᵢ (for d ≥ 3 this is dⁿ).

Exercise

  • (a)
    Over ℂ, compute I(V(x² − 2xy + y²)) and I(V(x³, y − 1)).
  • (b)
    Find an explicit certificate showing that x = 0 and xy − 1 = 0 have no common zero.
  • (c)
    Show that over ℝ the ideal ⟨x² + y²⟩ is radical, but I(V(x² + y²)) ≠ ⟨x² + y²⟩.
Show solution

Answers: (a) x² − 2xy + y² = (x − y)², so I(V) = √⟨(x − y)²⟩ = ⟨x − y⟩. Next, √⟨x³, y − 1⟩ = ⟨x, y − 1⟩, which is maximal, so I(V(x³, y − 1)) = ⟨x, y − 1⟩, the ideal of the point (0, 1). (b) y · x − (xy − 1) = 1. (c) x² + y² is irreducible over ℝ (a factorization would be into two real linear forms, but x² + y² has no real zero other than the origin, while a real line through the origin has infinitely many), so ⟨x² + y²⟩ is prime, hence radical. But Vℝ(x² + y²) = {(0, 0)}, whose ideal is ⟨x, y⟩ ≠ ⟨x² + y²⟩.
