Linear Systems and the Matrix Exponential

Lesson 7 of 12

Overview123456789101112ProblemsAssessment

Key idea of this section

x′ = Ax,  x(0) = x₀   ⟹   x(t) = etA x₀,   etA = ∑n≥0 tⁿAⁿ/n!

The scalar theory generalizes verbatim to linear systems, with the matrix exponential in place of the exponential. The new phenomena are rotation (complex eigenvalues), polynomial corrections (non-trivial Jordan blocks), coexistence of growth and decay in different directions (saddles), and transient growth in systems that are asymptotically stable.

Definition and basic properties

For an n × n real or complex matrix A, the series ∑ Aⁿ/n! converges absolutely in any operator norm, since ‖Aⁿ/n!‖ ≤ ‖A‖ⁿ/n!; hence ‖eA‖ ≤ e‖A‖. Term-by-term differentiation (justified by uniform convergence on bounded t-sets) gives (d/dt) etA = A etA = etA A. The uniqueness argument of Theorem 1.1 carries over: if x′ = Ax then (e−tA x)′ = 0. Further properties:

eA+B = eA eB   whenever AB = BA
ePAP⁻¹ = P eA P⁻¹
(eA)⁻¹ = e−A
det eA = etr A

The commuting hypothesis cannot be dropped. With A = [[0, 1], [0, 0]] and B = [[0, 0], [1, 0]] (rows listed), eA = [[1, 1], [0, 1]] and eB = [[1, 0], [1, 1]], so eA eB = [[2, 1], [1, 1]], whereas A + B = [[0, 1], [1, 0]] has eA+B = [[cosh 1, sinh 1], [sinh 1, cosh 1]] ≈ [[1.543, 1.175], [1.175, 1.543]]. The general correction is the Baker–Campbell–Hausdorff formula, eA eB = eA + B + [A,B]/2 + ….

The determinant identity (Liouville's formula) has a two-line proof: over ℂ, A is similar to an upper triangular matrix T with the eigenvalues λ₁, …, λₙ on the diagonal, and eT is upper triangular with diagonal entries eλj, so det eA = det eT = eλ₁ + … + λₙ = etr A. Geometrically, the flow of x′ = Ax multiplies volumes by et tr A.

Computing etA

If A = PDP⁻¹ is diagonalizable with D = diag(λ₁, …, λₙ), then etA = P diag(eλ₁t, …, eλₙt) P⁻¹: in the eigenbasis the system decouples into n scalar exponential laws. Example: A = [[1, 2], [2, 1]] has eigenvalues 3 and −1 with eigenvectors (1, 1) and (1, −1), and

etA = (1/2) [[e3t + e−t,  e3t − e−t],
                [e3t − e−t,  e3t + e−t]]

The origin is a saddle: growth at rate 3 along the diagonal, decay at rate 1 along the antidiagonal.

For a Jordan block J = λI + N with N nilpotent (Nm = 0), λI and N commute, so:

etJ = eλt (I + tN + t²N²/2! + … + tm−1 Nm−1/(m−1)!)

and polynomial factors appear: for J = [[λ, 1], [0, λ]], etJ = eλt [[1, t], [0, 1]]. For complex eigenvalues a ± ib of a real 2 × 2 matrix, the real normal form [[a, −b], [b, a]] has exponential eat [[cos bt, −sin bt], [sin bt, cos bt]]: rotation at angular speed b combined with exponential growth or decay at rate a.

Spectral characterization of stability

Theorem 7.1. Let α(A) = max Re λ over the eigenvalues of A (the spectral abscissa). For every ε > 0 there is Cε with ‖etA‖ ≤ Cε e(α(A)+ε)t for t ≥ 0, and ε may be taken 0 if every eigenvalue with Re λ = α(A) is semisimple. In particular every solution of x′ = Ax tends to 0 if and only if α(A) < 0, and then the decay is exponential.

Proof. Use the Jordan form A = P J P⁻¹. Each entry of etJ has the form eλt tʲ/j! with j smaller than the size of the block, and |eλt tʲ| ≤ C e(Re λ + ε)t for t ≥ 0. Conversely, if Re λ ≥ 0 for some eigenvalue with eigenvector v, the solution eλt v does not tend to 0 (for real A take its real part). ∎

For 2 × 2 real matrices, with τ = tr A and Δ = det A, the eigenvalues are (τ ± √(τ² − 4Δ))/2 and the phase portrait is classified by the (τ, Δ) plane: Δ < 0 gives a saddle; Δ > 0 and τ < 0 a stable node (τ² ≥ 4Δ) or stable spiral (τ² < 4Δ); Δ > 0 and τ > 0 the unstable counterparts; Δ > 0 and τ = 0 a centre. For nonlinear systems x′ = F(x) the Hartman–Grobman theorem says that near an equilibrium whose Jacobian has no eigenvalues on the imaginary axis, the flow is topologically conjugate to the linear flow of the Jacobian.

Transient growth and non-normality

Eigenvalues govern the limit t → ∞, not intermediate times. For A = [[−1, 10], [0, −2]], both eigenvalues are negative, yet the (1, 2) entry of etA equals 10(e−t − e−2t), which rises from 0 to its maximum 2.5 at t = ln 2 before decaying. For highly non-normal matrices (large ‖A‖ compared with the eigenvalue gap) the transient amplification can be enormous; this mechanism is central to the theory of the transition to turbulence in shear flows, and is the reason pseudospectra, not spectra, predict the short-time behaviour of such systems. An entry of exactly this form is the daughter population of the decay chain of Lesson 3, which is the linear system with triangular matrix [[−λA, 0], [λA, −λB]].

Exercise

  • (a)
    Compute etA for A = [[2, 1], [0, 2]] and solve x′ = Ax with x(0) = (1, 1).
  • (b)
    Classify the origin for A = [[1, −5], [1, −3]].
  • (c)
    Without computing eA, find det eA for A = [[3, 7], [−2, −5]].
Show solution

Answers: (a) A = 2I + N with N = [[0, 1], [0, 0]], so etA = e2t [[1, t], [0, 1]] and x(t) = e2t(1 + t, 1). (b) τ = −2, Δ = −3 + 5 = 2, τ² − 4Δ = −4 < 0: eigenvalues −1 ± i, a stable spiral. (c) det eA = etr A = e3 − 5 = e−2.
