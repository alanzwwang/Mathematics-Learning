The Gauss–Markov Theorem

OLS:    β̂ = (XᵀX)⁻¹Xᵀy,   E[β̂] = β,   Cov(β̂) = σ²(XᵀX)⁻¹
Gauss–Markov:  β̂ is the Best Linear Unbiased Estimator (BLUE)

The linear model

Lesson 8 treated least squares as geometry. Statistics asks why it is a good idea. In the linear model an n-vector of observations y is generated as y = Xβ + ε, where X is a known n × p design matrix of full column rank, β ∈ ℝᵖ is an unknown parameter, and ε is a random error vector. The Gauss–Markov assumptions are that the errors have mean zero, E[ε] = 0, and are uncorrelated with common variance, Cov(ε) = E[εεᵀ] = σ²I (homoscedasticity). No normality is assumed.

An estimator β̃ of β is linear if β̃ = Cy for a fixed p × n matrix C, and unbiased if E[β̃] = β for every β. Since E[Cy] = CXβ, a linear estimator is unbiased exactly when CX = I. The ordinary least squares (OLS) estimator β̂ = (XᵀX)⁻¹Xᵀy is linear, with C₀ = (XᵀX)⁻¹Xᵀ, and unbiased because C₀X = I. Its covariance is

Cov(β̂) = C₀ Cov(y) C₀ᵀ = σ² (XᵀX)⁻¹XᵀX(XᵀX)⁻¹ = σ²(XᵀX)⁻¹.

For symmetric matrices write M ⪰ N if M − N is positive semidefinite. This is the natural order on covariance matrices: M ⪰ N means that every linear combination aᵀβ̃ has at least as large a variance under M as under N.

Theorem 9.1 (Gauss–Markov)

Under the Gauss–Markov assumptions, every linear unbiased estimator β̃ = Cy satisfies Cov(β̃) ⪰ Cov(β̂). Consequently, for every vector a, the estimator aᵀβ̂ has the smallest variance among all linear unbiased estimators of aᵀβ.

Proof. Write C = C₀ + D. Unbiasedness gives CX = I = C₀X, so DX = 0. Then

Cov(β̃) = σ²CCᵀ = σ²(C₀C₀ᵀ + C₀Dᵀ + DC₀ᵀ + DDᵀ).

Now DC₀ᵀ = DX(XᵀX)⁻¹ = 0, and C₀Dᵀ is its transpose, so Cov(β̃) = σ²(XᵀX)⁻¹ + σ²DDᵀ. The matrix DDᵀ is positive semidefinite, since aᵀDDᵀa = ‖Dᵀa‖² ≥ 0. Hence Cov(β̃) − Cov(β̂) = σ²DDᵀ ⪰ 0, with equality only if D = 0, that is β̃ = β̂. The second statement follows because Var(aᵀβ̃) = aᵀCov(β̃)a. ∎

Estimating the error variance

The fitted values are ŷ = Hy with H = X(XᵀX)⁻¹Xᵀ, and the residual vector is e = (I − H)y. Since (I − H)X = 0, we have e = (I − H)ε, and the residual sum of squares is RSS = eᵀe = εᵀ(I − H)ε, because I − H is symmetric and idempotent.

Theorem 9.2

The estimator σ̂² = RSS/(n − p) is unbiased for σ².

Proof. For any fixed matrix M, E[εᵀMε] = E[tr(Mεεᵀ)] = tr(M E[εεᵀ]) = σ² tr M. With M = I − H we get E[RSS] = σ²(n − tr H) = σ²(n − p), since tr H = tr((XᵀX)⁻¹XᵀX) = tr Ip = p. ∎

The divisor n − p, the degrees of freedom, is the dimension of the orthogonal complement of the column space into which the residual is projected. For the worked example of Lesson 8 (n = 4, p = 2, RSS = 4.2) the estimate is σ̂² = 2.1. In simple regression the slope has variance σ²/Sxx, so its estimated standard error is √(2.1/5) = √0.42 ≈ 0.648.

Beyond Gauss–Markov

Each hypothesis of the theorem is essential, and relaxing each leads to an important theory.

  • 1.
    Correlated or heteroscedastic errors. If Cov(ε) = σ²Ω with Ω known and positive definite, OLS is still unbiased but no longer best. The best linear unbiased estimator is the generalised least squares estimator β̂GLS = (XᵀΩ⁻¹X)⁻¹XᵀΩ⁻¹y (Aitken, 1935), obtained by applying OLS after transforming by the inverse square root of Ω (Problem 52).
  • 2.
    Normality. If in addition ε is Gaussian, then β̂ is the maximum-likelihood estimator and, by the Lehmann–Scheffé theorem, it is the minimum-variance unbiased estimator among all unbiased estimators, linear or not. Gauss's own 1809 argument went in the reverse direction: he asked which error law makes the arithmetic mean the most probable value, and found the normal distribution.
  • 3.
    Unbiasedness. Dropping unbiasedness can reduce the mean squared error. Ridge regression (XᵀX + λI)⁻¹Xᵀy trades bias for variance, and the James–Stein phenomenon (1956, 1961) shows that when estimating three or more means simultaneously, the obvious unbiased estimator is inadmissible under squared-error loss.
  • 4.
    Linearity. Without normality there can be nonlinear unbiased estimators that beat OLS; the restriction to linear estimators is what makes the theorem hold under only second-moment assumptions.

Exercise

  • (a)
    A regression has n = 10 observations and p = 3 parameters. What is tr H, and what is the divisor in σ̂²?
  • (b)
    In simple regression σ² = 4 and Sxx = 16. Find the variance of the OLS slope.
  • (c)
    In the model yᵢ = μ + εᵢ (i = 1, …, n), identify X and show that the BLUE of μ is the sample mean.
Show solution

Answers: (a) tr H = p = 3, and the divisor is n − p = 7. (b) σ²/Sxx = 4/16 = 1/4. (c) X is the n × 1 column of ones, XᵀX = n and Xᵀy = Σyᵢ, so β̂ = (1/n)Σyᵢ = ȳ, which by Gauss–Markov has variance σ²/n, the smallest among linear unbiased estimators.
