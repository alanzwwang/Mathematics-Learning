Key idea of this section

C(2n, n) = (4ⁿ/√(πn)) (1 − 1/(8n) + O(n⁻²))
4ⁿ/(2√n) ≤ C(2n, n) ≤ 4ⁿ/√(3n + 1)       (n ≥ 1)
C(n, αn) = 2nH(α) / √(2πnα(1 − α)) · (1 + o(1)),   H(α) = −α log₂ α − (1 − α) log₂(1 − α)

Stirling's formula

Stirling's formula n! = √(2πn)(n/e)ⁿ(1 + 1/(12n) + O(n⁻²)) is the basic tool; Robbins (1955) gave the explicit bounds √(2πn)(n/e)ⁿ e1/(12n+1) < n! < √(2πn)(n/e)ⁿ e1/(12n) for n ≥ 1. Applied to C(2n, n) = (2n)!/(n!)², the main terms give 4ⁿ/√(πn), and the correction factors combine to e1/(24n) − 2/(12n) + O(n⁻²) = 1 − 1/(8n) + O(n⁻²).

Elementary bounds

Proposition 13.1. For n ≥ 1, 4ⁿ/(2√n) ≤ C(2n, n) ≤ 4ⁿ/√(3n + 1), with equality in both at n = 1.

Proof. Let aₙ = C(2n, n)/4ⁿ, so a₁ = 1/2 and aₙ₊₁ = aₙ (2n + 1)/(2n + 2). For the upper bound we show aₙ²(3n + 1) ≤ 1 by induction. It holds with equality for n = 1, and the inductive step requires (2n + 1)²(3n + 4) ≤ (3n + 1)(2n + 2)². Expanding, the left side is 12n³ + 28n² + 19n + 4 and the right side is 12n³ + 28n² + 20n + 4, so the inequality holds. For the lower bound we show 4n aₙ² ≥ 1; equality holds at n = 1, and the step requires (2n + 1)²(n + 1) ≥ 4n(n + 1)², i.e. (2n + 1)² ≥ 4n(n + 1), i.e. 1 ≥ 0. ∎

Both bounds are of the correct order 4ⁿ/√n, and they pin the constant: 1/2 ≤ aₙ√n ≤ 1/√3. The true limit 1/√π ≈ 0.5642 lies between 0.5 and 0.5774; the statement lim aₙ√(πn) = 1 is equivalent to Wallis's product π/2 = ∏ (2k)²/((2k − 1)(2k + 1)).

Entropy and the binomial distribution

Proposition 13.2. Let 0 < α < 1 with αn an integer. Then 2nH(α)/(n + 1) ≤ C(n, αn) ≤ 2nH(α). Proof. With k = αn, αᵏ(1 − α)ⁿ⁻ᵏ = 2−nH(α). The upper bound follows from 1 = (α + (1 − α))ⁿ ≥ C(n, k) αᵏ(1 − α)ⁿ⁻ᵏ. For the lower bound, the term with j = k is the largest of the n + 1 terms C(n, j) αʲ(1 − α)ⁿ⁻ʲ (the ratio of consecutive terms crosses 1 at j = k), and they sum to 1. ∎

The sharp form C(n, αn) ~ 2nH(α)/√(2πnα(1 − α)) follows from Stirling. A related estimate bounds the volume of a Hamming ball: for 0 < α ≤ 1/2, ∑k≤αn C(n, k) ≤ 2nH(α), since for k ≤ αn we have αᵏ(1 − α)ⁿ⁻ᵏ = (1 − α)ⁿ(α/(1 − α))ᵏ ≥ (1 − α)ⁿ(α/(1 − α))αn = 2−nH(α), and the sum of C(n, k)αᵏ(1 − α)ⁿ⁻ᵏ is at most 1. This inequality underlies the Gilbert–Varshamov and Hamming bounds in coding theory.

The local limit theorem

The de Moivre–Laplace theorem in local form states that for even n,

C(n, n/2 + x) = 2ⁿ √(2/(πn)) e−2x²/n (1 + o(1))

uniformly for integers x with |x| = o(n2/3). Proof sketch: log(C(n, n/2 + x)/C(n, n/2)) = ∑j=1x log((n/2 − j + 1)/(n/2 + j)) = −2x²/n + O(|x|³/n² + |x|/n), using log((1 − u)/(1 + u)) = −2u + O(u³). Combined with the central asymptotics this gives the Gaussian profile: the rows of Pascal's triangle, normalized, converge to the normal density, which is the central limit theorem for fair coin tossing. The binomial coefficients are also strictly log-concave in k, C(n, k)² > C(n, k − 1)C(n, k + 1) for 0 < k < n, because the ratio C(n, k + 1)/C(n, k) = (n − k)/(k + 1) is strictly decreasing; log-concavity implies unimodality, with mode(s) ⌊n/2⌋ and ⌈n/2⌉.

Random walk interpretation. C(2n, n)/4ⁿ is the probability that a simple random walk is at the origin at time 2n. Since it is ~ 1/√(πn), the expected number of returns ∑ C(2n, n)/4ⁿ diverges, so the one-dimensional walk is recurrent (Pólya, 1921). For n = 50 the exact probability is 0.079589 and 1/√(50π) = 0.079788.
