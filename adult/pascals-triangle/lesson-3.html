The Chu–Vandermonde Identity

Lesson 3 of 14

Overview1234567891011121314ProblemsAssessment

Key idea of this section

∑ₖ C(α, k) C(β, n − k) = C(α + β, n)      for all α, β and all n ∈ ℕ
equivalently  (α + β)n = ∑ₖ C(n, k) αk βn−k

Statement and two proofs

The identity was known to Zhu Shijie in 1303 and rediscovered by Alexandre-Théophile Vandermonde in 1772. For natural numbers it is a familiar double count: choosing n people from a group of a women and b men, classified by the number k of women chosen.

Theorem 3.1 (Chu–Vandermonde). For all α, β in a commutative ℚ-algebra and every n ∈ ℕ, ∑k=0n C(α, k) C(β, n − k) = C(α + β, n).

First proof (polynomial method). Fix n. Both sides are polynomials in (α, β) with rational coefficients. For (α, β) = (a, b) ∈ ℕ², both sides count n-subsets of a disjoint union of an a-set and a b-set. By the two-variable form of Lemma 1.1 the identity holds identically. ∎

Second proof (formal power series). Define the formal power series Bα(x) = ∑ₖ C(α, k) xᵏ in A[[x]]. The coefficient of xⁿ in Bα(x) Bβ(x) − Bα+β(x) is a polynomial in (α, β) which vanishes on ℕ², because for natural exponents Ba(x) = (1 + x)ᵃ is a polynomial and (1 + x)ᵃ(1 + x)ᵇ = (1 + x)a+b. Hence Bα Bβ = Bα+β in A[[x]], which is exactly the theorem. ∎

The second proof shows that Bα behaves like an exponential: Bα Bβ = Bα+β and B1 = 1 + x. This is the formal content of the generalized binomial theorem; Lesson 5 adds convergence.

The binomial-type form

Multiplying Theorem 3.1 by n! gives (α + β)n = ∑ₖ C(n, k) αk βn−k. A sequence of polynomials pₙ(x) with deg pₙ = n satisfying pₙ(x + y) = ∑ₖ C(n, k) pₖ(x) pₙ₋ₖ(y) is said to be of binomial type. The monomials xⁿ, the falling factorials xn, the rising factorials x(x + 1)⋯(x + n − 1) and the Abel polynomials x(x − an)ⁿ⁻¹ are all of binomial type; Rota's umbral calculus classifies such sequences through their generating functions ∑ pₙ(x) tⁿ/n! = exp(x g(t)) for a power series g with g(0) = 0 and g′(0) ≠ 0. For falling factorials g(t) = log(1 + t).

Hypergeometric form

With the Pochhammer symbol (a)ₙ = a(a + 1)⋯(a + n − 1), the Gauss hypergeometric series is ₂F₁(a, b; c; z) = ∑ₙ (a)ₙ (b)ₙ zⁿ/((c)ₙ n!). When a = −n is a negative integer the series terminates, and Chu–Vandermonde is equivalent to

₂F₁(−n, b; c; 1) = (c − b)ₙ / (c)ₙ

a special case of Gauss's summation theorem ₂F₁(a, b; c; 1) = Γ(c)Γ(c − a − b)/(Γ(c − a)Γ(c − b)) for Re(c − a − b) > 0. The translation uses C(α, k) = (−1)ᵏ(−α)ₖ/k!. In this language most classical binomial identities become special evaluations of hypergeometric series, which is the starting point of the Wilf–Zeilberger theory.

Consequences

Corollary 3.2. (i) ∑ₖ C(n, k)² = C(2n, n). (ii) ∑ₖ C(m, k) C(n, k) = C(m + n, m) for m, n ∈ ℕ. (iii) For a, b, n ∈ ℕ, ∑k=0n C(a + k, k) C(b + n − k, n − k) = C(a + b + n + 1, n). Proof. (i) and (ii) follow from Theorem 3.1 with β = n and C(n, n − k) = C(n, k). For (iii), upper negation gives C(a + k, k) = (−1)ᵏ C(−a − 1, k), so the sum equals (−1)ⁿ ∑ₖ C(−a − 1, k) C(−b − 1, n − k) = (−1)ⁿ C(−a − b − 2, n) = C(a + b + n + 1, n), by Theorem 3.1 and upper negation once more. ∎

Part (iii) has a combinatorial reading in terms of multisets, and for a = b = 0 it reduces to ∑ₖ 1 = n + 1. It shows how negative upper indices, which have no direct combinatorial meaning, give short proofs of positive identities.

Corollary 3.3. ∑ₖ k C(n, k)² = n C(2n − 1, n − 1). Proof. By absorption the sum is n ∑ₖ C(n − 1, k − 1) C(n, n − k) = n C(2n − 1, n − 1) by Theorem 3.1, since the lower indices sum to n − 1. ∎

Exercise

  • (a)
    Evaluate ∑k=05 C(7, k) C(6, 5 − k).
  • (b)
    Evaluate ∑k=04 C(k + 2, 2)(5 − k) using Corollary 3.2(iii), and check by direct addition.
  • (c)
    Show that ∑ₖ C(1/2, k) C(1/2, n − k) = 0 for n ≥ 2 and verify it for n = 2.
Show solution

Answers: (a) C(13, 5) = 1287. (b) Here 5 − k = C(1 + (4 − k), 4 − k), so a = 2, b = 1, n = 4 and the sum is C(2 + 1 + 4 + 1, 4) = C(8, 4) = 70; directly, 1·5 + 3·4 + 6·3 + 10·2 + 15·1 = 5 + 12 + 18 + 20 + 15 = 70. (c) By Theorem 3.1 the sum is C(1, n) = 0 for n ≥ 2. For n = 2: 2 C(1/2, 0) C(1/2, 2) + C(1/2, 1)² = 2(−1/8) + 1/4 = 0.
