Key idea of this section

rows: (1 + x)ⁿ     columns: xᵏ/(1 − x)k+1     whole triangle: 1/(1 − y − xy)
bₙ = ∑ₖ C(n, k) aₖ   ⟺   aₙ = ∑ₖ (−1)ⁿ⁻ᵏ C(n, k) bₖ

Rows, columns and the bivariate series

The nth row has generating function ∑ₖ C(n, k) xᵏ = (1 + x)ⁿ. For the kth column we need ∑ₙ C(n, k) xⁿ. Writing n = m + k and using upper negation, C(m + k, m) = (−1)ᵐ C(−k − 1, m), so

∑ₙ C(n, k) xⁿ = xᵏ ∑ₘ C(−k − 1, m)(−x)ᵐ = xᵏ / (1 − x)k+1

by the formal identity Bα(−x) = (1 − x)α with α = −k − 1 (Lesson 3). Summing the row generating functions against yⁿ gives the generating function of the whole triangle,

∑n,k C(n, k) xᵏ yⁿ = ∑ₙ (y(1 + x))ⁿ = 1 / (1 − y − xy)

from which every row and column series can be extracted. Shallow diagonals are obtained by substituting: the sums dₙ = ∑ₖ C(n − k, k) along the lines of slope one in the left-justified triangle have generating function ∑ₙ yⁿ ∑ₖ C(n − k, k) = 1/(1 − y − y²), obtained from the bivariate series by the substitution that weights C(m, k) by ym+k, namely x ↦ y and y ↦ y in 1/(1 − y − xy). Since 1/(1 − y − y²) = ∑ Fₙ₊₁ yⁿ with F₁ = F₂ = 1, we get dₙ = Fₙ₊₁: the shallow diagonal sums are Fibonacci numbers.

n = 4:  C(4, 0) + C(3, 1) + C(2, 2) = 1 + 3 + 1 = 5 = F₅

The central binomial coefficients

From C(−1/2, n) = (−1/4)ⁿ C(2n, n) (Lesson 1) we obtain:

∑ₙ C(2n, n) xⁿ = ∑ₙ C(−1/2, n)(−4x)ⁿ = (1 − 4x)−1/2

Squaring gives (1 − 4x)−1 = ∑ 4ⁿ xⁿ, hence the striking identity ∑k=0n C(2k, k) C(2n − 2k, n − k) = 4ⁿ. For n = 3 the terms are 20, 12, 12, 20, with sum 64. Bijective proofs of this identity exist but are considerably more intricate than the two-line generating-function argument, which illustrates how far ahead the algebra can be.

Exponential generating functions and the binomial transform

For sequences (aₙ), (bₙ) with exponential generating functions A(x) = ∑ aₙ xⁿ/n! and B(x) = ∑ bₙ xⁿ/n!, the product rule for exponential series reads

A(x) B(x) = ∑ₙ ( ∑ₖ C(n, k) aₖ bₙ₋ₖ ) xⁿ/n!

so binomial convolution corresponds to multiplication. In particular bₙ = ∑ₖ C(n, k) aₖ means B(x) = eˣ A(x), and therefore A(x) = e⁻ˣ B(x), that is aₙ = ∑ₖ (−1)ⁿ⁻ᵏ C(n, k) bₖ. This is binomial inversion, a special case of Möbius inversion on the Boolean lattice.

Example (derangements). Every permutation of [n] fixes some set of k points and deranges the remaining n − k, so n! = ∑ₖ C(n, k) Dn−k = ∑ₖ C(n, k) Dₖ. Binomial inversion gives Dₙ = ∑ₖ (−1)ⁿ⁻ᵏ C(n, k) k! = n! ∑j=0n (−1)ʲ/j!.

D₄ = 1 − 4 + 12 − 24 + 24 = 9          D₅ = 44          D₆ = 265

The Pascal matrix

Let Lₙ be the (n + 1) × (n + 1) lower-triangular matrix with entries (Lₙ)ᵢⱼ = C(i, j), 0 ≤ i, j ≤ n. Binomial inversion says precisely that Lₙ⁻¹ has entries (−1)i−j C(i, j). More generally the matrix with entries C(i, j) ti−j represents the substitution f(x) ↦ f(x + t) on polynomials of degree at most n in the basis 1, x, …, xⁿ (up to transposition), so these matrices form a one-parameter group: their product for parameters s and t is the matrix for s + t. Its infinitesimal generator is the matrix S with Si,i−1 = i and zeros elsewhere (the matrix of d/dx), and Lₙ = exp(S), the series terminating because S is nilpotent.

The symmetric Pascal matrix Pₙ has entries C(i + j, i). By Corollary 3.2(ii), ∑ₖ C(i, k) C(j, k) = C(i + j, i), which says Pₙ = Lₙ Lₙᵀ. This is the Cholesky (LU) factorization of Pₙ, and since Lₙ is unitriangular, det Pₙ = 1 for every n. Thus Pₙ is a positive-definite integer matrix of determinant 1 whose entries grow exponentially.
